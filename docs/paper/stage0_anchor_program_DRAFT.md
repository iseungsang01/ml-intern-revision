# Stage 0 초안: 기준시점 일관 추정기 프로그램의 메타데이터 준비

상태: **등록 확정 전 초안, 실행하지 않음.** 현재 B.104 학습·예측·코드는
그대로 유지한다. 이 문서는 새로운 적합이나 TEST 재채점을 허용하지 않는다.
우선순위 근거는 `fable_deep_review/DECISION.md`와 마지막
`13_delayed_measurement_source_addendum.md`이며, 이전의 지연 갱신 독립 기여
제안보다 마지막 병합 결정을 우선한다. 원고의 pedestal-top nowcasting
목적과 기존 질문을 바꾸지 않고 그 안에서 후속 비교를 준비한다.

문헌 접근 상태에는 최신 `fable_deep_review/NN_CES_CORRECTION.md`와
`docs/reference/nnces_source.md`를 적용한다. DECISION 말미의 NN-CES 전문
미확보 문장은 최신 사실이 아니다. 해당 전문이 과거 Fable 요청에 들어간
것으로 소급하지 않으며, P1 순위를 모든 최근접 원문까지 포함해 최종
재검증한 것으로 주장하지 않는다. 실행 등록 전 입력·표적·시점·가용 규칙의
문헌 대비표를 이 원문까지 포함해 완성해야 한다.

## 다음 프로그램의 고정 질문

CES 과거 이력과 NBI를 조건으로 했을 때 BES/ECEI가 추가하는 예측 정보를
같은 평가 행에서 구분한다. 현재 TCN의 FAST/HISTORY 대비와 기존 B.98의
fast+NBI 결합 대비만으로 이 질문을 모두 답했다고 취급하지 않는다.

선형 강제응답 계열의 핵심 팔은 H(CES 이력), H+fast, H+NBI,
H+NBI+fast이다. fast 증분의 직접 대비는 H+NBI+fast 대 H+NBI이며,
H+fast 대 H도 구분한다. hold, 인과 GP, GP+부스팅, 정적 anchor 차분을
같은 행에서 비교하되 정보집합·TRAIN 지원·적합 예산 차이를 별도 표시한다.
기준시점 fast 값을 쓰는 팔에는 그 정보가 없는 대조와의 차이를 명시한다.

## Stage 0에서 등록할 메타데이터 범위

- 기존 B.73/B.75/B.79/B.81/B.82/B.84/B.98의 등록·구현·적합·외부 평가
  상태와 실제 존재하는 비교군을 구분해 목록화한다. B.90 observer/loss의
  보류·미평가를 실험적 탈락으로 쓰지 않는다.
- 저장 예측의 row index 키·정렬·shape·설계/규칙/표적·설정 및 소스 hash를
  조사한다. 새로운 오차, skill, 표적 값, 예측 값은 계산하거나 읽지 않는다.
- 각 비교 안에서 동일 평가 행을 만들 수 있는지 row index와 적격 마스크의
  메타데이터로 확인한다. 서로 다른 검증 설계의 cluster 교집합을 강요하지 않는다.
- NBI의 기존 유효성 규칙, TRAIN/VAL 파일·정규화 통계, CES source index와
  source-time fast 접근 가능성 및 기준선의 정보집합을 확인한다.
- 공통 지원 비교와 각 표적의 원래 모집단 설명을 구분한다. F와 L5를 같은
  물리 참값으로 취급하거나 모집단이 같다고 가정하지 않는다.
- 공개 문서에는 개수·hash·가용 여부만 기록하고 원 row/shot 식별자와
  관측 값은 ignored data 안에만 둔다. 새 과금 호출은 별도 상한 아래에서만 한다.

## P1 실행 등록 전에 남은 선택

최소 실행 범위, TRAIN/VAL에서만 선택할 τ·정칙화 경로, NBI 유효성의 모든 팔
공통 적용, bootstrap 단위·다중성 계열과 처리, 운영 또는 내부 VAL 근거의
마진 δ, 계산 예산과 중단 규칙을 확정해야 한다. 이 초안은 δ나 실행 시간을
임의로 고정하지 않는다. 충분한 공통 지원이 없으면 대조를 억지로 만들지 않는다.

기존 skill은 `1-MSE(진단 포함)/MSE(이력만)`로 양수가 감소 방향이다.
새 손실 차를 쓰면 `L(후보)-L(대조)`로 정의하여 음수가 감소 방향임을
명시한다. 마진을 넘는 감소 판정은 보정 구간 상한 `< -δ`, 마진 이내
판정은 구간 전체가 `(-δ,+δ)` 안에 있을 때이다. 그 외는 미해결이며,
우월성 미확인을 동등성이나 정보 부재의 증거로 해석하지 않는다.

## 방법·물리·검증의 경계

사건 갱신·버퍼 재전파는 P1의 구현·대조로 두고 독립 알고리즘 신규성으로
주장하지 않는다. 반복 hold를 고정 분산의 독립 CES 관측으로 세는 약한
대조만 사용하지 않는다. 선형·중간 갱신 없는 경우의 단축식을 일반 비선형
필터에 그대로 적용하지 않는다. 비선형 특징 차분의 offset 불변성도 가정하지 않는다.

실제 도착 기록이 없으므로 source-age 규칙은 구성된 시나리오다. 예측 분산은
보고값의 분산이고, τ는 식별된 물리 수송 시간이 아니다. 네 검증 설계와
기존 두 evidence scope를 분리하고, 재사용 TEST 이후의 모든 새 방향은
탐색적으로 기록한다. 별도 미사용 관측 없이는 독립 확증을 주장하지 않는다.

평균을 고정한 보고값 분산 모형과 동결 인과 표현 탐침은 그다음 조건부
후보다. 인코더 이름·다중 진단·진단 결측·빠른 계산만으로 차별점을 확정하지
않으며, 같은 계산 예산과 source-time 계약에서의 결과 및 문헌 대조가 필요하다.
