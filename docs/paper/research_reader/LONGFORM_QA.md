# 한국어 장문 원고를 위한 독립 편집·근거 점검

검토 대상은 현재 `../introduction_review/manuscript_sections.json`, 영문 원고 `../ppcf_revision/main_ppcf.tex`의 Results·Discussion·Conclusion, 그리고 아래에 명시한 문헌별 원문 감사 기록이다. 새로운 API 호출이나 과학 실험은 수행하지 않았다. 이 문서는 논문 본문이 아니라 장문 재작성자를 위한 내부 점검표다. 원문 감사 기록의 재독은 새로운 PDF 전문 시각 검증과 구분한다.

## 1. 가장 먼저 바꿀 점

현재 한국어 원고는 잘못된 주장을 막는 데 치우쳐 연구 질문과 완료된 발견을 설명하지 못한다. 특히 결론의 “결론은 실제로 완료한 기준선·모델 비교와 그 적용 범위를 요약한다”는 문장은 결론을 쓰는 지시일 뿐 연구의 결론이 아니다. 고찰도 “함께 다룬다”, 결과도 “나눠 읽는다”라는 편집 지시로 끝난다. 사용자가 읽어야 할 것은 작성 방침이 아니라 어떤 추정기가 어떤 조건에서 유용했는지에 대한 완결된 설명이다.

서론은 pedestal 측정의 물리적 필요 → CES가 만드는 측정량과 시간 정보 → 진단 융합·스펙트럼 판독 연구의 성취 → 아직 남은 한 측정선의 보고값 nowcasting 질문으로 이어져야 한다. 결과와 결론은 이미 끝난 GP+boosting 실험의 발견부터 제시해야 한다. CNN/NN 설계 계획은 완료된 결과를 대체할 수 없다.

“미래의 물리적 온도를 예보하는 문제가 아니다”, “독립적인 참값이 아니다”, “실시간 배치는 주장하지 않는다”, “우열을 주장하지 않는다”를 문단마다 반복하면 연구가 무엇을 했는지 흐려진다. 입력·표적·정보 가용성을 방법에서 한 번 정확하게 정의하고, 각 결과를 해석하는 데 필요한 한정만 가까이 둔다. 참조와 한정은 삭제하는 것이 아니라 설명의 자리에 배치한다.

## 3. 원문 감사 기록을 다시 읽고 확인한 문헌 사용 범위

### Ko2015 — 물리적 동기를 구체화할 주된 재료

KSTAR의 이온온도 pedestal이 수 cm 폭으로 형성되고 L–H 전이 이후 진화하며 RMP ELM 억제 중 낮아진다는 내용은 서론의 실질적인 물리 배경이다. “Pedestal은 중요하다” 한 문장 뒤 곧바로 NN으로 넘어가는 것보다, 진단이 포착하는 높이·폭·시간 변화가 어떤 질문을 가능하게 했는지 설명할 수 있다. 이 논문은 제공자가 선정한 우리 측정선의 pedestal-top 위치, 2022 운전 설정, 보고 도착 시각을 확인해 주지 않는다. 각 discharge의 pedestal 위치를 새로 피팅했다는 문장도 만들 수 없다.

참조: `../introduction_review/paper_Ko2015IonTemperature.json`, PDF pp.3–5 및 p.8에 대응하는 claims.

### NN-CES — 현재 연구의 정확한 위치를 정하는 가장 가까운 선행연구

입력은 한 CES 채널의 현재 스펙트럼이며, 현재 프레임의 Doppler 이동·폭을 읽는다. 우리 입력은 엄격히 과거의 CES 보고 이력과 현재까지의 BES·ECEI 전압 표본이다. 이 차이를 먼저 설명하면 “상류 판독–하류 시간 추정”이라는 관계가 자연스럽다. 실제 연결 효과는 측정하지 않았지만 모듈 경계는 구체적으로 설명할 수 있다. 새 판독값이 도착하면 이력을 갱신하고, 갱신 사이에는 이력과 빠른 진단으로 보고값 추정을 유지하는 구조다.

NN-CES의 GPU 배치당 프레임 처리 시간을 온라인 단일 프레임 지연으로 쓰지 않는다. 주변부 성능 저하에 대한 저자의 설명을 우리 측정선의 관측 결과로 옮기지 않는다. 우리 방법이 NN-CES보다 더 발전했다거나 더 정확하다는 결론도 없다. 반대로 NN-CES의 존재가 현재 연구를 무효화한다는 결론도 없다. 더 빠른 판독은 앵커를 최신화하면서 nowcast가 필요한 시간을 줄일 수 있다.

참조: `../introduction_review/paper_Lee2026NeuralNetworkbased.json`, pp.2–5 대응 claims.

### Shousha/RTCAKENN — 관련 연구의 성취를 충분히 인정할 것

이 논문은 전자량만 다루는 진단도, 비인과 보간만 하는 연구도 아니다. 최신 가용 진단으로 현재 kinetic profile을 재구성하고, 실제 DIII-D PCS에서 실행했다. CER를 제외한 경우에도 프로파일을 산출하는 입력 dropout 대책이 있다. 다만 no-CER 상태의 이온온도 정확도는 정성적으로만 평가되었고, CAKE의 edge Ti는 주이온/전자온도 비율 가정이 들어간 외삽이다. 따라서 차이는 “다른 진단으로 Ti를 처음 추정”이 아니라 표적·이력 앵커·가용 시점·검증 비교에 둔다.

코퍼스 키에 2023이 들어가지만 감사 기록의 실제 출판연도는 2024다. 저자·연도 표기에는 키 문자열을 쓰지 않는다.

참조: `../introduction_review/paper_Shousha2023MachineLearningbased.json`, PDF pp.3–6, pp.13–17 대응 claims.

### Vanovac2018 — 신호 의미와 인과 해석을 분리

AUG의 경계 ECEI에 대한 방사 전달 모델은 밀도 변화와 shine-through가 신호에 영향을 줄 수 있음을 보여 준다. 이 결과는 BES·ECEI 신호에 예측력이 있다는 것과 전자–이온 에너지 전달 기전을 식별했다는 것을 구분할 근거다. 다른 장치에서의 정량 비율을 KSTAR에 이식하지 않는다. “ECEI는 전자온도를 측정하지 못한다”는 일반 결론도 쓰지 않는다.

참조: `../introduction_review/paper_Vanovac2018EffectsDensity.json`, PDF pp.5–11 대응 claims.

## 4. 긴 결과·고찰·결론에 실제로 넣어야 할 발견

아래는 영문 Results와 Conclusion을 읽고 추린 **결과의 방향과 조건**이다. 정량값을 넣을 때는 해당 생성 표·매크로를 직접 재사용하고 새로 추정하거나 손으로 전사하지 않는다.

1. **완료된 본선 모델을 명시한다.** CES 이력의 인과 GP와 이력·BES·ECEI 요약 특징의 boosted regression 결합이 현재 비교에서 가장 낮은 오차를 보인 인과적 추정기다. “NN을 설계할 예정이다”만으로 연구 결과를 마치지 않는다.
2. **대기하는 기준선과의 비교를 분리한다.** 현재 프레임 표적 F에서는 네 설계 모두 PCHIP보다 낮은 MSE가 확인된다. 양측 GP와 비교한 차이는 random·cluster-held-out에서 확인되며 rolling-origin·chronological에서는 확인되지 않는다. 이력-only 모델은 네 설계 모두 양측 GP보다 높은 MSE를 보였다. 이것이 빠른 진단의 역할을 설명하는 직접 근거다.
3. **오차 함수에 따라 의미가 다르다.** 양측 GP는 중앙 절대오차가 더 작을 수 있지만 nowcast는 큰 오차 쪽과 MSE에서 이점을 보인다. “모든 정확도 지표가 향상”으로 쓰지 않는다. PCHIP와의 중앙값 차이가 확인되지 않은 사실도 유지한다.
4. **F와 L5의 결과를 섞지 않는다.** 직전 CES 프레임이 보일 때 빠른 진단의 F 증가분은 네 설계에서 확인되지만 L5 증가는 rolling-origin에서 확인되지 않는다. 한 표적의 유의성을 다른 표적의 결론으로 쓰지 않는다.
5. **낡은 이력에서 다른 진단의 가치가 커진다.** 더 오래된 CES 앵커를 쓰는 조건에서 fast-input 증가분이 커지는 패턴은 핵심 응용 결과다. 각 가용성 규칙별로 재적합한 본선 모델이므로 하나의 고정 모델이 자동으로 모든 지연에 대응했다고 쓰지 않는다.
6. **대조 실험의 역할을 설명한다.** 현재 fast 표본을 앵커 시각 표본으로 대체하는 대조, 행 간 순열 대조, 빔 스칼라를 양측에 주는 비교는 현재·변화 정보의 예측 가치를 구분하려는 설계다. 순열의 모든 셀이 0이었다고 단정하지 않는다. 빔 스칼라를 통제했다고 물리적 인과가 식별되는 것은 아니다.
7. **마지막 shot 블록의 실패를 고찰의 실질적 질문으로 쓴다.** beam-modulation 규칙 S에서 마지막 블록의 fast 증가분은 시간 분할뿐 아니라 random test에서 그 블록만 모아도 확인되지 않는다. ECEI 양상의 차이는 사후 관찰이며 원인 규명이 아니다. shot별 자기장·ECEI 설정이 이 판단을 바꿀 정보다.
8. **MAST는 다른 장치에서 방향을 확인한 확장이다.** MAST의 Thomson 산란은 CES보다 빠른 센서가 아니다. 오래된 CES 이력에 현재의 다른 진단이 더하는 정보를 시험한 것이다. KSTAR의 BES/ECEI와 같은 센서·주파수 구조를 재현한 실험, 장치 간 무재학습 전이, KSTAR 전 반경 검증으로 쓰지 않는다.
9. **TCN 결과를 설명 없이 누락하지 않는다.** 선택한 TCN은 고정 예산에서 fast-enabled와 history-only를 비교했으며 증가분의 부호와 구간은 설계·가용성에 의존했다. 전체 suite의 한 초기화와 고정 subset의 세 초기화를 합쳐 전체 초기화 안정성으로 보고하지 않는다. 현재 범위에서 범용 채택을 뒷받침하지 않는다는 결과가 후속 NN 설계의 출발점이다.
10. **계산 가능성과 실제 운용을 구분한다.** 기존 생성 결과의 추론 비용은 프레임 예산과 비교할 수 있다. 진단 수집·전송·CES 분석의 실제 지연, 제어 적용 성과까지 측정한 결과로 확대할 수 없다. 이러한 한정은 계산 시간 결과를 설명한 뒤 논리적으로 붙인다.

영문 근거 위치: `../ppcf_revision/main_ppcf.tex`의 `sec:res:best`, `sec:res:fast`, `sec:res:designs`, `sec:res:use`, `sec:res:mast`, `sec:res:limits`, `sec:res:tcn`, `sec:conclusion`.

권장 결과 어휘는 “같은 평가 행에서 MSE 감소가 확인되었다”, “구간이 0을 포함해 차이를 확인하지 못했다”, “이 조건에서는 증가분이 확인되지 않았다”, “고정 계산 예산에서 도달한 적합 결과”이다. “차이가 없다”, “동등하다”, “이온 동역학을 복원했다”, “센서 간 인과관계를 증명했다”, “새 신경망이 우수하다”로 바꾸지 않는다. 결과의 정량 표시는 점추정·구간·0 제외 여부를 함께 제시한다.

## 5. 긴 실제 논문 본문을 위한 구성 재료

### 서론

- a에서는 연구 대상과 정보 집합을 먼저 제시하고, 어떤 기준선에 대해 어떤 질문을 평가했는지 연결한다. 두 단계 연구 계획은 완료된 경험적 평가와 후속 설계의 관계로 설명한다.
- b에서는 pedestal-top 측정이 필요한 물리적 맥락, CES 측정과 배경 분리 과정, 현재 보고값을 아직 쓸 수 없는 시간 구간을 차례로 다룬다. “기존 진단은 이온 물리량을 반영하지 못한다”는 총괄 비판을 회복하지 않는다.
- c에서는 추정값뿐 아니라 그 값을 사용할 조건을 오차·가용 이력·계산 시간으로 평가한다는 목적을 설명한다. 실제 제어 이익은 기대효과와 검증 결과를 구분한다.
- d에서는 선행연구를 나열하는 대신 스펙트럼 판독 / 현재 kinetic 재구성·가상 진단 / 시간 융합 / 미래 예보의 입력·표적·시간 관계로 비교한다. 연구 수를 성과처럼 제시하지 않는다.

### 이론적 배경

pedestal과 탄소 불순물 측정량, 활성·수동 방출 및 Doppler 폭의 관계, 노출·샘플링·보고 시각의 구분, causal filtering과 양측 smoothing, hold·GP·boosting·recurrent·TCN의 역할을 순서 있게 설명할 수 있다. 수식은 기호·단위·가정을 해설해야 하며 현재 원고처럼 식 하나를 긴 문장 안에 삽입하고 끝내지 않는다. 현재 BES·ECEI 파일이 full-rate turbulence 기록이 아닌 격자 표본이라는 점은 자료와 모델 해석을 연결하는 핵심이다.

### 고찰과 결론

고찰은 큰 오차에서의 개선, 최신 CES 이력이 이미 강한 기준선인 이유, 가용성이 줄어들 때 다른 진단의 기여가 커지는 패턴, 일부 shot 블록에서 성립하지 않는 이유를 찾기 위한 정보, TCN의 조건 의존성을 순서 있게 해석할 수 있다. 마지막에 독립 캠페인·스펙트럼·프레임별 피팅 불확실도·자기장과 ECEI 설정·평형 정보가 어떤 주장 범위를 확장할지 연결한다.

결론은 (1) 완료된 GP+boosting 추정과 기준선 비교, (2) fast 진단이 더하는 조건부 정보, (3) 검증 설계·표적·가용성에 따른 경계, (4) 그 결과에 근거한 다음 NN 설계 및 실제 판독기 연동 검증이라는 네 흐름으로 완결한다. 절 작성 지시, 파일 위치 안내, API·읽은 문헌 개수·버전 상태는 논문 결론의 내용을 대신할 수 없다.

## 6. 장문 최종본 점검 시 반드시 유지할 경계

- 네 검증 설계를 모두 보고한다. 0 포함 구간은 무효과·동등성 증명이 아니다. 모델 적합·선택·다중 비교의 불확실성이 구간에 포함되었다고 쓰지 않는다.
- MAST의 다른 진단·가용성 실험을 KSTAR 측정선의 독립적 참 온도 검증으로 쓰지 않는다.
- 문헌별 실측 결과·모델링·저자의 해석을 구분한다. DOI·연도·장치·연구 대상이 키 문자열이나 요약 표현과 다를 때 실제 서지를 따른다.
- 새로운 수치는 생성 표·검증된 원자료에서 불러오며, 문장 확장을 위해 새로운 실험 결과를 만들어 넣지 않는다.

### NN-CES Lee2026: 입력·분할·추론 시간

직접 읽은 파일: `data/literature/Lee2026NeuralNetworkbased.pdf`. PDF 페이지와 논문 페이지가 같다.

- **PDF p.2, §2.1–2.2 본문 직접 확인:** D 중성빔과 C6+의 charge exchange 이후 들뜬 C5+가 C VI 선을 내는 반응식, 529.05 nm 파장, beam-on/off 배경 제거 절차를 제시한다. 방출선의 전하 상태와 진단하고자 하는 charge-exchange 이전 모이온의 상태를 혼동하지 않아야 한다.

결론: 입력·분할·시간의 감사 기록을 원본문으로 확인했다. 스펙트럼 판독의 가속이라는 성취를 충분히 설명하면서도, 그 배치당 프레임 비용을 우리 시간 추정기의 온라인 응답시간과 직접 비교하지 않는다.

### Shousha/RTCAKENN: CER 결측 상태에서의 Ti 평가

직접 읽은 파일: `data/literature/Shousha2023MachineLearningbased.pdf`. 출판사 표지가 있어 PDF 페이지가 논문 페이지보다 하나 크다. PDF 헤더의 출판 정보는 Nuclear Fusion 64 (2024) 026006이다.

- **PDF p.14, Fig.11 직접 시각 확인:** CER 결측 hardware test의 pressure·current-density 프로파일을 여러 시각의 곡선으로 표시한다. 이 그림은 Ti 정량 오차 그림이 아니다.
- **PDF p.15, Fig.12 직접 시각 확인:** 나머지 출력에 carbon Ti와 회전 프로파일이 실제로 포함되어 있다. 여러 시각의 예측 곡선을 표시하지만, 이 패널에는 독립 Ti 참조 곡선·잔차·정량 오차 지표가 제시되어 있지 않다. 따라서 “CER가 없어도 Ti를 출력했다”는 사실과 “CER가 없을 때 Ti 정확도를 정량 검증했다”는 주장은 분리해야 한다.
- **PDF pp.14–15, §4.3 본문 직접 확인:** 실제 PCS 실행 비용을 다룬다. 실제 장치에서 실행되었다는 성취를 단순 오프라인 추론 사례로 축소하지 않는다. 이 성취가 no-CER Ti의 정량 정확도를 자동 보장하는 것은 아니다.
- **확인하지 않은 범위:** Fig.12 곡선을 새로 디지털화하거나 CAKE와의 오차를 재계산하지 않았다. 감사 기록에 없는 CER 결측 Ti 오차 수치를 만들어 내지 않았다.

결론: 감사 기록의 “CER 결측 Ti는 정성 평가”는 원본문과 Fig.12를 직접 대조해 유지할 수 있다. 다만 논문 전체에 정량 Ti 평가가 없다는 표현은 틀리다. input dropout이 없는 regression과 CER 완전 결측 실험의 검증 조건이 서로 다른 것이다.

### Vanovac2018: ECEI 복사전달 모델의 성격

직접 읽은 파일: `data/literature/Vanovac2018EffectsDensity.pdf`. 출판사 표지가 있어 PDF 페이지가 논문 페이지보다 하나 크다.

- **PDF p.4, §3 본문 직접 확인:** 주어진 H-mode 평형과 전자온도·밀도 프로파일에서 예상 복사온도를 계산하는 forward model을 설명한다. IF bandwidth를 포함하고, 빔을 single ray로 근사하며 O-mode emission의 영향을 무시한다. 굴절을 포함한 ray tracing 뒤 시선을 따라 복사전달 방정식을 푼다. 따라서 이것은 BES/ECEI에서 Ti를 학습·추정하는 ML 연구가 아니다.
- **PDF pp.5–6, §3–4 본문 직접 확인:** SOL 쪽 shine-through와 ELM 관련 비정상 조건의 해석을 설명하면서, 연구에 사용한 전형적 H-mode 프로파일의 separatrix 안쪽에서는 복사온도와 전자온도가 같다고 볼 수 있다고 명시한다. “edge ECEI는 전자온도를 측정하지 않는다”는 일반화는 이 본문과도 맞지 않는다.
- **PDF p.8, §5 및 p.9, §6 본문 직접 확인:** Li-BES를 이용한 밀도 변동 분석에 이어, 밀도 섭동을 입력 프로파일에 넣어 ECE 복사온도 응답을 계산한다. 온도 섭동의 가정을 달리한 경우를 비교한다. 밀도가 복사온도에 기여한다는 결론은 측정 신호의 상관 분석과 이러한 모델링을 함께 바탕으로 한다.
- **PDF p.9, §6 본문 직접 확인:** 단순화한 모델 때문에 모델led amplitude와 measured amplitude를 직접 비교할 수 없다고 저자들이 명시한다. 모델에 주어진 밀도 섭동과 계산된 복사온도 변화 비율을 KSTAR 원시 전압의 보정 계수처럼 사용할 수 없다.
- **확인하지 않은 범위:** Fig.10 픽셀에서 새로운 수치를 추출하지 않았다. AUG의 특정 관측 기하와 방전 조건을 우리 KSTAR 측정선에 대입해 검증하지 않았다. 우리 raw-voltage 자료가 보정 가능한지 여부도 이 논문만으로 판정하지 않는다.

결론: “경계 ECEI에는 밀도·방사 전달의 영향이 있으므로 전압 예측력만으로 전자온도 기전을 식별할 수 없다”는 제한된 해석을 뒷받침한다. “밀도가 우리 ECEI 신호를 지배한다” 또는 “우리 자료의 물리적 원인을 확인했다”는 결과는 제공하지 않는다.

## 8. 합친 장문 초안의 최종 독립 점검

점검 대상은 `longform/draft_longform.json`의 전체 절이다. 서론·이론·방법을 직접 읽고, 결과·고찰·결론은 독립 작성본과 정확히 일치함을 JSON 비교로 확인한 뒤 기존 영문 근거와 다시 연결했다. 원고 JSON은 수정하지 않았다. 아래의 인용문은 해당 초안의 정확한 원문이다. 제안은 새로운 실험 결과가 아니라 잘못된 범위 확대와 문장의 모호성을 바로잡기 위한 것이다.

| 서론 c | “판독이 빨라지면 추정기가 기대는 이력이 젊어져 추정이 쉬워진다.” | 실제 NN-CES 출력으로 평가하지 않았다. “같은 품질의 보고가 더 일찍 가용해진다면 더 최신 이력을 사용할 수 있다”와 같이 조건부로 쓴다. 보고 품질·분포가 달라질 가능성과 결합 미검증을 유지한다. |
| 서론 d의 Pastore 대조 | “pedestal top의 이온온도에는 간섭계에 해당하는 빠른 직접 측정이 없다.” | 전 장치를 포괄하는 부재 주장으로 읽힌다. “현재 제공 자료에는 이온온도의 독립적인 고속 직접 측정이 없다”로 자료 범위에 한정한다. |

이론 3의 “가장자리 시선에서는 수동 신호가 활성 신호보다 훨씬 약하다. 분리가 특히 중요한 것은 코어 시선이다”는 Viezzer2011 감사 기록의 설명과 맞는다. 이를 NN-CES의 KSTAR 외곽 active/passive 비 감소와 같은 장치·같은 기하의 보편 법칙으로 합치지만 않으면 된다. 현재 초안처럼 장치와 시선 의존성을 밝히는 문맥을 유지한다. Shousha의 CER 결측 Ti 정성 평가, Vanovac의 AUG forward model 성격, NN-CES 스펙트럼 입력 자체의 설명도 본 초안에서 삭제할 오류는 아니다.

### 8.3. 본문에서 덜어낼 작업 메모와 조정할 서술

- 방법 NN a의 “이 연구의 이전 판에서 주 추정기였고, 지금은 추정기 비교 표의 비교 행으로 남아 있다”는 버전 이력이다. 현재 논문의 비교 후보와 입력을 설명하는 문장으로 바꾼다. LSTM과 두 단계형을 평가했다는 사실은 남긴다.
- 방법 사의 “실행 대기열은 끝까지 돌았고, 실행 뒤의 감사를 통과했으며”는 실행 상태 보고다. 필요한 내용은 사전등록·구조 선택·독립 재계산의 범위다. 완료 상태나 대기열 정보는 연구 본문에서 제거한다.
- 방법 사의 “표는 감사된 결과 파일에서 생성되며 손으로 고치지 않는다”는 내부 작성 규칙에 가깝다. 재현성 설명이 필요하다면 “표와 지표는 동일한 평가 산출물에서 생성하였다”로 간결하게 기술한다.
- 방법 NN b의 “같은 회귀에 원시 창을 그대로 주면 오차가 크게 높아졌다”는 실험 결과다. 방법에서는 요약 특징의 정의를 설명하고, 구조 선택의 경험적 근거는 결과·고찰의 해당 비교로 옮기거나 명시적으로 연결한다.
- 서론 a의 “빠른 입력을 행끼리 뒤섞어 다시 적합하면 증분이 사라져야 한다”는 대조의 예상이다. 실제 대조의 모든 조건이 영과 구분되지 않았던 것은 아니므로 결과 서술과 섞이지 않게 가설임을 표시한다.
- 서론 c는 기대효과에 이미 완료된 결과를 길게 반복한다. 원래 a/b/c/d 구조는 유지하되 c에서는 결과의 요지와 활용 목적만 남기고, 조건별 상세 비교는 결과 절로 모으면 본문 흐름이 좋아진다.

### 8.4. 유지해도 되는 주요 결과와 남은 확인

결과·고찰·결론은 독립 작성본과 동일하다. F의 fast 증가가 네 설계에서 확인된다는 문장과 L5의 rolling-origin 미확인을 구분하고 있다. 양측 GP 대비 시간 순서 두 설계에서 차이가 확인되지 않음, 중앙 절대오차의 반대 방향, 마지막 S 블록의 한계도 유지된다. TCN은 본선 ladder와 다른 평가 행, 고정 예산과 checkpoint 선택, 전체 단일 초기화와 부분집합 반복을 구분한다. MAST의 Thomson이 CES보다 빠르지 않다는 점과 장치별 재적합을 명시하고 있다. 새 성능 수치를 만들어 넣거나 NN 재설계를 완료 결과로 제시한 문장은 이 세 절에서 발견하지 못했다.

방법의 GP 최근 관측 수·커널·주변우도 선택, 현재 특징과 앵커 특징, 표준화 범위, 가용성 규칙, 검증 분할과 bootstrap 설명은 현재 영문 `sec:methods:est`, `sec:methods:rules`, `sec:methods:designs`와 대체로 일치한다. 다만 한글에서 앵커 평균의 창 끝이 생략되어 있으므로 “각 인덱스에서 끝나는 최근 창”임을 명확히 하면 재현성이 좋아진다. “오차는 eV”와 “모든 구간을 영과 비교”는 위 표처럼 반드시 정정한다.

방법 시나리오 절의 “채점된 행은 모두 빔이 입사되는 구간에 있다”는 본선 자료의 새 전칭 진술이다. 현재 영문에는 CES가 보는 빔이 없는 absent frame을 구분한 설명이 있으나, 모든 채점 행에서 어떤 빔 신호가 어떤 기준 이상인지에 대한 명시적 검정 수치는 이 점검에서 확인하지 않았다. 해당 판정 기록이 없다면 “빔과 관련된 측정이며 빔-off에 대응하는 absent frame은 채점하지 않는다” 수준으로 좁히는 편이 정확하다.

최종 형식에서는 참고문헌 절과 실제 표·그림 연결을 복구해야 한다. `draft_longform.json` 자체에는 참고문헌이 독립 절로 들어 있지 않으며, 결과 절의 “아래 … 생성 표”는 HTML/PDF 삽입이 전제된 문장이다. 이 둘은 본문 내용의 오류가 아니라 최종 통합 때 확인할 연결 사항이다.
