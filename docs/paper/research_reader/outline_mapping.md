# 원래 HWP 목차와 현재 절별 구성

최신 요청의 일곱 상위 절로 번호만 정리했다. 원래 Dataset/수집 기준/장치 설계/NN의 하위 자리는 유지한다. 원 API 응답은 바꾸지 않았다.

원본의 개인 정보와 본문은 공개 기록이나 API 요청에 넣지 않았다. 아래는 목차만 대조한 구조 기록이며, 과거 제안 문구가 완료된 실험을 뜻하지 않는다.
