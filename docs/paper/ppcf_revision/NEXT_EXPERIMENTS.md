# PPCF 개정과 후속 실험 계획

이 문서는 독립 PDF 심사와 novelty 검토를 받은 뒤 정리한 계획이다. 현재 TEST 결과를 보고 제안한 분석은 탐색적이며, 실행 전 별도 사전등록이 필요하다. 새 GPU/CPU 적합과 새 TEST 재채점은 수행하지 않았다.

## 현재 주장할 수 있는 기여

기존 GP·boosting·TCN을 새로운 알고리즘으로 제시하지 않는다. 연구의 기여 후보는 pedestal-top CES 보고값의 인과 추정에서 보간 기준과의 차이, CES 이력 너머의 빠른 진단 증분, 정보 가용 조건과 검증 설계에 따른 성립 범위를 함께 평가한 실증 근거다. 원시 스펙트럼에서 온도를 읽는 NN-CES와 CES 보고값을 추정하는 과제는 입력과 평가 대상이 다르다. 서로의 성능 우위는 같은 자료의 비교 없이는 주장하지 않는다.

## 완료한 원고 수정

- 독립 감사된 선택 TCN 결과를 기존 GP·회귀 estimator와 구분해 추가했다.
- 전체 unit의 한 seed와 고정 subset의 세 seed를 별도 표로 생성했다. 모든 새 표의 수치는 원천 JSON에서 읽는다.
- 첫 PDF에서 누락된 TCN 절과 상호참조를 복구했다. 첫 심사 기록은 수정하지 않는다.
- GP 대비 빠른 진단의 기여가 모든 시간순 조건에서 성립하는 것처럼 읽히는 문장을 좁혔다.
- novelty는 알고리즘 우선권이나 물리 기전 발견으로 확대하지 않는다.

## 다음 후보와 필요한 증거

### 1. 현재 지표가 실제 사용 요구를 얼마나 충족하는가

기존 저장 예측으로 사건 근처/그 밖의 행에서 상대 오차와 보간 대비를 기술할 수 있다. GPU는 필요하지 않지만 새 결과 분석이므로 행 정의·표적·비교군·구간·모든 설계 보고 규칙을 사전등록해야 한다. 기존 B.82와 사건/beam 통제 분석을 먼저 대조해 중복을 배제한다. 독립 캠페인으로 일반화가 확인된 것은 아니다.

반증 조건: 시간순 설계의 움직이는 프레임에서 보간 대비 구간이 유리한 쪽으로 zero를 제외하지 않으면 그 조건의 우위 주장을 하지 않는다. 양의 결과도 TEST-informed 탐색으로 표기하고, 음의 결과는 사용 범위 제한으로 보고한다.

### 2. 신경망의 고정 예산 효과

최신 결과는 학습이 도달한 예산에서의 비교다. 예산 증가가 짧은 CES 이력 조건의 음수 증분을 바꾸는지는 현재 결과로 답할 수 없다. 기존 TRAIN/VAL 곡선의 기술적 검토는 가능하지만 새 적합은 별도 사전등록과 GPU 승인이 필요하다. 이 작업에서는 실행하지 않는다.

반증 조건: 미리 고정한 한 수준의 확대 예산에서도 같은 방향의 점추정과 구간이 유지되면 예산 부족 설명을 지지하지 않는다. 양의 결과는 예산 민감성, 음의 결과는 한정된 자원에서의 비채택 근거로 적는다. 테스트를 보며 예산을 반복 조정하지 않는다.

### 3. 반경 특이성과 캠페인 독립성

측정 위치의 물리적 특이성은 per-shot 평형, 채널 mapping과 진단 설정이 필요하다. 범용 기여의 독립 확인에는 사용하지 않은 캠페인과 실제 가용 timestamp가 필요하다. 이 자료는 현재 확보되었다고 쓰지 않는다. GPU 없이도 가능한 통제 분석이 있지만 핵심 제약은 추가 측정/metadata다.

반증 조건: 위치를 맞춘 채널의 증분이 off-radius 또는 공통 상태 신호보다 크지 않으면 국소 pedestal 메커니즘의 증거로 해석하지 않는다. 독립 캠페인에서 재현되지 않으면 캠페인 내 결과로 제한한다.

## 심사 해석

Claude 평가는 실제 PPCF 편집 결정이 아니다. 첫 novelty 검토는 weak reject였고, 고정 심사는 원고 결함과 신규성 부족을 지적했다. 최종 판정은 수정 PDF를 읽은 후속 독립 보고를 우선한다. 심사자의 문헌·수치 해석도 검증된 사실로 자동 승격하지 않는다. 별도 검토가 제시한 secondary 웹페이지 링크는 원저자를 직접 확인하기 전 참고문헌에 넣지 않는다.
