# PPCF revision with independent novelty feedback

The current deliverables are `main_ppcf.tex` / `main_ppcf.pdf`, `supp_ppcf.tex` / `supp_ppcf.pdf`, `generated_tables.tex`, `NEXT_EXPERIMENTS.md`, and the independent review records. This is an isolated revision of `../ppcf`, not a replacement of the established manuscript. Original copied assets are identified in `initial_copy.json`; the original source remains authoritative for inherited tables.

New TCN tables are generated directly from the independently audited `../b94_methods.json` by `ces_prediction/research/icml_revision.py:generate_tables`, called from the PPCF workflow. `evidence_binding.json` binds the original audit. One-seed full-suite and three-seed fixed-subset evidence are separate. No scientific fit or GPU work is performed.

The author first requested ICML format and then changed the target to PPCF while the first request was in flight. Its incomplete response and all usage were preserved locally; no ICML review was used. A PPCF long-form draft also reached its output limit. Its complete prefix was recovered, the remaining original manuscript was retained, and the missing TCN section was subsequently restored with generated source tables. First-round PDFs therefore lacked that section; their criticism remains in `grade1.md` and `novelty1.md`. The second novelty review reads the corrected PDF and recommends weak reject. This is simulated feedback, not an actual editorial decision.

`grade2_INCOMPLETE.md` is explicitly an incomplete response and must not be presented as a grade. A fresh fixed-prompt review is preserved separately as `grade3.md` when complete. The fixed grading instructions are in `../review_loop/GRADER_PROMPT.md`; novel-claim review is an independent additional task, not a change to that fixed prompt. API reviewer calls are fresh contexts containing only frozen PDFs and their respective prompts; no previous reviews are supplied. The attached PDFs are anonymized local copies.

Exact requests, responses, incomplete attempts and errors stay in ignored `data/.ppcf_revision/` and `data/.icml_revision/`. Public usage metadata and hashes are in `api_usage.json`; current state is in `status.json`. Review suggestions and externally sourced claims require independent verification; reviewers' prose and percentages are not facts. New TEST-informed proposals require separate preregistration before scientific execution. `NEXT_EXPERIMENTS.md` distinguishes writing work, CPU analysis, GPU fits, and new measurements.

Build with `pdflatex` and `bibtex` in this directory. `latexmk` on this machine currently lacks Perl. Compile the supplement and main repeatedly until crossreferences resolve. The checked PDFs have no undefined references or overfull-box warnings in their final build logs. Preview PNGs were inspected locally and are not manuscript inputs.
