# TCN 결과 뒤의 연구 판단

새 API 검토 없이 기존 등록·결과·문헌 검토·소스를 대조한 작업자 판단이다.
새 방법의 독창성이나 출판 가능성을 확정한 문서가 아니다.

## 먼저 바로잡을 것

TCN은 제한된 A/C/T pilot에서 고정 시간 예산의 VAL 평균으로 선정됐다.
선정 파일 `data/.b94/selection.json`의 기준은 GP+부스팅이 아니라 C 대조였다.
등록한 GRU/observer/강건 손실 후보 전부를 실험해 탈락시킨 적은 없다.
그러므로 “모든 방법을 시도했고 TCN도 실패했으니 끝”이라는 해석은 틀리다.
그렇다고 남은 이름을 차례로 돌리는 것이 연구 기여를 보장하지도 않는다.

GP+fast 부스팅은 CES 전용 GP와 다르다. 빠른 BES/ECEI 정보가 후단에 들어간다.
B73의 TX 대 T0는 그 추가 가치를 분리한 기존 비교다. 신경망의 교체 merit와
멀티모달의 추가 가치는 서로 다른 질문이다. B73/B75/B79의 원본 구간·조건을
따르며 어떤 조건에서도 fast가 유용하다는 주장으로 넓히지 않는다.

## 지금 필요한 비교: B106

기존 LSTM+후단 보정과 GP+잔차 회귀를 혼동한 보고를 실제 학습으로 바로잡는다.
원래 온도 LSTM 경로를 현재 F에 적합하고, 네 파일-OOF 예측으로 후단을 학습한다.
원래 D10 후단과 scenario-mixture 후단은 구분한다. GP+fast,GP+history,GP 단독,
hold,TCN의 MSE를 같은 행에서 먼저 보여준다. 이 비교는 baseline 확인이지
그 자체가 새로운 알고리즘 제안은 아니다. 세부 계약 PREREGISTRATION_B106.md.

## 본 방법론의 다음 후보는 이름이 아니라 가설로 좁힌다

1. **GP 기준값을 보존하는 학습 잔차.** TCN 원인 검토가 지적한 직접 회귀의
   단점을 고립해 보는 최소 변경이다. 임의의 새 backbone 대신 인과 GP/hold에
   작은 잔차 순환 모델을 붙이고 현재 F·동일 지원에서 강한 회귀기와 비교한다.
   잔차 학습 자체는 표준 구성요소이므로 이것만으로 독창성을 주장하지 않는다.
   먼저 저장 VAL 잔차와 선택 지원의 차이를 분해해야 하며 아직 실행하지 않았다.
2. **NBI를 조건으로 남는 fast 강제응답.** 기존 P1 방향의 H,H+fast,H+NBI,
   H+NBI+fast 대비로 실제 진단 정보가 빔 대용변수 너머로 무엇을 주는지 분리한다.
   선형·정적 source 차분을 강한 대조로 두고, source 시점 제약을 갖는 작은
   학습 상태방정식은 그 대조에 설명되지 않는 잔차가 있을 때만 검토한다.
   이 질문은 논문 목적의 “빠른 진단이 CES 이력 너머로 더하는 것” 안에 있다.
   B98의 fast+NBI 동시 추가를 fast 단독의 검증으로 읽지 않는다.
3. **보고값 예측분포**는 평균 MSE 개선과 별도 목표다. 관측 잡음/물리 참값을
   식별할 자료가 부족한 상태에서 학습 분산을 물리적 잡음으로 부르지 않는다.
   평균 정확도를 못 높인 것을 불확실도 그림으로 대체하지 않는다.

당장 실행하는 것은 B106뿐이다. 후속 본 후보는 기존 결과와 새 비교를 확인한 뒤
하나의 가설·강한 대조·사전 고정한 판정 기준으로 등록한다. 기존 TEST를 본 뒤의
선택은 모두 탐색적이다. 현재 보고값,10ms nowcast,네 검증 설계라는 원고 틀은
바꾸지 않는다. GRU/Transformer/SSM이라는 이름을 추가하는 것을 기여로 삼지 않는다.
