# 최종 권고에 적용할 작업자 수학·구현 확인

API 보고서는 검토 의견이며 검증된 구현이 아니다. 특히 `09_substantive_research_programs.md`의 후보 식은 아래 조건 없이 구현 규격으로 쓰지 않는다.

- **비선형 특징 차분은 원신호 오프셋 불변성을 보장하지 않는다.** 일반적으로 phi(x+c)-phi(xs+c)는 phi(x)-phi(xs)와 다르다. 예를 들어 phi(u)=u²이면 차이에 2c(x-xs)가 추가된다. 선형 사상 뒤 차분, 또는 원신호 차분을 입력으로 받는 phi(x-xs)는 공통 가산 오프셋을 제거하지만 서로 다른 모형이다. 곱셈 이득 변화는 이들 모두에 별도 문제가 된다. 어떤 변환에 대한 불변성을 시험하는지 사전 정의해야 한다.
- **과거 측정 갱신은 저장한 과거 prediction 하나로 충분하지 않다.** 일반적인 비선형 상태천이에서는 측정시점의 사전 상태·공분산과 이후 입력을 보존하고 재전파하거나, 그에 맞는 지연측정 알고리즘이 필요하다. 단순 alpha^(t-s) 보정은 그 식이 성립하는 선형·대각 천이와 중간 갱신 조건에 한정된다. 중간 관측이 있으면 현재-과거 교차공분산 또는 정확한 재전파가 필요하다. 실제 도착 기록이 없으므로 이를 실측 지연 재현이라고 부르지 않는다.
- **새로 보인 CES 사건**은 원 측정의 식별자로 판별한다. 매 행 반복되는 held value를 새 CES 관측으로 재사용하지 않는다. 그렇다고 BES/ECEI를 이용한 매 시점 상태 갱신까지 금지하는 것은 아니다.
- **공정한 입력 비교**는 같은 feature slot 수만으로 성립하지 않는다. anchor 시점의 fast 값에 접근하는 모형은 대조군에도 같은 정보와 이력을 제공하거나, 입력 효과와 구조 효과를 나눈 실험이 필요하다. 같은 행·target support·초기화·갱신 수와 총 계산 예산을 구분해 기록한다.
- **학습된 age gate**와 수동 shrinkage는 별도 대조다. age에 따른 단조 gate 또는 age=0 제약은 선택한 가설이지 데이터가 보장하는 법칙이 아니다. 단순 GP shrinkage/selector와 비교하지 않고 short-age 위험 감소를 fast 정보 활용의 증거로 해석하지 않는다.
- **Faithful mean 보존**은 이름만 붙이면 성립하지 않는다. 평균 trunk와 head의 갱신·초기화·batch 순서·정지 시점·난수 흐름 및 optimizer 처리를 맞추고, 분산 gradient가 평균 경로에 들어가지 않게 한다. 전역 gradient clipping과 wall-clock 정지는 대응을 깨뜨릴 수 있다. 별도 mean 경로 검증이 필요하다.
- **Coverage는 관측된 보고값에 대한 경험적 coverage**다. 시계열·shot 의존성과 소수 cluster가 있는 데이터에 별도 가정 없이 distribution-free 미래 coverage를 보장한다고 쓰지 않는다. NLL도 보고 분포에 대한 평가 점수로 계산할 수 있으며, 의존성이 있다는 이유만으로 쓸 수 없는 점수가 되는 것은 아니다. 신뢰구간·일반화 주장은 별도 문제다.

현재 B94 paired skill의 양수 방향은 `b92_reduced/readout92.py:cell`의 TX/TH 순서와 `lead_checks/verify_bootstrap92.py`의 1-num/den 계산에서 교차 확인했다. 숫자의 원본 검증은 기존 final-audit gate에 둔다.
