## Information-set and validation constraints

F is a reported CES scalar, L5 is future-derived offline supervision. An optional future-informed teacher must never use TEST labels or TEST-derived configuration selection; deployment student remains causal. Its performance must be against a matched-budget, matched-input student and appropriate no-teacher/no-future-teacher controls. More dense teacher labels are not independent high-rate physical truth.

Future measured CES used as input changes the estimation information set and is a noncausal reference at the original decision timestamp. Simply passing a past timestamped sample to a model does not prove the value had arrived then. Missingness/availability replay is a constructed scenario, not measured live delay.

Do not require a new physics mechanism or a new architecture as a condition of useful research. Do not claim algorithmic novelty from a familiar component or assert that current data make new algorithms logically impossible. Evidence-value questions, estimator hypotheses and operational use cases can coexist within the author's fixed framing.

## Exact implementation semantics checked by host

`b90_methods/models90.py:DiagonalObserver._step` makes a learned pseudo-observation on EVERY nominal grid row from the entire22-slot input. Both its learned drive and observation are tanh(linear(x)); noise depends on metadata slots15:22. The continuous variant uses a=exp(-softplus(rate)*dt), prior=a*mean+(1-a)*drive, prior_variance=a²*variance+q*(1-a²), gain=prior_variance/(prior_variance+noise), followed by an innovation update towards the learned observation. The discrete variant uses one bounded diagonal transition per row. This is not an explicit newly-arrived-CES-event update, and does not replay a delayed measurement from its measurement timestamp. These statements describe code structure, not an observed performance defect. The latent drive/observation can encode history availability implicitly.

`b88_anchor/model88.py:B88Model._fuse_input` passes13 current fast inputs through shared nonlinear phi(13→32→16), applies the same phi to13 fast inputs stored at the latest visible CES anchor, multiplies the anchor embedding by has-history, and CONCATENATES current embedding, anchor embedding and7 history/time slots. Control C substitutes zero for the anchor embedding. It does not explicitly subtract the embeddings or enforce invariance to gain/offset. Parameter equality and short pilot selection do not establish all anchor mechanisms unhelpful.

`b98_physics/model98.py:matrix` uses the strictly earlier source index and exact exponential propagation from that anchor; the forcing basis subtracts the propagated source-time basis. This already provides a stable simple source-time-consistent comparator for a proposed arrival/replay or state-update model, in its registered TRAIN/internalVAL scope. Its effective relaxation coefficient is not physically identified, and extrapolating its existing internalVAL result to outer TEST would be a new experiment.

## Specific errors to challenge in the new source dossiers

The source dossiers are advisory and not authoritative. The host checked the following logical/code mismatches while they were being produced; crosswalk, design competition and adversarial review must address them.

- The completed fusion dossier suggests mixed anchor-dropout/age-inflation training as if distinct. Mixed-availability training already underlies B85/B92/B94, and pooled availability was evaluated in B84. An actually different corruption intervention would have to specify what new mechanism is varied. A monotone age-response is not implied by information nesting or by finite trained-model risk.
- State information does NOT imply the fast increment against L5 is at least that against F. Genuine fast physical variation may predict F and be removed by the L5 median; future evolution, report noise and selection can all change this relation. F-only benefit does not identify report artifact, and L5-only benefit does not identify physical truth.
- Better performance from past-window features versus a point snapshot does NOT alone identify aliasing. Averaging noise, changing features, unequal sample support or genuine exposure mismatch may explain it. The size/power of the raw subset has not been quantified here; call precision unknown, not underpowered as a fact.
- The implemented B90 DiagonalObserver does NOT have merely a fixed/scheduled gain. It propagates learned latent variance and computes gain from an input-dependent observation variance EVERY row. Its actual difference from a proposed filter is explicit event/source-time semantics, factorized state structure and other precisely stated constraints, not the mere existence of learned gain.
- A multimodal filter may update from current BES/ECEI even when no new CES report appears. Forbidding ALL state updates without a CES arrival throws away available fast observations. Distinguish a newly visible CES update from fast-input drive/pseudo-observation and from ordinary time propagation.
- With delayed CES, a CES update at original measurement time requires a source-time state and replay/sufficient-statistic construction; do not apply the old value as a current physical state observation or pretend real arrival logs exist. Fixed source-age replay remains a constructed scenario. The simple B98 anchor-propagation comparator already handles its registered source-time rule explicitly.
- A learned innovation variance can be trained/evaluated for reported targets without per-frame spectroscopy error labels. It is not automatically calibrated and does not identify physical Ti uncertainty. Distinguish these questions.
- Failed superiority is not equivalence; CI overlap is not a direct effect test. Failure of a noninferiority lower-bound criterion is not evidence of inferiority. Cross-target and cross-support contrasts need separately defined estimands and paired resampling where appropriate; no automatic cross-design cluster intersection.
