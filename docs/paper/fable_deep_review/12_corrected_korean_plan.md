# KSTAR 페데스탈-톱 CES nowcast: 최종 연구 메모 (이전 메모 대체)

적합·실행·TEST 판독은 하지 않았습니다. 위치 표기는 전달받은 조사서와 호스트 확인을 승계한 것이며, 이번에 원문을 다시 대조하지는 않았습니다. 태그: [S] 원문·코드 확인(호스트 확인 포함), [A] 저자 주장, [H] 적용 가설, [U] 미확정.

## 0. 결론

1순위는 **원천시각 일관 1차 강제 필터**, 2순위는 **CES 갱신 의미론(사건 대 매 행) 대조**, 3순위는 **보고값 수준 예측분포**입니다. 세 프로그램 모두 단순 모형을 먼저 읽고, 학습 모형은 B104 판독 뒤에 조건부로 엽니다. B98 V3의 악화와 B104 예산 불확실성은 설계를 제약하지만, 추정기 연구를 막는 근거는 아닙니다.

## 1. 정정된 판단과 문헌 근거

**이전 메모에서 바뀐 판단**

1. **TS2Vec 코드는 [S]입니다(E6 철회).** `zhihanyue/ts2vec`@b0088e1의 `ts2vec.py:encode`는 기본값이 causal=False, sliding_length=None입니다. 오른쪽 문맥 제한은 sliding 분기에만 있습니다. causal=True 인자 하나나 chunk 전체 출력 사용으로는 시점별 미래 차단이 보장되지 않으므로, 배포 경로의 prefix 불변성 검사가 필요합니다. 논문 손실은 양측 crop 문맥입니다 [S: https://arxiv.org/abs/2106.10466 pp.3–4].
2. **부호는 확인됐습니다.** B94 쌍대 skill은 `readout92.py:cell`의 TX/TH 순서와 `verify_bootstrap92.py`의 1−num/den으로 양수 방향이 교차 확인됐습니다. 따라서 짧은 D의 음수는 TX가 TH보다 나쁘다는 뜻으로 읽힙니다. 패킷에 행 배열이 없다는 사실은 저장소에 쌍대 기준선 증거가 없다는 뜻이 아닙니다. 공통지지 판독은 등록할 새 작업입니다.
3. **비선형 차분은 오프셋을 상쇄하지 않습니다.** φ(u)=u²이면 2c(x−x_s)가 남습니다. 선형 사상 뒤 차분과 φ(x−x_s)는 가산 오프셋을 제거하지만 서로 다른 모형이고, 곱셈 이득은 별개 문제입니다.
4. **지연 갱신에는 저장한 예측 하나로 부족합니다.** 원천시각의 사전 상태·분산과 이후 입력을 보존해 재전파해야 합니다. α^{t−s} 보정은 선형·대각 천이이고 중간 갱신이 없을 때만 정확합니다. 지연 식과 fresh-anchor 수축은 구성상 fast 정보를 입증하지 못합니다.
5. **B90 관측기에는 부정적 증거가 없습니다.** 이미 입력 의존 이득을 매 행 계산합니다 [S: `models90.py:DiagonalObserver._step`]. 제안 필터와의 차이는 사건·원천시각 의미론뿐입니다. CES가 도착하지 않아도 fast로 상태를 갱신하는 것은 허용됩니다.

**1차 문헌**

- **RKN:** 공식 셀은 기본 `never_invalid=True`라서 유효 마스크를 무시합니다 [S: https://arxiv.org/abs/1905.07357 §2.4 p.5; `rkn_cell/RKNCell.py::RKNCell.forward`, https://github.com/ALRhub/rkn_share @7cb29e1].
- **CRU:** 무효 시 사전 상태를 유지합니다 [S: https://arxiv.org/abs/2111.11344; `lib/CRUCell.py::RKNCell._update`, https://github.com/boschresearch/Continuous-Recurrent-Units @79723e7].
- **KalmanNet:** 원 KalmanNet만 f/h 기지를 요구합니다 [S: https://arxiv.org/abs/2107.10043 §II-B p.3; `KNet/KalmanNet_nn.py::KNet_step`].
- **Faithful:** 평균이 MSE 해와 일치합니다 [S: https://arxiv.org/abs/2212.09184 Eq.5, Thm 1, p.4]. 단, 구현 통제가 있어야 성립합니다.
- **β-NLL:** 평균을 바꿉니다 [S: https://arxiv.org/abs/2203.09168 Eq.3–9; D.5 p.24].
- **GD:** https://arxiv.org/abs/1511.03643 Eq.4 p.3; Exp.6 p.8.
- **RTCAKENN:** PCS에서 최신 유효값을 재사용합니다 [S: https://doi.org/10.1088/1741-4326/ad142f PDF p.4–6]. 실제 PCS 구현이므로, 배포가 없는 본 연구와 구별합니다.
- **COMPASS:** 방전 단위 분할과 교차검증을 씁니다 [S: https://doi.org/10.1088/1361-6587/ae72c6 p.5–6]. 시간순 외부 캠페인 검증은 [U]입니다.
- **Diag2Diag:** 느린 진단을 ffill로 정렬합니다 [S: https://arxiv.org/abs/2405.05908 Methods; https://doi.org/10.5281/zenodo.16748363].

## 2. 과학 목표 5개

1. 동일 행에서 hold, 인과 GP, GP+부스팅 대비 각 추정기의 쌍대 손실 차를 4개 설계에서 동등하게 확정한다.
2. 원천시각 계약에서 CES 이력과 NBI를 넘는 fast 증분을 fast-only/NBI-only로 분리한다.
3. 짧은 연령의 TX 결손이 갱신 의미론, 원시 전압의 비전이, 예산 중 무엇과 양립하는지 가른다(원인 식별은 아님).
4. 보고값 예측분포의 경험적 품질이 age·flag·이력을 넘어 fast로 개선되는지 본다.
5. 명목 10 ms 격자 계약의 실제 의미(노출·도착·결측 사유)와 스텝당 계산 시간을 측정 가능한 범위에서 확정한다.

## 3. 공통 규칙

- **입력과 표적.** 입력은 엄격히 과거인 CES 앵커/age/flag, 현재·과거 BES9/ECEI4 원시 전압, NBI입니다. 표적은 F와 L5(오프라인 라벨)이며, F/L5 비교는 공동 적격 행에서만 합니다. D 규칙은 구성된 시나리오이고 예측 지평이나 실측 지연이 아닙니다.
- **Estimand.** 설계×규칙×표적별 샷-클러스터 쌍대 손실 차를 MSE와 MAE 모두로 냅니다. 공통지지와 선택모집단을 둘 다 보고하고, FULL15와 FOUR는 따로 표시합니다.
- **다중성과 마진.** 4개 설계를 동등한 1차 계열로 두고, 다중성 보정 방식과 종합 주장 규칙을 등록문에 고정합니다. 마진 δ는 운영 허용오차나 내부 VAL hold−GP 쌍대 격차의 등록 분율로 정합니다. 사후적인 "N개 설계 이상" 임계는 쓰지 않습니다.
- **판정.** 양성은 보정 구간이 −δ를 넘는 경우입니다. 음성은 등록된 ±δ 안에 구간이 들어온 경우에 한하며, "이 모형군·계약에서 증분이 마진 이내"라고만 씁니다. 그 밖은 미해결입니다. 미해결은 비용상 중단 사유가 될 수 있지만, 정보 부재나 동등성의 증거는 아닙니다.
- **TEST와 확증.** 재사용 TEST는 등록 후 1회만 읽고 탐색적으로 표기합니다. 미접촉 캠페인이 없으므로 확증은 계수를 동결한 채 향후 캠페인이나 사전 봉인 방전에서만 가능합니다. 동결 적합 구간은 적합·선택 불확실성을 빼고 있음을 명기합니다.

## 4. 프로그램 3개 (순위순)

### P1. 원천시각 강제 필터와 기준선 쌍대

- **가설 [H].** fast-only 강제가 이력-only(H)와 NBI-only보다 손실을 낮추고, 치환하면 그 차이가 사라진다.
- **표준인 것.** 1차 완화, 강제항, hold/ffill(RTCAKENN, Diag2Diag).
- **새 실증 질문.** B98은 F 전용, TRAIN/내부 VAL 범위이고 M이 fast와 NBI를 합쳐 넣습니다. 새 요소는 강제항 분리, L5, 4개 설계의 외부 TEST, 기준선과의 동일 행 쌍대입니다. 과제·증거 구분일 뿐 알고리즘 신규성 주장이 아닙니다.
- **단순 모형.** ŷ_t = e^{−a/τ}y_s + (1−e^{−a/τ})μ + θᵀ[B_t − e^{−a/τ}B_s] (`model98.py:filter_basis`, `matrix`). 공통 가산 오프셋 c는 (1−e^{−a/τ})θᵀc만큼 남습니다. 완전 상쇄는 정적 차분 L에서만 일어나므로, 두 팔은 서로 다른 불변성 가설로 등록합니다.
- **조건부 학습 모형.** B104 판독 뒤, 같은 계약에서 스칼라 잠재와 비선형 구동 d(x)를 씁니다. φ(x_t−x_s) 팔과 연결 팔은 별도로 둡니다.
- **팔과 공정성.** H, M_fast, M_NBI, M_both, L, fast 치환, hold, 인과 GP, GP+부스팅.
  - 선형 팔끼리는 같은 행, 같은 τ 격자와 정칙화 경로를 쓰고 TRAIN 통계만 씁니다.
  - 앵커 시점 fast 값에 접근하지 않는 TX/TH와의 대비는 "정보집합 상이"로 표기합니다. 슬롯 수가 같다고 정보가 같은 것은 아닙니다.
  - 학습 팔은 초기화, 업데이트 수, 총 계산을 맞추고, 수렴 기준에 미달한 팔은 "예산 제한"으로 둡니다.
- **선택.** τ와 정칙화는 내부 VAL에서 정해 동결합니다.
- **보존할 불리한 증거.** B98 V3 내부 VAL에서 M이 H보다 나빴습니다(군집 중첩 0). 원시 전압 구조의 비전이 가능성으로 등록하고, 재현 여부를 설계별로 봅니다.
- **결과 해석.** 양성이면 학습 단계를 엽니다. 음성이면 선형 계열의 증분이 마진 이내이므로 원고는 hold/GP/GP+부스팅을 주 nowcast로 쓰고 "이 계약·모형군에서 미검출"로 적습니다. 미해결은 그대로 보고합니다.
- **자원과 중단.** CPU만 쓰며 소요 시간은 [U]입니다. 선형이라 샷 재표집 재적합으로 적합 불확실성을 포함할 수 있습니다 [H]. TEST 이후 재탐색은 금지합니다. 스텝당 추론 시간은 측정값만 보고합니다.

### P2. CES 갱신 의미론: 사건·재전파 대 매 행

- **가설 [H].** 새로 가시화된 보고(원 측정 식별자로 판별)만 그 원천시각 상태에 반영하고 재전파하면, hold 값을 매 행 재관측하는 쌍둥이보다 손실이 낮다.
- **표준인 것.** 마스크 갱신(CRU), Kalman 갱신(RKN §2.4). 지연측정 재전파의 1차 출처는 받지 못해 인용하지 않습니다.
- **새 실증 질문.** B90은 매 행 의사관측이고 미실행이며, B98에는 분산이 없습니다. 사건 대 매 행의 단일 스위치를 격리한 대조는 기존 작업에 없습니다.
- **단순 모형.** 선형 스칼라 필터입니다.
  - 전파: z⁻ = αz + (1−α)(μ+θᵀx), P⁻ = α²P + q(1−α²).
  - 보고 가시화 시: 이전 보고가 모두 반영된 원천시각의 (z⁻_s, P⁻_s)를 복원해 갱신하고, 저장 입력으로 s→t를 정확히 재전파합니다. 저장된 갱신 전 디코드는 재사용하지 않습니다.
- **조건부 학습 모형.** B104 뒤에 B90형 학습 이득 관측기에 같은 스위치를 넣습니다. 비선형 모형에서는 α 지름길을 쓰지 않고 전 구간을 재실행합니다.
- **팔.**
  - 주 스위치: 사건+재전파 대 매 행 hold-채움.
  - 부 스위치: fast를 구동으로만 쓰는 팔 대 매 행 의사관측으로 쓰는 팔. 후자는 재전파 때 fast 갱신도 다시 수행합니다.
  - 대조: zero-fast 쌍둥이와 fast 치환. 수축 게이트 γ는 넣지 않습니다.
- **해석 제한.** 사건 팔의 단기 개선은 의미론 효과입니다. fast 증분은 같은 의미론 안의 fast 대 zero-fast/치환 대비로만 읽습니다. 단기 결손은 같은 TEST에서 선택된 패턴이므로 0으로의 회귀를 "수리"로 읽지 않습니다.
- **계약 검사.** 시점 k 이후 입력을 교란해도 출력이 불변인지 검사합니다. D 규칙에서 대기 보고가 생기는지는 [U]입니다.
- **선택.** q, r(flag), α는 내부 VAL에서 정합니다.
- **결과 해석.** 양성이면 원고의 융합 추정기에 사건 의미론을 채택합니다. 음성이면 의미론 차이가 마진 이내이므로 단순한 쪽을 택합니다. 미해결은 중단할 수는 있어도 기각은 아닙니다.
- **자원.** 선형 단계는 CPU입니다. 긴 D의 재전파 비용과 10 ms 충족 여부는 미측정입니다.

### P3. 보고값 수준 예측분포

- **가설 [H].** fast 입력이 이력-only 분산 모형을 넘어 보고값 산포를 예측한다.
- **표준인 것.** Faithful(Stirn)과 β-NLL(Seitzer).
- **새 실증 질문.** B90-N은 평균을 바꾸는 결합 NLL이고 미실행입니다. 평균을 고정한 채 fast가 분산에 주는 증분은 다뤄진 적이 없습니다.
- **단순 모형.** 동결한 GP+부스팅 평균 위에서 교차적합한 TRAIN 잔차로 분산을 모형화합니다(in-sample 과소추정 회피). 팔은 B0 상수, B1 age×flag 표, B2 이력-only(주 대조), fast 추가입니다. 모든 팔에 같은 내부 VAL 재보정을 적용합니다.
- **조건부 학습 모형.** B104 뒤에 TCN 위 faithful 헤드를 씁니다.
  - 항등 게이트 조건: 초기화, 배치 순서, 난수 흐름, 업데이트 수 기준 정지, MSE 체크포인트가 같아야 합니다. 분산 gradient는 평균 경로에서 차단하고 전역 클리핑은 쓰지 않습니다.
  - 평균 궤적이 MSE 쌍둥이와 수치적으로 일치해야 합니다.
  - 게이트에 실패하면 "동결 평균 순차 변형"으로 명시해 대체합니다.
- **평가.** NLL(정당한 예측 점수), 구간점수, 층별 경험적 포함률을 씁니다. 불확실성은 샷-클러스터 쌍대 재표집으로 따로 다룹니다. 분포무관 보장은 주장하지 않습니다.
- **결과 해석.** 양성 표현은 "이 캠페인에서 fast가 보고 산포를 예측"까지입니다. 음성 표현은 "이 헤드군에서 증분이 마진 이내"입니다. σ̂를 맞춤 잡음, 플라즈마 변동, 벌크 Ti 불확실성으로 읽지 않습니다.
- **자원.** 단순 단계는 CPU이고, 학습 단계는 FOUR 시드당 1회입니다. 소요 시간은 [U]입니다.

## 5. 보류 2개

- **D1. 인과 fallback 선택기.** 현 TEST에서는 관측된 부호표를 재진술하는 데 그칩니다. P1의 쌍대표와 독립 데이터가 생긴 뒤 다룹니다.
- **D2. 특권정보 학습과 인과 사전학습.** B104 전에는 예산 효과와 분리되지 않습니다. CES 정보 교사가 모두 중복이라고 가정하지 않고, 대조를 정확히 등록합니다.

  - B87은 같은 학습기의 입력 정보집합을 바꾼 참조이므로 이와 다른 질문입니다.
  - TS2Vec형 인코더는 sliding 인과 경로의 prefix 검사를 통과해야 합니다.
