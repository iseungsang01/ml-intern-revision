# KSTAR 페데스탈-톱 CES nowcast: 다음 연구 메모

적합·실행은 하지 않았습니다. 성능 수치는 전달받은 요약의 인용이며, 익명 집계 패킷을 직접 대조하지 못했습니다. 태그: [S] 직접 읽은 원문·코드, [A] 저자 주장, [H] 적용 가설, [U] 미확정.

## 0. 결론

다음 연구 대상은 **원천시각(source-time) 일관 1차 강제 필터 계열**입니다. 선형 B98 계열을 fast/NBI로 분리해 먼저 읽고, 조건이 충족될 때만 사건 게이트 스칼라 잠재 필터로 넘어갑니다. 병행 가치가 있는 것은 평균을 건드리지 않는 **보고값 수준 신뢰도(faithful 분산 헤드)**입니다. 새 대형 구조(S4/Mamba/SSL)는 적용 가능하지만, B104 판독 전에는 예산 효과와 분리되지 않습니다.

## 1. 이전 조사 대비 정정 5건

1. **B90 계열에 대한 부정적 증거는 없습니다.** 감쇠 GRU, 관측기, Huber, Student-t, Gaussian은 B92에서 비용·관련성 사유로 보류됐을 뿐입니다. `models90.py::DiagonalObserver._step`은 이미 매 행에서 분산을 전파하고 입력 의존 이득을 계산합니다. 따라서 제안 필터와의 차이는 "학습 이득"이 아니라 사건·원천시각 의미론과 스트림 분해입니다.
2. **마스크 계약은 구현마다 다릅니다 [S].**
   - RKN 공식 셀은 기본 `never_invalid=True`라서 `obs_valid`를 무시합니다.
   - CRU는 무조건 마스킹합니다.
   - 원 KalmanNet만 f/h 기지와 상태 라벨을 요구하며 마스크가 없습니다.
   - 스텝 단위 마스크 하나로는 매 스텝 존재하는 BES/ECEI와 간헐적인 CES를 함께 다룰 수 없습니다.
3. **이전 Program A 수식에는 오류가 있습니다.**
   - 저장된 갱신 전 디코드로 혁신을 계산하면, 보고가 여러 건 대기할 때 같은 오차를 반복 보정합니다. α=1, K=1, 대기 10건이면 최종 오차가 −9e입니다. D 규칙이 실제로 대기 보고를 만드는지는 [U]입니다.
   - 비선형 φ(x_t)−φ(x_s)는 오프셋을 상쇄하지 않습니다.
   - 앵커가 엄격히 과거이므로 γ(0)=0은 실현되지 않는 제약이고, 단조 γ는 GP 쪽 수축으로 "단기 개선"을 만들어 냅니다.
   - fast가 구동항으로만 들어가면 이득은 age·flag의 결정적 스케줄입니다. 적응 이득이라고 부르면 안 됩니다.
4. **Faithful 손실의 평균은 MSE 쌍둥이와 항등입니다 [S: Stirn Thm 1].** 평균 이득은 원리상 0이고, 기여는 분산뿐입니다. 항등성을 지키려면 [H] 업데이트 횟수 기준 정지(현 1200 s 벽시계 상한은 위반), 동일 배치·난수 흐름, 헤드 간 클리핑 금지, MSE 기준 체크포인트가 필요합니다. β-NLL은 평균을 바꾸므로 제외합니다.
5. **문헌과 패킷의 위치를 다시 잡아야 합니다.**
   - COMPASS는 방전 단위로 분할했습니다 [S].
   - Diag2Diag 공개 스크립트는 방전 인덱스로 분할하지만 더미 데이터로 돌아가므로 실제 파이프라인은 [U]입니다.
   - RTCAKENN은 유효 TS 없이 PCS에서 동작했습니다 [S]. 다만 표적 진단의 보고 간 staleness 대비 오차를 정량화한 출처는 셋 중 없습니다.
   - 패킷에는 TX/TH와 hold/GP 사이의 동일 행 쌍대 대비가 없습니다.
   - FULL15와 FOUR는 중첩 관계이므로(V4a 값 일치) 독립 재현이 아닙니다.
   - "L5 증분 ≥ F 증분", "창 특징이 낫다 = 앨리어싱", "부분집합 검정력 부족"은 모두 철회합니다.

## 2. 과학 목표 5개

1. 동일 행에서 hold/인과 GP/GP+부스팅 대비 각 추정기의 쌍대 차이를 확정한다(원고의 핵심 질문).
2. 원천시각 일관 계약에서 CES 이력과 NBI를 넘는 fast 진단 증분이 있는지 V1~V4a 각각에서 본다.
3. 짧은 원천 연령에서 융합이 해로운 패턴이 갱신 계약, 원시 전압 수준의 비전이, 예산 중 무엇과 양립하는지 판별한다. 원인 식별은 아니다.
4. 보고값 분산이 age·flag·이력을 넘어 예측되는지 본다.
5. 명목 10 ms 격자 인과 계약의 실제 의미(노출창, 도착 시각, 결측 사유)와 스텝당 계산 시간을 확정한다.

### P1. 선형 원천시각 강제 필터 사다리 + 기준선 쌍대표

| 항목 | 내용 |
|---|---|
| 가설 | 엄격히 과거인 원천 인덱스 계약에서 fast-only 강제가 이력-only(H)와 NBI-only보다 보고값 예측 손실을 낮추고, 치환 대조에서는 사라진다. |
| 최근접 선행 | Diag2Diag: CER을 ffill하고 fast ECE로 TS 추정(Methods "Feature extraction", `extract_features`의 `reindex(…, 'ffill')`). RTCAKENN: 최신 유효값 hold(§3, PDF p.6). 1차 완화와 강제항은 표준이다. |
| B73~104와의 차이 | B98은 F 전용, TRAIN/내부 VAL, 4단위이고 M이 fast와 NBI를 함께 넣는다. 새 요소는 강제항 분리, L5, 4개 설계, 외부 TEST, hold/GP와의 동일 행 쌍대뿐이다. |
| 최소식 | ŷ_t = e^{−a/τ}y_s + (1−e^{−a/τ})μ + θᵀ[B_t − e^{−a/τ}B_s]. B는 `model98.py::filter_basis`, 원천 인덱스는 `::matrix`. |
| 계약 | 입력은 과거 CES 앵커/age/flag와 현재·과거 BES9/ECEI4 원시 전압, NBI. 표적은 F와 L5(오프라인 라벨). 명목 스탬프이며 D 규칙은 예측 지평이 아니다. |
| 팔과 대조 | H, M_fast, M_NBI, M_both, L(정적 앵커 차분), fast 치환. 저장 예측에 행 ID가 있으면 hold, 인과 GP, GP+부스팅, TX/TH. 동일 행, 동일 τ 격자와 정칙화 경로, TRAIN 통계만 사용. |
| TRAIN/VAL | τ와 정칙화는 내부 VAL에서 정하고 동결한다. |
| TEST와 확증 | 재사용 TEST 1회 판독, 탐색적. FULL15와 FOUR는 별도 표시. 확증은 계수를 동결한 채 새 캠페인이나 사전 봉인 방전에서 1회 판독. |
| Estimand | 설계×규칙×표적별 Δ = 손실(M_fast) − 손실(비교군)의 샷-클러스터 평균. MSE와 MAE 모두, 음수가 유리. 공통지지와 선택모집단 둘 다 보고. |

| 양성 | H와 NBI-only 대비 구간 상한이 2개 이상 설계에서 −δ 미만이고 치환 시 소실. P2로 진행. |
| 음성 | fast-only와 NBI-only의 차이 구간이 ±δ 안에 들어오거나, V3형 군집 외 악화가 재현. 비선형 확장 중단. |
| 불확정 | 구간이 0과 ±δ에 걸침. "미해결"로 보고하며 동등이 아니다. |
| 자원과 중단 | CPU, 소요 시간 [U]. TEST 이후 τ·특징 재탐색 금지. |

### P2. 사건 게이트·재계산 혁신 스칼라 필터

진입 조건은 P1 양성과 B104 판독 완료입니다.

| 항목 | 내용 |
|---|---|
| 가설 | CES 갱신을 새로 가시화된 보고에만, 그 원천시각 상태에 적용한 뒤 현재까지 재전파하면, 매 행 갱신 쌍둥이보다 짧은 연령 손실이 낮고 긴 연령 증분은 유지된다. |
| 최근접 선행 | CRU `lib/CRUCell.py::RKNCell._update`(무효 시 사전 유지), `lib/CRULayer.py::CRULayer.forward`(갱신 후 예측). RKN PDF p.5 §2.4 Eq. 4–7, `rkn_cell/RKNCell.py::RKNCell.forward`. 마스크 갱신은 표준이다. 지연 측정 재전파는 교과서적이지만 1차 출처가 제공되지 않아 인용하지 않는다. |
| B73~104와의 차이 | B90 관측기는 22슬롯 전체로 매 행 의사관측을 하고 미실행이다. B88은 연결, B98은 선형이다. 새 요소는 사건 대 매 행 단일 스위치와 비선형 구동뿐이다. |
| 최소식 | 스칼라 z, h=1(대각 근사 문제 회피). 전파: z⁻ = αz + (1−α)d(x), P⁻ = α²P + q(1−α²). 보고 y_s 가시화 시: ν = y_s − z_{s∣이전 보고 모두 반영}, K = P⁻_s/(P⁻_s + r(flag)), 이후 저장된 fast 입력으로 s→t 개루프 재전파. ŷ_t는 F_t 사용 전에 디코드. |
| 계약 | P1과 같다. 재전파는 구성된 시나리오이며 실제 도착 지연은 아니다. k 이후 입력을 교란해도 출력이 비트 동일한지 등록 검사한다. |
| 대조(단일 스위치) | 매 행 hold-채움 갱신 쌍둥이, 선형 구동(=P1 M_fast), zero-fast 이력 쌍둥이, 치환, NBI-only. 수축 인공물을 피하려고 γ 게이트는 넣지 않는다. 동일 행, 동일 업데이트 횟수, 등록 수렴 기준. 미달 팔은 "예산 제한"으로 표기하고 비교하지 않는다. |
| TRAIN/VAL | 잠재 차원 1은 사전 고정. 정지와 학습률은 내부 VAL. |
| TEST와 확증 | FOUR 3시드 1회, 탐색적. 단기 결손 패턴 자체가 같은 TEST에서 선택됐으므로 0으로의 회귀가 "수리"처럼 보일 수 있다. 주 대비는 쌍둥이 간 대비다. 확증은 P1과 같다. |
| Estimand | 등록된 연령 층별 Δ = 손실(사건) − 손실(매 행), 그리고 손실(사건) − 손실(P1 선형). |
| 양성 | 단기 층 상한이 −δ 미만이고 장기 층 상한이 +δ 미만(비열등 제안). |
| 음성 | 비선형이 선형 P1을 넘지 못함. 선형을 채택한다. |
| 불확정 | 그대로 "미해결"로 보고. |
| 자원과 중단 | 갱신은 원소별 연산이다 [A: RKN §2.4]. 10 ms 충족 여부는 미측정이고, 긴 D에서 재전파 비용이 추가된다. 5팔×4단위×3시드, 구조 탐색 없음. |

### P3. 보고값 수준 신뢰도: faithful 분산 헤드

| 항목 | 내용 |
|---|---|
| 가설 | fast 입력이 이력-only 분산 헤드를 넘어 보고값 분산을 예측한다. |
| 최근접 선행 | Stirn Eq. (5), Thm 1, p.4. 대조로 Seitzer Eq. 7 p.5, App. D.5 `beta_nll_loss` 12–17행. 모두 표준이다. |
| B73~104와의 차이 | B90-N은 결합 NLL이라 평균이 바뀌고 미실행이다. 기존 강건 손실 선별은 평균 대상이다. |
| 최소식 | L = ½(y−μ)² − log N(y; ⌊μ⌋, σ²(⌊trunk⌋)), 선정된 TCN 위에 적용. |
| 게이트 | 점예측이 MSE 쌍둥이와 허용오차 내에서 일치해야 한다. 실패하면 판독 무효이고, "동결 평균 순차 변형"으로 명시해 대체한다(Stirn p.3). |
| 대조 | B0 상수 분산, B1 age×flag 표, **B2 이력-only 헤드(주 대조)**, head(fast). 모든 팔에 같은 내부 VAL 분위 재보정. 공통지지 행. |
| Estimand | 샷 수준 쌍대 구간점수 차(10/90, 25/75), head(fast) − B2, 음수가 유리. 층별 분포무관 포함률. L5는 공동 적격 행에서 병렬 표시만 하고 차분 해석은 하지 않는다. |
| 양성 | 상한이 −δ 미만. "fast가 이 캠페인 보고 분산을 예측"까지만 말한다. |
| 음성 | B2와 차이가 ±δ 안. 분산은 이력 장부다. |
| 불확정 | "미해결". |
| 자원과 중단 | FOUR에서 시드당 1회. 직렬 상관 때문에 우도와 ECE는 기술 통계다. |

## 4. 보류 2개

- **D1 인과 fallback 선택기(감시 시나리오).** 현재 TEST에서는 관측된 부호표의 재진술입니다. Stage 0에서 always-GP 팔이 정의되고 독립 데이터가 생긴 뒤에 다룹니다.
- **D2 인과 사전학습과 미래-fast 교사.** B104 전에는 예산과 교락됩니다. 정확한 조건부평균 교사라면 E[t|P]=E[y|P]이므로 이득은 유한표본 분산 감소로 한정됩니다. GD 자체 증거도 라벨 있는 점에만 증류하면 이득이 없었습니다(Exp. 6, p.8). 선행 단계로 의미 있는 것은 "미래 fast 입력" 단일 게이트뿐입니다.

두 보류 모두 불가능하다는 판정이 아닙니다.

## 5. 권고 추정기 계열

**권고는 앵커 기준 원천시각 1차 강제 필터(P1 선형 → P2 스칼라 사건 필터)입니다.**

- **진행 조건:** 부호와 지표 확인, fast-only가 NBI-only를 넘음, 치환 시 소실, B104가 단기 결손을 예산 인공물로 돌리지 않음.
- **No-go:** NBI-only가 fast-only와 마진 내에서 같음, 치환 후에도 증분 유지, V3형 악화가 TEST에서 재현, 동일 행에서 L이나 인과 GP를 넘지 못함. 이 중 하나면 원고는 hold/GP/GP+부스팅을 nowcast로 제시하고, fast 증분은 "이 계약에서 미검출"로 적습니다.
- **단순 모형 대비:** L(정적 앵커 차분)과 인과 GP가 항상 같은 행의 쌍대 비교군입니다. 학습 필터가 이들을 넘지 못하면 단순 모형을 택합니다.

**보존할 불리한 증거(전달 요약 기준):**

- TX−TH가 짧은 D에서 음수입니다(부호 관례 [U]).
- B98 V3에서 M이 H보다 나쁩니다.
- L의 MAE가 대부분 셀에서 더 낮습니다(주변값 판독이며 쌍대 검정이 아님).
- V1 D1000에서 MSE와 MAE의 결론이 엇갈립니다.
- 확증 적합 46건 중 38건이 예산 제한입니다.
- 파일럿에서 T가 더 많은 업데이트를 받았습니다.

## 6. 예측 경로와 물리 주장의 분리

- **현 데이터로 가능한 주장:** "명시된 행 모집단에서 탄소 CES 보고값 또는 그 전방 중앙값을 예측한다"까지입니다. P1~P3은 모두 이 범위 안입니다.
- **추가 측정이 필요한 주장(요청 가능):**
  - 진단 담당자와 만드는 CES 프레임 출처표: 노출과 도착 시각, 결측 사유, χ²와 수렴 여부, warm-start 여부. 필요성의 근거는 Bishop pp.765–768, 772이며 JET 사례입니다.
  - 짝지은 UFCES.
  - 평형과 ECEI 매핑.
  - 국소 흡수 파워.
  - 고속 원시 부분집합(정밀도 [U]).
- 이들 없이는 σ̂, F−L5, F 전용/L5 전용 증분을 맞춤 잡음, 플라즈마 변동, 벌크 Ti로 읽지 않습니다.

## 7. 즉시 가능한 한 단계(적합 없음)

Stage 0 등록문과 저장 예측 목록을 작성합니다.

- B73/75/84/94/98별로 행 ID가 있는 저장 예측이 있는지 확인합니다.
- 쌍대값의 부호와 지표 정의를 확인합니다.
- D 규칙에서 대기 보고가 생기는지 확인합니다.
- hold/GP/GP+부스팅/TX/TH의 동일 행 쌍대표 양식을 MSE와 MAE, 두 estimand로 정합니다.

행 ID가 없으면 이 표는 P1의 등록된 재적합에 포함시킵니다.

## 8. 출처와 접근 한계

URL은 공개 식별자로 재구성했고 이번에 접속해 검증하지 않았습니다. 위치 표기는 제공 PDF와 고정 커밋 기준입니다.

- RKN: https://arxiv.org/abs/1905.07357 (p.5 §2.4, §2.6); https://github.com/ALRhub/rkn_share @7cb29e1
- CRU: https://arxiv.org/abs/2111.11344; https://github.com/boschresearch/Continuous-Recurrent-Units @79723e7
- KalmanNet: https://arxiv.org/abs/2107.10043 (p.3 §II-B); https://github.com/KalmanNet/KalmanNet_TSP @828a2cf, `KNet/KalmanNet_nn.py::KNet_step`
- Stirn: https://arxiv.org/abs/2212.09184 (Eq. 5, Thm 1, p.4)
- Seitzer: https://arxiv.org/abs/2203.09168 (Eq. 3–9, pp.3–5; D.5, p.24)
- TS2Vec: https://arxiv.org/abs/2106.10466 (pp.3–4)
- GD: https://arxiv.org/abs/1511.03643 (Eq. 4, p.3; Exp. 6, p.8)
- Diag2Diag: https://arxiv.org/abs/2405.05908; https://github.com/PlasmaControl/Diag2Diag-SRTS @7e938a3
- URL 미확인이라 서지로만 표기: RTCAKENN(Nucl. Fusion 64 026006), COMPASS(PPCF 68 065049), Bishop(PPCF 35 765–773).

**한계:**

- 코드가 행 번호 없이 제공되어 Seitzer D.5 외에는 줄 번호를 제시하지 못합니다.
- Diag2Diag는 본문 텍스트만 받았습니다. 그림, 보충자료, 샷 목록은 없습니다.
- TS2Vec, Stirn, Seitzer, GD의 공식 저장소는 받지 못했습니다. 따라서 `ts2vec.py::encode` 기본값 주장은 [U]로 낮춥니다.
- 선행연구 검색은 하지 않았으므로 선행 기술의 부재나 신규성은 추론할 수 없습니다.
- 문헌 접근은 이 데이터에서의 성능을 보장하지 않습니다.

호스트가 확인한 B88/B90/B98 구현 의미론은 완료된 후속 확인으로서 증거로 썼습니다.
