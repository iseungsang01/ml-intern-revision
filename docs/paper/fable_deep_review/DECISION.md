# 원문·공식 코드 심화 조사 후 연구 방향

이 문서는 작업자가 Fable의 분야별 검토, 반박, 정정 및 마지막 지연측정 문헌 검토를 종합한 판단이다. API 원문을 수정하지 않고 보존했다. 전체 실험 계약은 `12_corrected_korean_plan.md`, 마지막 우선순위 수정은 `13_delayed_measurement_source_addendum.md`, 별도 구현 확인은 `METHOD_CHECKS.md`를 함께 읽는다. 아직 새 실험의 등록문이나 성능 결과가 아니다.

## 달라진 핵심 판단

**큰 모델을 더 비교하는 것보다, CES 기준시점과 fast 입력의 관계를 분명히 한 작은 추정기 계열을 먼저 조사하는 것이 타당하다.** 기존 TCN 결과와 B98의 불리한 내부 검증 결과를 보존하면서, 선형 기준선에서 시작하고 학습 구조는 조건부로 확장한다.

기존 B90 observer·Huber·Student-t·Gaussian 계열은 완료된 작은 pilot에서 평가되지 않았다. 등록·구현·보류를 실험적 탈락으로 읽었던 이전 판단은 철회한다. 완료된 pilot의 A/C/T 비교도 고정된 짧은 시간 예산 안의 선택이지 수렴한 구조의 최종 비교가 아니다. B104의 별도 예산 연구와 중복 실행하지 않는다.

가까운 핵융합 선행연구에도 방전 단위 검증과 실제 PCS 구현이 있다. 따라서 '멀티모달', '진단 간 융합', '방전 단위 분할', '빠른 추론'만을 차별점으로 제시할 수 없다. [RTCAKENN](https://doi.org/10.1088/1741-4326/ad142f) PDF p.4–6, [COMPASS](https://doi.org/10.1088/1361-6587/ae72c6) PDF p.5–6, [Diag2Diag 출판본](https://doi.org/10.1038/s41467-025-63492-1) 및 [공식 코드](https://doi.org/10.5281/zenodo.16748363)를 대조했다. 이들의 대상·입력·검증은 서로 다르므로 CES 성능으로 전용하지 않는다.

마지막 문헌 확인 결과 **사건 갱신·과거 상태 재전파 자체도 표준 방법**이다. 이를 독립 기여로 내세우는 P2는 P1의 구현·대조 실험으로 합친다. [Koch 등](https://doi.org/10.1177/0278364920903094) §4.3은 버퍼 복원과 입력·관측 재처리의 구현 근거이며, [Mina 등 v2](https://arxiv.org/abs/2508.21260v2) §II와 §VII는 지연상태 문제 및 선형 조건의 동치 관계를 설명한다. 로봇 분야 근거가 CES에서의 효과를 보장하지 않는다.

## 과학 목표

1. 같은 평가 행에서 hold·인과 GP·GP+부스팅과 후보 추정기의 차이를 비교한다.
2. CES 이력과 NBI를 조건으로 했을 때 BES·ECEI의 추가 예측 가치를 분리한다.
3. 기준시점 처리와 특징 표현의 제약이 설계 간 성능 차이를 줄이는지 조사한다.
4. 평균 오차와 별개로, 관측된 CES 보고값의 예측분포를 평가한다.
5. 계산시간 및 가용 시각 계약을 명시하고, 실제 운용에 필요한 추가 기록을 구체화한다.

## 우선 프로그램 세 개

| 순위 | 연구 가설과 최소 비교 | 진행·중단 판단 |
|---|---|---|
| 1. 기준시점에 맞춘 강제응답 추정기 | 기존 B98의 작은 선형 계열을 이력-only, fast-only, NBI-only, 둘 다로 나누고 정적 차분·hold·GP·부스팅과 같은 행에서 비교한다. 사건 갱신과 재전파는 이 계열 안의 부팔이다. CES를 반복된 독립 관측으로 잘못 세는 대조군에만 유리한 비교를 만들지 않는다. | fast가 이력과 NBI를 조건으로 추가 정보를 주는지 직접 비교한다. 등록한 범위에서 해상도가 충분하면 작은 학습 잔차/필터로 확장한다. 불리한 결과와 미해결 결과를 구분해 남긴다. |
| 2. 보고값 예측분포 | 고정 평균 위의 상수 분산, age/flag 표, 이력-only 분산, fast 추가 분산을 비교한다. 먼저 교차적합 잔차를 쓰는 작은 모델로 시작하고 필요하면 faithful TCN 헤드로 확장한다. | 같은 평균과 같은 평가 행에서 NLL·구간점수·경험적 포함률을 비교한다. fast가 이력-only 분산보다 유용한지 본다. 평균 보존 검사를 실패하면 faithful이라는 이름으로 결과를 해석하지 않는다. |
| 3. 동결 인과 표현 탐침 | TRAIN fast 신호만으로 사전학습한 동결 인코더, 동일 구조의 무작위 동결 인코더, 원시 특징을 같은 선형 하류 모델에 연결한다. 치환 대조와 배포 경로의 미래 차단 검사를 포함한다. | 원시 특징의 비전이와 양립하는 현상이 표현 변경으로 줄어드는지 시험한다. 단순 추가 계산량·비선형 특징 확장과 구별할 수 없으면 해석을 제한한다. GPU 필요 여부와 사전학습 비용은 아직 미측정이다. |

세 번째는 마지막 추가 검토에서 축소 승격한 조건부 후보다. 원시 특징 팔을 본 뒤 무등록으로 실행하지 않는다. 별도 등록에서 같은 입력·support·하류 적합 예산뿐 아니라 **총 사전학습 비용**과 이에 대응하는 scratch/추가 학습 대조도 정한다. 무작위 동결 인코더만으로 계산 예산 효과까지 제거했다고 주장하지 않는다. B104는 TCN의 학습 예산 질문이며 이 SSL 대조를 대신하지 않는다. 짧은 전압 신호를 어떤 augmentation으로 변형해도 된다는 가정도 두지 않는다.

[Faithful regression](https://proceedings.mlr.press/v206/stirn23a.html) Eq.5·Thm.1과 [TS2Vec](https://arxiv.org/abs/2106.10466) §3은 표준 구성요소다. TS2Vec 공식 `encode`의 causal 인자 하나만으로 온라인 인과성이 보장되지는 않는다(`PRIMARY_CHECKS.md`). 세 프로그램의 가치는 익숙한 방법 이름이 아니라, 현재 CES 계약에서 아직 분리하지 못한 질문을 공정한 비교로 답하는 데 있다. 이것이 출판 가능한 차별점인지에 대한 판단은 결과와 추가 문헌 대조 뒤에 남는다.

## 보류한 선택지

- **상황별 GP/fast 추정기 전환:** 고정 규칙을 TRAIN/VAL에서 정하는 운용 시나리오로 가능하다. 같은 TEST의 관측된 부호표를 다시 학습한 것을 운용 검증으로 부르지 않는다.
- **특권정보 교사·증류:** CES 기반 교사를 모두 중복이라고 배제하지 않는다. leave-k-out 교사, 과거-only 교사, 무교사, 단순 미래 보간 표적을 구분해야 한다. 표적 복사와 선택 누출을 막고, 학생의 총 계산 예산을 맞춘 뒤 검토한다.

## 판단과 해석의 고정점

손실 차이는 후보−비교군으로 정의한다. 음수가 후보에 유리하며, 사전 정의한 다중성 처리 후 구간 **상한이 −δ보다 작은 경우**를 해당 마진을 넘는 감소로 판단한다. δ는 운영 근거나 사전에 정한 내부 VAL 기준으로 정하며 이번 조사에서 숫자를 제안·확정하지 않는다. 우월성 미확인은 동등성이 아니다. 마진 안의 결과도 해당 모형군·조건의 결론이며 데이터에 정보가 없다는 증명은 아니다.

F와 L5는 다른 표적이고 적격 행도 다르다. 같은 행 집합에서 비교하는 경우와 각 표적의 원래 모집단을 기술하는 경우를 나눈다. 네 검증 설계를 모두 보고하며 FULL15 단일 seed와 FOUR 다중 seed를 독립 재현으로 합치지 않는다. 재사용 TEST에 근거한 모든 새 방향은 탐색적이다. 확증에는 사전에 봉인한 새 관측이 필요하다.

예측분산은 CES **보고값의** 분산이다. F−L5나 학습된 분산만으로 물리적 이온온도·분광 적합 잡음을 분리할 수 없다. 실제 노출·처리·도착 기록이 없으므로 source-age 시나리오는 실측 통신 지연 재현이 아니다.

## 다음에 구체화할 일과 조사 종료

다음 작업은 Stage 0 등록문 초안과 저장 예측의 메타데이터 목록이다. 평가값을 새로 읽지 않고 행 ID와 사용 가능한 비교군을 확인해, 같은 support의 비교표 및 최소 P1 실행 범위를 정한다. 이 보고서는 새 적합·GPU 실행·TEST 재평가를 시작하지 않았다. 진단 담당자에게 필요한 출처표는 요청 항목으로만 정리했으며 외부 메시지를 보내지 않았다.

이번 추가 조사에서 Fable 생성 요청은 12건이고, 출력 한도에 도달한 원래 3건도 비용과 원문을 보존했다. 완결한 좁은 후속 요청으로 대체하고 별도 반박·정정까지 마쳤다. 반환된 사용량과 공식 공개 단가 기준 추가 추정액은 **USD 19.134768**이며 미확정 예약액은 0이다. 이전 조사 비용·세금·계정 할인은 포함하지 않았고 청구서 대조 금액이 아니다. 단순 소진을 위한 추가 호출 없이 USD30 상한 안에서 종료했다. 상세는 `cost_ledger.json`, 완료·gate hash는 `status.json`에 있다.

NN-CES 전문은 여전히 확보하지 못했다. 후보군 전체의 선행 기술 부재를 증명한 조사는 아니며, API의 각 응답이 '이번 요청에서 직접 검색하지 않았다'고 쓴 부분은 전체 작업의 검색 여부와 구별한다. 작업자는 앞선 검색 및 이번 원문·공식 코드 확인을 수행했으며, 마지막 합성 요청은 제공된 자료를 검토하는 방식이었다.
