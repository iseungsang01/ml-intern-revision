# B.75 — the estimate when the CES history is as old as it really is

Registered: `ces_prediction/experiments/PREREGISTRATION_B75.md`; implementation choices in `ces_prediction/experiments/PREREGISTRATION_B75_ADDENDUM1.md`, written before any readout. CPU only; no network trained or run. T_i, cut population, the D1 rows of B.70 as cached by B.73 (222,672 rows, 635 discharges). Exploratory on used data (registration section 1): the rows, targets, designs and learners are those of B.73; the availability rules and the anchor inputs are new.

**Rule S assumes zero analysis time**: a value becomes visible as soon as the next beam-off frame has been taken. This favours every estimator under S.

Conventions. Skill of A over B = 1 - SSE(A) / SSE(B) on identical rows; MSE reduction in % = 100 x skill. Increment = TX over T0 under the same rule on the same rows. Each comparison: point, then 95 % intervals with discharges resampled (d) and with shot clusters resampled (c), 20,000 draws (V1: a re-partition drawn first; V2: an assignment drawn first; V3, V4: the scored units). Verdicts on the cluster form. Points under V1 and V2 = mean over the three re-partitions or assignments. Fixed-delay rules (D10 ... D1000) are fitted and scored on the common set, rule S and the D10 history beside it on the S set. RMSE in eV. Checks: `docs/paper/b75_checks.md`.

Order of work. Before this readout, these results existed: the five checks of registration section 9 and the counts of the row sets. No MSE, skill or statement under any rule had been computed.

## Limits (registration section 11, unchanged)

- Exploratory on used data. The anchor scalars are new inputs chosen before any readout; TX8 beside TX shows what they do.
- Rule S assumes the beam-modulation analysis with zero computation time. A reader of the frame's own spectrum would give another availability; no such values exist for these discharges.
- The history values are the offline product in every rule.
- The following level is built from reported values; a bias of the analysis that lasts 50 ms or more is in the target too. R11 is about scatter around the level, not about a systematic error of the diagnostic.
- The fixed-delay rules drop the first second of every block (the common set).
- One estimator per rule is fitted. An estimator fitted once for all ages is not part of this batch; the rows 'applied without refit' bound it from one side.
- V4 is one block of about 95 discharges; V3c is informative for fifths 2 and 3 only.
