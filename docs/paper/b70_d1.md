# B.70 — one data definition (D1): phase 1

Registered: ces_prediction/experiments/PREREGISTRATION_B70.md (with Addendum 1). CPU only; nothing trained except the registered refit of the B.64 second stage. T_i, cut population, re-partitions r2-r4 of the pooled cross-validation (15 test folds). Rows: every eligible row of `evaluate.build_clean_val_subset` (no random cap, `CES_MAX_VAL_SAMPLES=0`): T_i measured and withheld, the previous kept row carries T_i, every reference defined; every estimator of a table on the same rows. Skill of A over B = 1 - sum of squared errors of A / that of B. Point = mean over r2-r4; 95 % two-level interval (a re-partition drawn, then its test discharges resampled), 20,000 draws. Checks: `docs/paper/b70_checks.md`.
