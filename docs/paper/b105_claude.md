# B105 completed Fable post-evaluation advice

작업자 독립 확인: 이 API 요청은 일부 고정 overview를 제공했으므로 아래 “32개”는 전체 TEST 셀 수가 아니다. 원본의 현행 estimator 대비 TEST는64셀이고 점추정은 모두 음수다. 구간·판정 원본은 b105_merit.json/md이며 별도 audit512쌍을 통과했다. “실용적 이점은 없다”는 조언은 현재 후보의 교체 merit 미입증으로 한정한다. 운용 지연/상태 메모리 이득은 이번에 측정하지 않았다. 원인 분해나 TCN 일반의 열등성이 증명된 것은 아니다. 다음 게이트 재설계 제안은 아직 실행하지 않았고 원래 판정 기준을 소급 변경하지 않는다.

## 결론

현 incumbent 대비 실용적 이점은 없습니다. 후보(TCN35)는 VAL 자원 게이트는 통과했지만(S1), TEST에서는 우월성(S2)과 −0.05 여유의 비열등성(S3) 모두 성립하지 않았고, 측정된 운영상 이득도 없습니다. incumbent를 유지하는 것이 맞습니다.

부호는 수치로 확인했습니다. point = 1 − MSE(TCN35)/MSE(비교 대상)이므로 음수는 후보의 오차가 더 크다는 뜻입니다.

## VAL 스크리닝 (게이트일 뿐, 추론 아님)

- 네 유닛 모두 평균 정규화 MSE 비율이 0.97~1.03으로 통과했습니다. V2는 1.035로 후보가 오히려 약간 나빴습니다.
- 통과는 집계 평균 덕분이었습니다. D650에서 후보가 +0.06~+0.22 좋았고(V1·V3·V4는 대체로 0 제외, V2는 불확실), 이것이 D10의 열세(−0.10~−0.24, 대부분 0 제외)를 상쇄했습니다. S는 불확실했습니다.
- 즉 D10 열세는 VAL 단계에서 이미 보였습니다.
- 체크포인트 선택과 할당이 같은 VAL에서 이루어져 낙관 편향이 있으므로, 게이트 통과를 통계적 비열등성으로 읽을 수 없습니다.

## TEST (incumbent outer-fit 대비)

- **전체:** 32개 점추정이 모두 음수이며(−0.002~−0.416), 64개 구간 중 하한이 0을 넘는 것은 없습니다.
- **D10:** 4개 유닛, F·L5 모두 두 구간 방식에서 0을 제외하는 열세입니다. V1·V2는 약 −0.16~−0.19, V4는 −0.18~−0.33, V3는 −0.32~−0.42입니다.
- **D650:** VAL의 이득이 재현되지 않았습니다. 점추정은 −0.002~−0.16이고 대부분 0을 포함하며, V3의 F만 유의한 열세입니다.
- **K10·S:** 모두 음수 방향입니다. 일부는 0을 제외하고(V2 K10 F, V4 K10 F, V2 S, V1 S L5), 나머지는 불확실합니다.
- **공정 specialized 대비:** 같은 패턴이므로, 새 트리의 적합 방식 차이(내부 TRAIN만 사용, 조기 종료 없음)가 주된 원인으로 보이지는 않습니다.
- **기존 TEST의 TCN22 대 B84 mixture:** L5에서 12개 중 10개가 유의한 열세였습니다(V1 K10, V4 S는 불확실). V2와 F는 자료가 없어 판단하지 않습니다.

## 해석의 한계

- **아키텍처 열등성 결론 불가:** 35채널·3600초와 22채널·1200초는 입력, 파라미터, 시간 예산이 함께 다릅니다. 설계당 유닛 하나, 초기화 하나(seed 1701)뿐이어서 설계 전체나 초기화에 대한 일반화도 할 수 없습니다.
- **새로운 물리 주장 불가:** F와 L5는 센서에서 유도된 서로 다른 보고 대상이지 독립적인 물리적 참값이 아닙니다. 두 타깃의 일치를 독립적 재현으로 세면 안 됩니다.
- **구간의 범위:** 고정 적합 기준의 점별 구간이라 재적합, 선택, 초기화, 다중성 불확실성이 빠져 있습니다. 개별 셀 수준의 "발견"은 주장하지 않으며, 탐색적 결과입니다.
- **추가 적합 자동 실행 금지:** 이 실패가 seed 추가, 재학습, 재튜닝을 자동으로 정당화하지 않습니다. 후보 TEST는 이미 열람되었으므로, 이후 조정은 모두 TEST 정보에 오염된 것으로 취급해야 합니다.

## 다음 우선순위 (하나)

새 적합 없이 기존 VAL 산출물만으로 게이트를 사전 등록 방식으로 재설계하는 것입니다. 집계 평균 대신 타깃별(특히 D10) 하한 조건을 두어, 이번처럼 VAL에서 이미 보인 열세가 평균에 가려져 TEST까지 가는 일을 막습니다.
