# 잔차 진단 뒤의 실행 순서

근거는 [독립 검산한 B110 표](b110_residuals.md)와 대응 JSON이다.
방법 이름을 추가하기 전에 예측 오차와 비교 절차를 작은 문제로 나눈다.
현재 목적은 그대로 pedestal-top CES 보고값의 causal nowcasting이다.

## 이번 진단으로 좁혀진 것

- raw LSTM의 전체 VAL MSE는 TCN35보다 모든 설계에서 작았고 군집
  구간도 영을 제외했다. raw LSTM이 쓸모없다는 결론은 내릴 수 없다.
- 같은 전체 VAL에서 raw LSTM의 MSE는 B105 fair specialized GP+fast
  대조보다 컸고 군집 구간도 영을 제외했다. 따라서 LSTM 자체를
  최종 estimator로 선택할 근거는 아직 부족하다.
- TCN35와 fair specialized 대조의 손실 증가 방향은 이력 변화가
  작은 층과 큰 층 모두에서 나타났다. 관측된 차이를 급변 구간만의
  실패로 묶고 hard rule을 추가할 근거가 없다.
- 편향과 중심화 MSE를 분리해 보존했다. 한 방향의 평균 오차를
  보정하는 것만으로 전체 차이가 해소된다고 가정하지 않는다.

이력 변화 층은 TRAIN에서 고정한 abs(GP-hold) 기준이다. 실제 온도
급변의 정답 라벨이 아니다. VAL 선택 낙관성, 서로 다른 학습 표적/가용
혼합/예산을 유지해 해석하며, 통제된 architecture 비교로 부르지 않는다.
이번 진단에는 LSTM 후단, 지연 시나리오 TEST, 진단별 입력 제거 비교가 없다.

## 다음 필수 작업: 완료된 학습을 비교 결과로 연결

새 본 모델 학습에 앞서 별도 완전한 Colab 평가 실행을 등록한다.
이 작업은 기존 B106 목적을 완성하는 것이며 B110을 TEST로 확대하지 않는다.

1. 확보한 selected checkpoint와 원래 manifest/statistics를 묶고,
   내부 학습 파일을 제외한 OOF 예측과 외부 평가 예측을 구분한다.
2. 원래 D10 후단과 사전 고정 scenario-mixture 후단을 OOF 예측으로만
   적합한다. 외부 VAL/TEST를 후단 fitting에 넣지 않는다.
3. 같은 F 행에서 raw LSTM, 두 후단, TCN, GP/hold, 이력-only GP 보정,
   fast 포함 GP 보정의 MSE를 먼저 비교한다. 모든 가용 시나리오와
   검증 설계를 함께 보고, paired 구간과 독립 감사를 완료한다.
4. checkpoint나 후단이 빠지면 최종 merit 미완료로 명시한다. 진행
   수치나 raw LSTM VAL 결과로 2단계 estimator의 최종 결과를 대신하지 않는다.

CPU 직렬화/원모델 prefix 확인/회수 후 독립 검산만 로컬에서 수행하고,
추론과 후단 fitting은 Colab에서 한다. 로컬 GPU 중단은 유지한다.
기존 학습을 다시 시작하거나 새 후보 여러 개를 자동 배정하지 않는다.

## 그다음 연구를 결정할 작은 질문

| 질문 | 필요한 대비 | 이후 선택 |
|---|---|---|
| 기존 LSTM 후단이 남은 오차를 설명하는가 | raw 대 OOF 후단, 같은 외부 행 | 보정으로 충분하면 새 backbone보다 완전한 검증을 우선 |
| GP 기준을 보존하면 신경망의 잔차 학습이 달라지는가 | 같은 입력/표적/예산의 직접 회귀 대 GP+작은 잔차, 강한 boosting 대조 포함 | 남은 차이가 확인될 때만 최소 후보를 새 등록 |
| fast가 이력과 NBI 너머의 정보를 주는가 | H,H+fast,H+NBI,H+NBI+fast, 동일 지원 | 조건부 추가 정보를 확인한 뒤 작은 강제응답식 검토 |
| BES와 ECEI 중 무엇이 필요한가 | 같은 학습기에서 진단별 제거 | 유효 입력을 줄이고 역할을 해석; 이번 B110만으로 판단하지 않음 |

기존 B73/B79/B81 등의 대비를 먼저 대조해 이미 답한 것을 중복 적합하지
않는다. GP+boosting, residual 연결, soft conditioning 자체는 표준 요소다.
성능 결과와 기존 방법의 차이를 별도로 검증하며, 보고값 예측으로 물리
참값·수송 계수·가열 인과효과를 식별했다고 해석하지 않는다.

Claude API는 저자의 사용 불가 지시에 따라 호출하지 않았다. 이 문서는
새 fitting 허가를 대신하지 않으며 후속 실행에는 그에 맞는 사전등록이 필요하다.
