# B115 그림과 모델 개선 실행 계획

기존 S/V1 구간이0에 가깝다는 이유만으로 실패 또는 데이터 개수 문제라고 단정하지 않는다. 많은 행이 같은 방전·군집에 묶여 있고 모델별 오류가 군집마다 다를 수 있으므로 직접 그림으로 확인한다.

1. 기존예측 점검: S의 네 검증 설계에 점추정·95%구간·행/방전/군집 수를 나란히 표시하고 군집별 paired 오차 차이를 그린다. 실제 방전 하나의 보고값과 GP+fast·후보 예측도 시간순으로 그린다. 표시할 방전은 성능이 아닌 지원 행 수로 고른다. 기존 구간은 변경하지 않는다.
2. 모델 개선 비교: B114에서 이미 선택한 신경망 구조·직접/잔차형·세 초기화를 유지한다. 기존48학습은 모두patience8로9~41epoch에 끝났으므로, 새12학습은 조기 종료 없이300epoch 또는300초까지 학습하고80/160/240epoch에 학습률을 낮춘다. 원래 학습의 초기 경로가 재현되는지 확인한다. 최적 체크포인트는 각 설계 자체VAL만 사용한다.
3. 검산과 보고: 전체12학습 정상종료 뒤32조건을 평가한다. 기존·연장 모델에 같은 군집 재표집을 적용하고 실제 구간 너비비와 초기화 산포를 모두 보고한다. 더 학습했다고 독립 TEST군집이 늘어나는 것은 아니며 구간 축소를 보장하지 않는다.

GPU는 한 개에서 순차 실행, 원래 모델 재학습/변경 없음. GPU단계는 최초 실행부터2시간, CPU검산은 그 뒤30분까지 경계를 둔다. 추가 후보·재시도 없이 부분 결과와 실패를 보존한다. 직전 ClaudeAPI 인증오류 기록을 유지하며 새 검토 완료를 주장하지 않는다.
