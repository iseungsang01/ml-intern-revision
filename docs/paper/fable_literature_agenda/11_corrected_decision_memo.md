# 페데스탈-톱 CES 나우캐스팅: 교정 결정 메모

계획이며 새 결과가 아닙니다. 새 검색·적합은 없었고, 기존 스크리닝·예산 기록은 제가 직접 보지 못했습니다. 미공개·구 수치는 싣지 않습니다.

**고정 목적:** 과거 앵커 조건부 페데스탈-톱 나우캐스트에서 hold/GP/보간 대비 가장 유용한 추정기, 고속 진단 증분, 네 설계 병렬 보고, 10 ms 계산 예산을 다룹니다. 응용 시연은 부가 증거입니다. stale CES는 한 조건 축이지 논문의 줄거리가 아닙니다.

## 1. 철회하는 주장

1. "구간이 겹치면 대조와 구별되지 않는다"(E1). 별도 구간의 겹침은 차이 없음의 증거가 아닙니다.
2. "차이 구간이 0을 포함하면 목표 정의에 견고"(E2). 동등성 근거가 아닙니다.
3. "다른 설계에서 유의한 손해가 없으면 운용상 유용"(E3). 비열등성이 아닙니다.
4. 과거 전용 표준화와 절대 수준 제거를 새 실험처럼 제시한 것. `seq_data.py`의 `expanding_standardize`와 현행 B84(TXrel, TXall, raw-window 대조)가 이미 있습니다.
5. "RKN/CRU는 전제가 성립하지 않는다". 둘은 잠재 동역학을 학습하므로 기술적으로 적용 가능합니다. 알려진 f/h 전제는 KalmanNet에만 해당합니다. S4/Mamba/자기지도도 10 ms 자료에서 동작합니다.
6. "현 자료로는 경험적 기여만 가능하다". 불가능성은 증명되지 않았습니다. 현재 증거가 알고리즘 신규성을 입증하지 못할 뿐입니다.
7. "1회 판독 후 비유의면 종료"식 중단. 비유의는 효과 없음이 아닙니다.
8. "결론을 바꾸는 것은 실험이 아니라 자료뿐". 예측 가설은 현 실자료의 실험·분석으로도 바뀔 수 있습니다.
9. "읽은 다섯 편 어디에도 시간순 홀드아웃이 없다"를 문헌 일반의 부재처럼 쓴 것. 부분 열람 범위에서 확인하지 못했다는 뜻에 그칩니다.
10. 이전 철회(임의 문턱, 단조성 정리, gain/offset 해석, L5/F 이득의 물리 판정)는 유지합니다.

## 2. 실험 목표

- **O1.** hold/GP/보간 대비 나우캐스트 기량과 고속 증분이 짝 대조와 구별되는가.
- **O2.** 서열·증분이 목표 정의(F, L5)와 행 선택에 얼마나 민감한가.
- **O3.** 시간순 설계의 열화가 무엇과 대응하는가(대응이지 원인이 아님).
- **O4.** 소군집·다중성 아래 어떤 진술이 남는가(효과 있음, 동등, 미결을 구분).
- **O5.** 10 ms 계산 예산과 응용 시연은 종단 지연 주장 없이 유지.

## 3. 계열 결정과 조건부 다음 단계

| 계열 | 결정 | 다음 고려 조건 |
|---|---|---|
| 1. 짝 증분 귀속 재분석 | 실행(E1) | — |
| 2. 목표·선택 감사 | 실행(E2) | — |
| 3. 시간순 열화: 중복 지도 후 대응 분석 | 실행(E3) | 지도에 빈 칸이 있을 때만 재적합 제안 |
| 4. 소군집 추론(군집 재표집, 무작위화) | E1–E3에 내장 | 손실차에 대한 타당성은 가정으로 명시 |
| 5. 보고값 기준 보정·coverage·selective | 보류 | E2에서 목표 의존성이 확인되면 보고값 불확도 질문으로 승격 |
| 6. 학습형 잠재 필터(RKN/CRU, GRU-D) | 보류(우선순위 사유) | E1의 짝 대비가 특정 나이 층에서 양이고, observer/decay GRU/grey-box 스크린이 그 가설을 다루지 않았을 때 |
| 7. S4/Mamba/자기지도(10 ms 자료) | 보류(우선순위 사유) | 긴 과거 문맥이 증분을 바꾼다는 과제 특이 가설이 TCN/raw-window 기록으로 반박되지 않을 때 |
| 8. 고속 원자료 감사, 스펙트럼 NN, UFCES 교사 | 새 측정 필요 | 별도 사전등록 |

- 6·7에서 조건이 충족되면 GPU 적합을 제안할 수 있습니다. 승인, 사전등록, 기존 스크린과 동일 예산의 비교가 전제이며 지금은 착수하지 않습니다.
- KalmanNet은 f/h가 없어 원형대로는 부적합합니다.
- 새 방법은 반증 가능한 과제 특이 가설과 기존 스크린 중복 감사를 통과해야 "신규"로 부를 수 있습니다.

## 4. 실험 3건

**공통 규약**
- 입력은 과거 CES 앵커·나이·플래그와 현재·과거 BES9/ECEI4 스냅숏뿐입니다.
- 부호는 Δ = 손실(비교군) − 손실(후보)로 정의하며, 양수가 기량 이득입니다.
- 구간은 같은 행에서 군집을 함께 재표집한 짝 구간입니다.
- 층·여유폭은 TRAIN/내부 VAL 변동에 근거해 제안하고 사전등록에서 고정합니다. 값은 여기서 정하지 않습니다.
- TEST 재사용이므로 결과는 탐색적이며, 독립 확증은 추후로 남습니다.
- 네 설계를 병렬 보고합니다.
- 구간 폭을 항상 보고하고, 표본 충분성은 주장하지 않습니다.

### E1(1순위). 짝 증분 귀속
- **가설:** 원천 나이 층별로, 고속 증분(fast-added-to-NBI 대 NBI, fast-added 대 history)이 commonality·permutation 대조 증분보다 크다.
- **중복:** 지연-정확도 곡선과 각 대조는 이미 있습니다. 추가되는 것은 같은 행의 짝 결합 판독으로 예상되며, 인벤토리로 확인합니다.
- **비교군:** hold, 인과 GP, history 쌍둥이, NBI, 대조들. 미래 사용 보간은 참조선입니다.
- **판정:** 추정량은 C = Δ(고속) − Δ(대조)의 행별 짝 차이입니다. C의 구간이 0을 양으로 배제하면 "대조를 넘는 예측 증분"과 부합합니다. 인과 주장은 아닙니다.
- **반증:** C의 구간 전체가 0 미만인 경우, 또는 사전등록한 동등 여유폭 안에 전부 들어가는 경우. 0을 포함하고 여유폭을 벗어나면 미결로 보고합니다. 미결은 동등이나 교란의 근거가 아닙니다.
- **자원:** 저장된 행 예측과 군집 ID. 적합은 없습니다.
- **중단:** 판독 후 층을 재정의하지 않습니다. 미결이면 정밀도 한계를 기술하고 끝냅니다. 행 예측이 없으면 재적합 승인을 따로 요청합니다.

### E2(2순위). 목표·선택 감사
- **가설:** hold 대비 기량과 증분의 결론이 F와 L5에서, 그리고 전체 F 행과 L5 유효 행에서 실질적으로 같다.
- **추정량:** 각 목표 안에서 같은 목표의 hold 손실로 정규화한 상대 기량을 구하고, 이를 공통 행 교집합에서 목표 간 짝 차이로 비교합니다. F와 L5의 원 라벨을 같은 물리 참값으로 비교하지 않습니다. L5는 미래 유래 감독입니다. 선택 효과는 F 목표에서 전체 행과 L5 유효 행을 따로 대비합니다.
- **중복:** 칸별 F/L5 값은 있습니다. 교집합 짝 대비가 있었는지는 확인하지 못했습니다.
- **비교군:** hold, GP, 쌍둥이.
- **판정:** 짝 구간 전체가 사전등록한 동등 여유폭 안에 있으면 "여유폭 내 동등"입니다.
- **반증:** 구간 전체가 여유폭 밖에 있으면 목표 의존입니다. 그 외는 미결입니다.
- **자원:** 저장된 예측과 플래그. 적합은 없습니다.
- **중단:** 잡음·과정 분산 분해는 하지 않습니다. 목표 의존이면 목표별로 분리 보고합니다.

### E3(3순위). 시간순 열화: 중복 지도 → 대응 분석 → 조건부 쌍둥이
- **가설:** 시간순 설계의 열화가 입력 주변분포·가용성 변화와 함께 움직이며, 과거 전용 정규화 변형이 시간순 손실을 줄이고 다른 설계에서는 비열등하다.
- **중복(1단계, 필수):** `expanding_standardize`와 B84의 TXrel, TXall, raw-window가 어떤 자료·특징·모델·설계 칸을 이미 덮는지 지도로 만듭니다. 수치는 인용하지 않습니다. 덮인 칸은 기존 현행 결과를 재판독만 합니다.
- **비교군:** 기존 fast-added와 history 쌍둥이. 계산시간에 전처리를 포함합니다.
- **판정:** 시간순 설계에서 Δ의 구간이 0을 양으로 배제하고, 나머지 설계에서 구간 하한이 사전등록한 비열등 여유폭(−m)보다 위에 있으면 "이득 + 비열등"입니다. 여유폭을 두지 않으면 설계별 손익을 그대로 보고합니다.
- **반증:** 시간순 Δ의 구간 전체가 0 이하인 경우, 또는 비열등 하한을 위반한 경우. 그 외는 미결입니다. 원인(gain/offset, 플라즈마, CES 변화)은 식별하지 않습니다.
- **자원:** 1단계와 기술 통계는 적합이 없습니다. 빈 칸에 대한 CPU 재적합 1건은 승인·사전등록 후에만 합니다.
- **중단:** 빈 칸이 없으면 재적합 없이 대응 분석만 보고합니다.

## 5. 즉시 할 일(1건)

수치를 판독하지 않고 중복·인벤토리 표를 만듭니다. 이 표가 E1–E3의 실행 가능성, 사전등록 초안, "신규" 표기 여부를 정합니다.

- 추정기·대조·설계·목표별 행 예측의 존재 여부
- 같은 행 교집합과 군집 ID
- 스크린 번호·예산
- `expanding_standardize`와 B84가 덮는 범위
- 파일 해시

## 6. 한계

- **새 측정이 필요한 주장:** 벌크 이온 참값, 물리 인과, 종단 지연, 캠페인 간 일반화. 원시 스펙트럼, 피팅 불확도, 짝 UFCES, 지연 로그, 독립 캠페인이 있어야 합니다.
- **현 실자료로 평가 가능한 것:** 보고값 기준의 예측 가설(E1–E3와 조건부 계열).
- **유지하는 것:** 음수 칸, seed 간 부호 반전, 예산 제한 적합, grey-box의 내부 VAL 한정은 원고에 남깁니다. 네 설계의 병렬 보고도 유지합니다.
