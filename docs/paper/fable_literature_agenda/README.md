# Fable 선행연구 조사와 실험 목표 검토

저자 요청에 따라 선행연구를 먼저 조사하고, 최신 감사 결과 및 PPCF 심사 지적과 대조해 실험 목표·시나리오·모델 계열을 검토한다. 모든 API 단계는 공식 Claude Fable을 사용한다. 새 학습·GPU 실행·TEST 재채점은 하지 않는다.

## 읽는 순서

1. `11_corrected_decision_memo.md`: 작업자가 발견한 통계 판정 오류·기존 표준화와의 중복을 교정한 최종 탐색적 계획. `10_final_research_agenda.md`는 이 교정 전 원본으로 보존한다.
2. `09_primary_text_audit_INCOMPLETE.md`: 원문 감사 응답은 출력 한도에서 잘렸다. 완결된 보고로 쓰지 않고, `HOST_SOURCE_CHECKS.md`의 정정과 최종 계획을 함께 읽는다.
3. `HOST_SOURCE_CHECKS.md`: 작업자가 별도로 확인한 주요 원천과 판정 한계.
4. `01_ces_measurement.md`부터 `06_use_and_validation.md`: 분야별 검색 근거표. 각 문헌의 전문/초록/발췌 접근 수준을 반드시 함께 읽는다.
5. `07_overlap_audit.md`와 `08_prioritized_agenda.md`: 원문 추가 확인 전의 중간 종합이며 최종 계획보다 우선하지 않는다.

아직 생성되지 않은 파일은 진행 중인 단계이며 완료된 산출물이 아니다. 최종 완료는 `status.json`의 `final_plan`과 실제 파일 존재를 함께 확인한다.

## 범위와 기록

여섯 분야는 CES 분광·계측, 가상 진단, 다중 속도/지연 관측기, 표적 잡음/선택 편향, 시간순 변화/표현 학습, 실제 사용과 검증이다. 분야별 다섯 회 이하 검색을 허용하고, 중간 종합 두 회·원문 감사 한 회·최종 계획 한 회로 시작했다. 이후 구간 겹침·동등성 판정 오류와 기존 표준화 중복을 발견해 교정 한 회를 추가했다. 전체 열한 회로 제한하며 실패·불완전 응답·불확실 과금 시도를 보존하고 무작정 재전송하지 않는다. API 응답과 요청은 local ignored cache에 남고, `api_audit.json`에 반환 모델·사용량·검색 질의·출처 URL·response hash를 기록한다.

`primary_text_manifest.json`은 실제 제공한 원문 PDF page 범위와 원본 hash를 식별한다. 접근한 원문 전체의 재현이나 모든 세부 가정의 검증을 뜻하지 않는다. 원문 PDF/XML 자체는 git에 넣지 않는다. 전문을 확보하지 못한 문헌은 초록·검색 수준의 한계를 그대로 남긴다. Diag2Diag와 Jalalvand 논문은 같은 계보이며, 기존 key Imrek의 실제 저자는 Imrisek임을 확인했다.

Fable의 문헌 해석과 적용 제안은 자문이며 검증된 새 결과가 아니다. 신경망 이름 교체를 새로운 원리로 제시하지 않고, 현재 데이터에서 구분할 수 있는 경쟁 설명과 최소 반증 실험을 우선한다. 기존 TEST를 읽은 이후 제안은 탐색적이며 실행 전에 별도 사전등록과 독립 확인이 필요하다. 기존 종결 배치와 물리 가정을 논문에 새로 확립된 사실처럼 넣지 않는다.
