# 조사 결과를 사용할 때의 결정 메모

공식 Fable API로 여섯 분야의 실제 검색을 수행하고, 중복 감사·예비 계획·원문 감사·계획 수정·통계 교정을 받았다. 문헌 검색은 실제 30회다. paid response 11건 중 원문 감사 한 건은 출력 한도에서 잘려 불완전으로 보존했고, 나머지 단계는 end_turn으로 완료했다. 이 횟수는 서로 독립적인 논문 수나 전문 열람 수가 아니다.

먼저 [교정된 Fable 계획](11_corrected_decision_memo.md), [작업자 원천 확인과 정정](HOST_SOURCE_CHECKS.md), 필요하면 분야별 보고를 읽는다. 원문 감사가 불완전하므로 그 응답의 완료나 문헌 전수 전문 검토를 주장하지 않는다. 읽은 source 범위는 manifest에 기록했다.

## 우선 연구 목표

1. **빠른 진단의 예측 증분이 어떤 조건에서 대조를 넘어서는가.** 현재 estimator와 NBI·commonality·permutation 대조를 같은 행의 직접 paired contrast로 검토할 수 있는지 먼저 확인한다. 별도 CI 겹침이나 유의성 변화만으로 판정하지 않는다.
2. **현재 보고값 F와 미래 유래 L5, 그리고 선택된 채점 행이 결론에 어떤 영향을 주는가.** 목표·행 선택을 분리하고, 동등성은 사전등록한 실질적 margin과 구간 전체로 판단한다. 독립 참 온도의 검증으로 바꾸어 읽지 않는다.
3. **시간순 열화를 이미 다룬 실험과 아직 빈 비교는 무엇인가.** 기존 과거 전용 표준화, B.84의 TXrel/TXall/raw 대조를 먼저 지도화한다. 학습 예산 문제는 별도 B.104 등록과 연결해 중복하지 않는다. 관측된 변화만으로 계측 변화와 실제 상태 변화를 식별하지 않는다.

현재 Fable의 모델 계열 우선순위는 무조건 새 backbone을 고르는 것이 아니다. 기존 TCN/observer/decay GRU/grey-box가 다루지 못한 구체적 가설이 남으면 **학습형 잠재 필터 RKN/CRU 또는 조건부 residual update**를 후보로 본다. 긴 과거 문맥의 역할이 실제로 미해결이면 **작은 SSM/S4 계열·자기지도 표현**을 그 가설에 대응하는 비교로 검토할 수 있다. 원형 KalmanNet은 부분적으로 알려진 f/h가 필요하므로 그대로 도입하기 어렵다. 기술적 적용 가능성과 연구 우선순위·신규성은 서로 다른 판단이다. 이 제안은 현재 자료에서의 성능 근거가 아니다.

## 계획 자체에 남은 판정 주의

- Fable 교정본 E3에서 비열등성 하한을 넘지 못한 것은 '비열등성이 확립되지 않음'이지 열등성이 입증된 것이 아니다. 실제 손해를 말하려면 해당 손해 방향의 직접 구간 또는 적절한 margin 검정을 제시해야 한다.
- margin은 TRAIN/VAL 변동뿐 아니라 실제 측정·사용에서 의미 있는 오차 차이와 함께 정해야 한다. 이 조사에서는 margin이나 검정력을 확정하지 않았다.
- 동일 행의 목표 대비와 서로 다른 support 모집단의 선택 효과는 다른 estimand다. 선택 효과를 공통 행 교집합만으로 추정하면 선택 효과가 사라질 수 있다. 실제 사전등록에서 전체/포함/제외 모집단과 shared-cluster resampling을 명확히 정해야 한다.
- 기존 준비 배열·예측 파일의 존재를 확인하는 인벤토리가 곧 새 TEST 분석을 허용하는 것은 아니다. 새 metric·층화·support 집계는 실험 판독에 앞서 등록한다.
- 새 알고리즘이 불가능하다는 결론은 없다. 현재 근거로 알고리즘 신규성을 주장할 수 없으며, 먼저 기존 방법이 답하지 못한 반증 가능한 질문이 필요하다는 판단이다.

이 조사에서 새 적합, GPU 실행, 저장 TEST 예측의 재채점은 하지 않았다. 다음 행동은 숫자 재판독 없이 기존 source·registration·저장 예측의 존재와 연결을 정리하는 것이다. 실행할 실험은 그 후 별도 사전등록한다.
