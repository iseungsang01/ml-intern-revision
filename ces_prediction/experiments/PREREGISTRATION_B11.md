# B.11 — 이산 코드북(VQ) 레짐 게이팅 (사전등록 v1, 2026-09-03)

**지위.** `PREREGISTRATION_W2.md` §1(공통 고정)·§2(채점·유의성)·§3(TEST 동결)을 **그대로
상속**하고, B.9의 `PRACTICAL_EPS = 0.02` 동률 규칙도 상속한다. 충돌 시 이 문서가 B.11에 한해
우선한다. **이 문서는 어떤 수치도 보기 전에 커밋한다.**

**변경 규칙.** 커밋으로만 변경한다. **val 수치를 본 뒤에는 §4의 TEST 규칙을 바꿀 수 없고**,
TEST 수치를 본 뒤의 변경은 전면 금지된다 — 이후의 대안 분석은 민감도 행으로만 추가한다.

---

## 1. 질문과 그것이 나온 자리

§8an이 승패를 예측하는 유일한 공변량을 지목하였다: **방전 안에서 타깃이 얼마나 움직이는가.**
그 산포의 3분위로 나누면 승률은

| | 조용 | 중간 | 변동 |
|---|---:|---:|---:|
| `CES_TI` | **42%** | 83% | 85% |
| `CES_VT` | **34%** | 48% | 55% |

이고, 조용한 방전에서 지는 이유는 표현력 부족이 아니라 **인과 GP가 이미 최적인 구간에 모델이
분산을 더하기 때문**이다. 연속 잠재는 레짐 경계를 매끄럽게 넘지만 이산 코드북은 "지금은
persistence를 신뢰한다 / 지금은 보정한다"를 **명시적이고 학습 가능한 스위치**로 만든다.

**B.11이 검정하는 것은 이 스위치이지 표현력이 아니다.** 추정기 축은 이미 닫혀 있다(§8ag 네 계열
동률, §8aa 폭 26배 평평, §8z 21k = 백본). 따라서 skill 승격은 1차 목표가 아니다.

**B.11이 검정하지 않는 것.** `V_rot`의 정보 부재. §8ar이 각운동량 수지를 항별로 감사하여
`T_NBI` 부재 · `T_NTV` 음성 종결 · `∇·Π_turb` 널 · `T_int` 도달 불가를 확정하였다. **정보가
없는 입력을 이산화해도 정보는 생기지 않으므로, `V_rot` skill 개선은 B.11의 가설이 아니다.**
`V_rot`는 라우팅 불변성의 구조적 대조군으로만 쓴다.

## 2. 팔(arm)과 통제 변수

**단 하나의 통제 변수: 읽기(readout) 가중치가 연속인가, 이산 코드로 선택되는가.**

| 팔 | 정의 |
|---|---|
| `b3k8` (대조군) | §8z의 채택된 해석 가능 칸. `ŷ = 이월값 + Σ_k w_k z_k + b`, `z ∈ [-1,1]^8` |
| `b3vqC` (후보) | 동일 구조 · 동일 K · 동일 앵커. 다만 `w`와 `b`가 **코드별**이다: `ŷ = 이월값 + ⟨w_{c(t)}, z_t⟩ + b_{c(t)}`, `c(t) = argmin_c ‖z_t − E_c‖` |

- 인코더·앵커·라우팅·손실·최적화·데이터 처리는 전부 동일하게 고정한다.
- 모든 `w_c`, `b_c`는 **0으로 초기화**한다 → 두 팔 모두 학습이 정확히 persistence에서 출발한다.
- 코드북은 EMA(decay 0.99)로 갱신하고 commitment 항 `β = 0.25`를 손실에 더한다. 코드북 자체에는
  그래디언트를 흘리지 않는다.
- **출력은 양자화하지 않는다.** §8aq에서 본류의 모델 오차가 타깃 자체 산포의 2.3–3.4배에
  불과하므로 출력단 양자화는 그만큼을 그냥 잃는다. 이산화는 **게이팅에만** 쓴다.
- 탐색하는 유일한 하이퍼파라미터는 코드 수 `C ∈ {4, 8, 16}`이다. `K = 8`로 고정한다(§8z가
  val에서 고른 값).

## 3. 1단계 — val 전용 선별 (이 세션에서 실행)

§8y의 선례를 따른다: 탐색은 val에서만 하고, TEST는 규칙을 통과한 뒤에만 연다.

**고정 조건.** 동결 B.1 `s42` 매니페스트의 `train_files`/`val_files`만 읽는다. 확정 데이터 처리
(held-free · 3 keV 컷 · shot별 표준화)를 러너 env에 **명시 고정**한다. AdamW 1e-3 / wd 1e-4 ·
batch 16 블록 · clip 1.0 · 최대 30 epoch · 조기 종료 patience 6. 초기화 시드 3개(42/1/7).

**선별 지표 (사전 선언).**

- **S1 코드북 생존.** 학습 종료 시 `T_i` 코드북의 **유효 코드 수(perplexity) ≥ 2**이고 사용률
  1% 이상인 코드가 2개 이상. 이를 만족하지 못하면 그 `C`는 **붕괴로 판정**하고 탈락한다.
- **S2 val 손실 비열세.** 세 시드 평균 val 마스킹 MSE가 `b3k8` 대비 **+0.02 이내**(B.9에서
  상속한 `PRACTICAL_EPS`). 즉 "게이팅이 손해를 끼치지 않는다"가 통과 조건이지 이득이 아니다.
- **S3 코드가 레짐을 잡는가.** 코드 배정과 **행 단위 타깃 이동량**(`|Δ CES_TI|`, 관측 연속쌍)
  사이의 상호정보가 **코드를 무작위 셔플한 귀무분포의 99 백분위를 초과**한다. 셔플 1,000회.
  이것이 B.11의 1차 선별 기준이다 — 코드가 shot id나 시간 위치가 아니라 **타깃의 움직임**을
  가리켜야 한다.
- **S4 라우팅 불변.** 고속 15채널을 0으로 두었을 때 `V_rot` 출력이 비트 단위로 동일하다.
  실패 시 그 팔은 **즉시 무효**이며 수정 후 재실행한다.

**1단계 판정.** S1·S2·S3·S4를 **모두** 만족하는 `C`가 하나 이상 있으면 2단계로 승격한다.
하나도 없으면 **B.11은 음성으로 종결**하고, §8j 규칙에 따라 그것을 뒤집을 측정을 지목한 뒤
`THESIS_RESULTS.md`에 기록한다. 이 경우 TEST는 열지 않는다.

## 4. 2단계 — TEST 확증 (1단계 통과 시에만, 별도 실행)

**이 절은 val 수치를 보기 전에 고정되었다.**

- 승격 후보는 1단계를 통과한 `C` 중 **S3 상호정보가 가장 큰 하나**로 한다(val 손실로 고르지
  않는다 — B.11의 가설은 skill이 아니라 레짐 게이팅이다).
- 4개 분할(42/1/7/123) × 초기화 3개, 두 모집단(컷 / 포함) 전부에서 `b3k8`과 짝지어 채점한다.
  TEST는 후보당 **1회만** 채점한다.
- **1차 판정(사전 선언): §8an 층화에서 조용 3분위의 `CES_TI` 방전 승률.** `b3vq`가 `b3k8` 대비
  조용 3분위 승률을 **+0.05 이상** 올리고, 변동 3분위에서 `PRACTICAL_EPS` 이상 잃지 않으면
  **KEEP**. 그렇지 않으면 **미승격**이며 음성으로 기록한다.
- **2차(보고만, 승격 근거 아님):** 전체 `T_i` skill vs PCHIP · 인과 GP, 두 모집단 4/4 계수,
  코드-물리 교차표(코드 × peak 플래그 × 3 keV 초과 행).
- **`V_rot`는 탐색(exploratory)으로만 보고한다.** §1의 이유로 확증 자격이 없다.

## 5. 반증 조건 — 무엇이 이 가설을 죽이는가

다음 중 하나라도 성립하면 B.11은 실패로 기록되며 재시도하지 않는다.

1. 세 `C` 전부에서 코드북이 붕괴한다(S1 실패) → 452개 학습 블록이 코드북을 지탱하지 못한다는
   뜻이며, 이는 데이터 규모의 문제이므로 하이퍼파라미터로 되돌리지 않는다.
2. 코드가 타깃 이동량이 아니라 **shot id**를 가리킨다(S3 실패, 셔플 대조 미통과). 공반
   진단으로 코드-shot 상호정보를 함께 보고한다.
3. 1단계는 통과했으나 2단계 1차 판정에서 조용 3분위 승률이 오르지 않는다 → **이산 게이팅으로는
   조용 방전 손실을 회수할 수 없다**가 기록되는 결론이며, 남은 후보는 인과 GP와의 명시적
   혼합(mixture)이지 표현력이 아니다.
