# Experiment batches

One directory per registered batch. The registration of a batch is `PREREGISTRATION_B{NN}.md` in this
directory (open choices in `..._ADDENDUM{n}.md`); its results are `docs/paper/b{NN}_*.md` and `.json`; what is
used from it is one subsection of `PROJECT_KNOWLEDGE.md` section 4. The procedure of a batch is in
`HANDOVER.md` section 5, the wiring between batches in the repository `README.md`. Run everything from the
repository root with `py`.

The directory was cleaned on 2026-11-21: batches that the current line of work neither imports nor reads
were removed with their registrations and results (git history, last commit before the cleanup `e86adaf`).
