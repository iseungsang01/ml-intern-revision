# B.19 — 앵커의 측정 모형: 꼬리 척도의 가우시안 → 본류 척도의 Student-t (사전등록 v1, 2026-10-30)

**지위.** `PREREGISTRATION_W2.md` §1–§3, `PREREGISTRATION_B16.md` §1–§2, `PREREGISTRATION_B18.md` §1–§2(설계·env·채점)를
그대로 상속한다. `PRACTICAL_EPS = 0.02`, B.13 co-metric(M1–M5), B.16 규칙 1 막대(M1 vs 백본 ≥ +0.05, ≥ 3/4)를 상속한다.
**이 문서와 코드·판정 스크립트는 B.19의 어떤 수치도 보기 전에 커밋한다.** §8bk·§8bl의 수치는 봤고, 그것이 이 등록의
동기다. 변경은 커밋으로만 하며 TEST 수치를 본 뒤의 변경은 전면 금지된다.

**어디서 나온 질문인가.**
1. §8bk: 유지-또는-점프 앵커와 OU 앵커가 `V_rot` 중앙값에서 똑같이 1.18×persistence다 — 사전분포 형태는 원인이 아니다.
2. §8bl(TRAIN 전용 진단): 증분은 추세가 없고(ρ₁ −0.34…−0.50), `V_rot`는 중앙값 행에서 persistence가 이미 최적이다
   (최선 고정 이득 평활 0.996–0.999×). 앵커가 쓰는 잡음 척도(정규화 단위 0.30 / 0.40)는 본류 산포(`T_i` 0.116 컷 /
   0.071 포함, `V_rot` 0.060)의 3–7배이고, 그만큼 작은 혁신을 과수축한다. `T_i`는 단순 평활로 0.95–0.96×에 닿는다.
3. §8bl 정정: 학습된 앵커 모수는 초기값에서 7 % 이내다. 끝단 MSE 학습은 앵커의 측정 모형을 움직이지 않으므로,
   측정 모형은 등록이 정하는 초기값이 곧 모형이다.
4. §8aq·§8bj: 측정 오차는 두꺼운 꼬리다(상위 1 %가 4차 차분 제곱합의 47–66 %, head의 ν ≈ 3, `V_rot` ν 하한).

가우시안 측정 모형은 척도 하나로 본류와 꼬리를 함께 설명해야 하므로 꼬리 척도를 갖는다. Student-t는 척도를 본류에 두고
꼬리를 ν로 따로 설명한다.

## 1. 팔과 통제 변수

**통제 변수는 앵커의 측정 모형 하나**: (가우시안, σ_n = 0.30 / 0.40) → (Student-t, ν₀ = 3, 척도 = TRAIN 본류 산포).
척도와 분포족은 함께 바뀐다 — t의 척도 모수는 본류 척도이고 가우시안의 σ는 전체 RMS라서, "같은 σ_n의 t"는 다른 모형이
아니라 같은 꼬리 척도를 두 번 세는 것이다. 사전분포(유지-또는-점프, λ₀·σ_J₀·σ_d₀)·잔차·손실(MSE)·선택(val MSE)·
epoch 상한 60·데이터·분할은 `v4kj`와 동일하다.

| 팔 | 출력 | 비고 |
|---|---|---|
| 대조군 `v2` | head(h) | 얼린 백본, 재학습 없음 |
| 대조군 `v4kj` | 유지-또는-점프 앵커(가우시안) + 잔차 | 얼린 B.18 run(`.b16_v4kj_*`), 재학습 없음 |
| 대조군 순수 점프 앵커 | `v4kj` 앵커만 | 얼린 B.18 readout(`.b18_anchor_*`) |
| **`v4kjt`** | **유지-또는-점프 앵커(Student-t) + 잔차** | `SeqCESV4K(gated=False, anchor="jump_t")` |

**셀** (`model_seq_v4k.py::JumpAnchor(nu0=3)`, `_jump_scan(student=True)`). 측정 $\tilde y = y + \varepsilon$,
$\varepsilon \sim t_\nu(0, r)$. 두 가설(점프 없음 / 점프 하나)의 가중치는 t 우도
$\propto S_h^{-1/2}(1 + e^2/(\nu S_h))^{-(\nu+1)/2}$, $S_h$ = 가설의 사전 분산 + r. 각 가설은 한 단계 변분 잡음 분산
$R_h = r(\nu + e^2/S_h)/(\nu+1)$로 Kalman 갱신한다(이상치일수록 R이 커져 이득이 줄어든다). ν = 2 + softplus(·)로
학습 가능(유한 분산), ν₀ = 3(§8bj의 `T_i` ν 2.8–3.5). 척도 초기값 `BULK_SIGMA_N`: `T_i` 0.116(컷) / 0.071(포함),
`V_rot` 0.060 — §8bl의 1.4826·MAD(d)/√2를 split별 TRAIN 목표 표준편차로 나눈 네 split 평균. 모집단은
`CES_TI_SPIKE_CUT_EV`로 고른다(러너 env가 항상 명시 고정).
- ν → ∞에서 가우시안 셀과 같아진다(ν₀ = 500에서 차 ≤ 0.013, 단위 테스트). `v4kj` 체크포인트의 state_dict는 그대로
  로드된다(ν 모수는 t 셀만 가짐).

## 4. 가설과 판정 (수치를 보기 전에 고정)

판정은 컷 1차, 포함 공동 1차. 유의성은 shot 군집 paired bootstrap CI 0 배제.

- **H19-a (기전, 순수 앵커).** 순수 t 앵커 `V_rot` 중앙값/persistence ≤ 1.02 → "1.18×는 잡음 척도였다";
  ≥ 1.05 → "척도가 원인이 아니다"; 사이 → "부분". 함께: 순수 t − 순수 점프 풀링 M1 `T_i` ≥ +0.02 ∧ CI > 0.
- **H19-b (본류).** `v4kjt − v4kj` 풀링 M1 `T_i` ≥ +0.02 ∧ CI > 0 ∧ MSE guard(`T_i` paired vs 백본 유의 열세 ≤ 1/4 ∧ 평균 ≥ −0.02).
- **H19-c (B.16 규칙 1).** `v4kjt` M1 vs 백본 `T_i` ≥ +0.05 ∧ CI > 0 (≥ 3/4) ∧ MSE guard.
- **H19-d (`V_rot` 전체).** `v4kjt` `V_rot` M1 vs 백본 ≥ +0.05 ∧ CI > 0 (≥ 3/4) ∧ MSE 유의 열세 0/4.
- **H19-e (해석, 판정 아님).** 학습 후 ν·척도·λ·σ_J의 초기값 대비 비.

**판정 규칙.**
1. **측정 모형 기전 확인**: H19-a의 `V_rot` 판독이 두 모집단 모두 "잡음 척도". 이때 §8bb P02 각주에 "달성 가능
   중앙값 ≈ 1.00×가 학습 앵커로 재현됨"을 적는다.
2. **앵커의 측정 모형 교체**: H19-b ∧ MSE guard. 컷·포함 모두면 무조건부, 한쪽이면 그 모집단 조건부.
3. **B.16 규칙 1 충족**: H19-c. 컷에서 충족되면 물리 rung이 포함 조건부(§8bg)에서 올라간다.
4. MSE guard 위반(유의 열세 ≥ 2/4)이면 기각하고 원인 층(peak/nonpeak, stale/fresh)을 기록한다.
5. 규칙 1은 통과, 규칙 2는 실패하면(앵커는 고쳐졌는데 잔차가 소모) 다음 측정은 잔차의 선택 규칙(§8bh: 자기 목적
   함수 선택)으로 지목한다.

## 5. 하지 않는 것

- 사전분포(λ·σ_J·σ_d 초기값), 잔차, 손실, 선택 규칙 변경 없음 — 각각 별도 통제 변수.
- 앵커 모수의 별도 우도 적합(사전 적합 후 동결) 없음 — 이 등록이 음성이고 원인이 "모수가 안 움직임"이면 그것이 다음 행.
- 데이터·분할·모집단·채점 코드 불변.
