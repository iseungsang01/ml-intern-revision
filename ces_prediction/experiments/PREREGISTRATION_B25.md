# B.25 — 잔차가 행 단위로 하는 일: 두 판독 진단 (사전등록 v1, 2026-11-01)

**지위.** `PREREGISTRATION_W2.md` §1–§3을 상속한다. **학습 없음, 재학습 없음.** 이미 있는 체크포인트를
행 단위로 다시 읽어 §8bn·§8bo가 "가설이며 측정이 아님"이라 적어 둔 두 해석을 검정한다.
이 문서와 `b16_physics/residual_rows_b25.py`, `b16_physics/verdict_b25.py`는 어떤 B.25 수치보다 먼저 커밋한다.

공통: 행 = 그 분할 파일들의 `build_blocks` 블록에서 해당 표적이 관측된 행(`mask = 1`), 그 블록에서 같은 표적이
그보다 앞서 한 번 이상 관측된 행만(앵커가 정의되는 행). 데이터 처리는 학습 때와 같다 — held-free
(`CES_DROP_STUCK_TARGETS=1`), 모집단별 `CES_TI_SPIKE_CUT_EV`(컷 3000, 포함 0), 빠른 채널 shot별 표준화,
표적은 TRAIN 파일 전역 통계(체크포인트 `metrics.json`과 일치를 FATAL로 검사). 한 체크포인트당 한 번의 전체 블록 추론
(`eval_seq`와 같은 경로), 앵커 a와 sd s는 모델의 두 Kalman 셀을 같은 입력으로 다시 불러 얻고 순수 앵커 경로
(`anchor_only`)와 비트 단위로 같은지 FATAL로 검사한다. 잔차 기여 c = y − a (가법은 r, 융합은 k·r).

## A. §8bo 해석 1의 검정 — 융합 잔차가 조용한 행에서 더 크게 움직이는가 (TEST)

- 비교: `.b16_v4kjtf_{pop}_s{s}`(B.21, y = a + k·r) 대 `.b16_v4kjt_{pop}_s{s}`(B.19, y = a + r). 두 체크포인트는 같은 등록 앵커에서 출발.
- 행: 각 split의 TEST 파일. 구간: 융합 체크포인트의 k(= s²/(s²+σ_r²))의 split·표적별 십분위. "저-k" = 하위 3개 십분위.
- 양: 구간별 median |c| 비 R = median|k·r|_융합 / median|r|_가법, median |y − 표적| 두 팔.
- **H25-a.** 저-k 구간 R > 1, ≥ 3/4 split (표적·모집단별). 성립 → "잔차가 이득을 1/k로 보상하며 조용한 행에 k·r 잡음을 얹는다"(§8bo 해석 1) 측정으로 확정.
- **H25-b.** 저-k 구간 median |y − 표적|이 융합 > 가법, ≥ 3/4 split. (중앙값 손실이 바로 그 행에 있다.)
- 판정: a ∧ b → 해석 확정. a 실패 → 해석 기각, 손실은 조용한 행의 잔차 크기가 아니다. 다음 측정으로
  같은 구간의 |a − 표적|을 두 팔 간에 비교한다(학습 중 앵커가 움직였는가). 이 값도 이 스크립트가 함께 기록한다.

## B. §8bn 해석 1의 검정 — 포함 모집단의 val MSE는 적합 실패 행이 지배하는가 (VAL)

- 비교: `.b16_v4kjt_{pop}_s{s}`(B.19, val MSE 선택) 대 `.b20_v4kjt_{pop}_s{s}`(B.20, val median-AE 선택).
- 행: 각 split의 VAL 파일 — 학습 중 선택 키가 계산된 바로 그 행 집합(train_seq `masked_pass`의 관측 행)에 앵커 정의 조건을 더한 것.
- 층 F = 원시 `T_i` > 3000 eV 행(포함 모집단에만 존재), 층 N = 나머지. 컷 모집단 사건층 E = 그 split VAL 행 중
  |표적 − 직전 관측값| 상위 10 %, 나머지 Q.
- **H26-a (포함).** MSE 선택 체크포인트에서 F가 val `T_i` 제곱오차 합의 > 50 %, ≥ 3/4 split.
- **H26-b (포함).** N층 median |오차|: medae 선택 < MSE 선택, ≥ 3/4 split; F층 MSE: MSE 선택 < medae 선택, ≥ 3/4 split.
- **H26-c (컷).** E층 `T_i` MSE: MSE 선택 < medae 선택, ≥ 3/4 split (가드가 재는 사건 행을 medae 선택이 잃는다).
- 판정: a ∧ b → "포함에서 MSE 키는 적합 실패 행으로 체크포인트를 고른다" 확정. c → "컷에서 medae 키는 사건 행 학습 전에 멈춘다" 확정.
  a 실패 → 포함 val MSE는 F가 지배하지 않는다; 선택 규칙 차이는 다른 행에서 온다 — 다음 측정은 N층 내부를 |Δ| 십분위로 나눈 같은 비교.
