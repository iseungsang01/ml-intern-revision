## Hypothesis and fixed single change

B118 found a larger relative loss against GP+fast in D10 rows with small current-versus-anchor fast change. This does not establish a causal mechanism. The testable hypothesis is that explicitly preserving the available CES level in the readout can help the same recurrent representation learn changes without relearning the entire absolute temperature level. GP+fast also uses its own causal GP/history summaries; this trial does not assert that its feature representation is identical to the LSTM's.

Exactly ONE new fit: original unit V1_r2_k0, seed1701, same thirty-five causal inputs, full-segment unidirectional LSTM64 and LayerNorm64/Linear64/GELU/Linear1 correction readout as B117. Add only the parameter-free visible-CES output connection: normalized prediction = b(x)+delta(h), where b(x)=x16 if x18>.5, else0. The absent-history zero is the normalized TRAIN mean, not physical zero temperature. Set the correction readout's last Linear weight and bias to ZERO at initialization; all other initial parameter arrays use the exact original seeded LSTM construction. Thus initialized predictions equal the visible CES value or the TRAIN mean before a visible CES exists. Train all parameters, no frozen backbone.

This is a residual-readout plus zero-initialization package, not an isolated causal estimate of skip connections. Do not add GP inputs, GP+fast predictions to the model, adaptive model switching, a new architecture, output clipping, a target change or a TEST-selected gate. In particular a small fast change does not force zero correction after training. The same GRU families are not queued. Historical B117/B118 checkpoints/results and source files remain frozen.
