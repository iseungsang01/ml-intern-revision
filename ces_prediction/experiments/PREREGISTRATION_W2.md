# W = 2 전면 재실험 — 사전등록 프로토콜 (v1, 2026-08-14)

**지위.** 2026-08-12 방향 재정립(`THESIS_RESULTS.md` §8v)의 실행 프로토콜이다. B.7 프로토콜
감사(`PROTOCOL_AUDIT.md`)의 (B)/(C) 교정을 반영해 **실행 전에** 고정한다. 이 문서의 변경은
커밋으로만 하며, 해당 실험의 TEST 수치를 본 뒤의 변경은 금지된다 — 그 시점 이후의 대안 분석은
민감도 행으로만 추가할 수 있다.

**적용 범위.** B.1–B.5 전 배치. B.6(kHz Mirnov)은 §7의 별도 규칙을 따른다.
기존 W = 4 산출물은 어떤 결과도 이월하지 않으며, 새 확증 주장의 control로 쓰지 않는다
(역사적 재현 확인은 예외).

### 1.1 이중 모집단 공동 1차 보고 (개정, 2026-08-14 승상님)

- **두 모집단을 공동 1차로 보고한다**: ① 컷 적용(스파이크 제외, "p99 체제") ② 전량 포함("p100 체제",
  컷 없는 학습·이력·앵커·평가의 일관 체제 — 윈도우 계열의 기존 대응물은 컷 없는 W = 2 스윕 계열).
  각 모집단 안에서는 모든 처리(학습 타겟·이력·앵커·평가)가 일관되고 전 arm 동일하다.
- **무조건부 주장 기준 = 두 모집단 모두에서 성립.** 한쪽에서만 성립하는 결과는 해당 모집단을
  명시한 조건부 서술로만 보고한다. 이 기준은 단일 헤드라인보다 엄격하다 — p100만 쓰면 스파이크가
  보간 앵커를 오염시켜 보간이 불리하고, 컷만 쓰면 "어려운 행 제거" 비판에 노출되기 때문.
- **근거(물리)**: >3 keV는 피팅 실패로 어떤 방법도 예측 불가하나, 배치된 시스템은 그런 행을
  실제로 만나므로 전량 포함 체제의 성능도 1차 정보다. ELM/천이 포착 주장은 모집단 선택이 아니라
  **peak 층화 분석**(두 모집단 모두 수행)이 운반한다.
- **정직성 기록**: 이 개정은 컷 체제 윈도우 계열 3/4 seed의 TEST 수치가 부분 언블라인딩된 뒤
  결정되었다(2026-08-14, w2cut s42/s1/s7 확인 후). 개정 방향이 "기준 강화"(양쪽 모두 요구)이므로
  선택 편향 위험은 반대 방향으로 작동한다.
- **B.1 관문은 영향 없음**: 백본 결정은 내부 모델 선택이므로 컷 체제 단일로 수행한다(§4).
  B.5 전면 재채점에서 두 체제의 수치를 모두 산출한다.

**W = 2 기준 컨트롤 계열.** 윈도우 스윕의 held-free W = 2 실행
`data/.wsweep_hf_w2_s{42,1,7,123}` + 해당 manifest. 이 계열은 확정 프로토콜과 완전히 일치하는
(W = 2 · held-free · cap 500 · per-shot OFF) **유일한 기존 산출물**이며, 스파이크 컷만 없다 —
컷 도입 후 첫 재학습 계열이 새 기준 컨트롤이 되고, 스윕 계열은 "컷 없는 민감도 대조"로 강등된다.

## 2. 채점·유의성 (전 배치 불변)

- 지표: 물리 단위 역정규화 후 타겟별 Murphy skill. 사다리 = persistence / AR(local) / linear /
  PCHIP / GP(오프라인) / **인과 GP(신규, §5)**.
- **PR1′** 헤드라인 비교 대상은 **PCHIP 유지**(기존 사전등록과의 연속성). 선형 대체 시 결론 유지
  확인과 GP·인과 GP 사다리 병기는 의무.
- **PR2** 보간의 persistence 폴백 유지. W = 2에서 폴백 빈도가 증가할 수 있으므로 **폴백률 보고 의무**.
- **PR3** TEST 하한(≥15 shot & ≥3,000 관측 `T_i`) 유지.
- **PR4** 유의성 = shot-clustered paired bootstrap(10⁴회) 95% CI의 0 배제. 확증 실험은 4 독립
  seed(관문 B.1만 16), 분할 통합(pooling) 분석은 물리 shot 클러스터.
- 헤드라인 모집단 = **스파이크 제외 · genuine**. 민감도 = 포함 · stuck0.
- 비교 전 row-pairing 검증(§5.8-C4); 얼린 실행 재채점은 가산 키 + 기존 키 bit-identical 확인
  (§5.8-C5), 단 `se_model`은 bounded-drift(RMSE < 0.01 물리 단위) 규칙.

## 3. TEST 동결

B.2 탐색 전 과정에서 모델 선택은 **val에서만** 한다. TEST는 판정 규칙을 사전 고정한 확증
실험에서 후보당 1회만 채점한다. 이 문서 §5·§6의 판정 규칙이 그 사전 고정이다.

## 4. B.1 — 백본 관문 (판정 규칙, 실행 전 고정)

**설계.** `seq_v2` 16 run = split seed {42, 1, 7, 123} × init seed 4개
(`CES_INIT_SEED`). 각 run은 자기 split의 **W = 2 held-free 윈도우 컨트롤**과 paired.

> 감사 (B)-4: §8t의 컨트롤은 W = 4 계열(`.sf_iter009_s*`)이었다. 관문의 컨트롤은 확정
> 프로토콜과 정합한 W = 2 계열로 교체한다. `seq_v2` 자체는 W 개념이 없으므로 arm 쪽은 재사용
> 가능하나, **스파이크 컷 도입이 모집단을 바꾸므로 관문 전 계열을 컷 적용 프로토콜로 재학습**한다.

**예산 균등화.** `seq_v2` 고정 10-epoch arm을 추가한다(현행 early-stopping arm과 병기) —
"+0.045를 아키텍처 효과로 인용"하기 위한 전제.

**판정 (전부 충족 시 `seq_v2`를 B.3 백본으로 채택, 하나라도 미충족 시 윈도우 W = 2 유지):**
1. split별 init-평균 paired `T_i` 부호 **4/4 양수**;
2. 16-run paired 평균에 대한 run-클러스터 bootstrap 95% CI가 **0 배제**;
3. 예산 균등화 arm에서도 부호 유지;
4. `V_rot` 유의 열세 run **0개**.

## 5. B.1 병렬 — 인과(past-only) GP 기준선 (판정 규칙, 실행 전 고정)

**구성.** 기존 GP arm(Matern-3/2 + white noise, 국소 정확 fit, 격자 로그 주변 우도 선택)에서
**미래 이웃을 제거**하고 과거 16 이웃만 사용. NaN 조건은 기존 `ar_local`과 동일하게 유지해
채점 모집단을 바꾸지 않는다(§5.8-C5 가산 키 검증 포함).

**판정.**
- 모델 vs 인과 GP paired, 4 seed: 모델 **유의 우세 4/4** → 주장 2("배치 가능한 모든 인과적 방법
  대비 우세") 유지·강화.
- 동률 또는 열세 → 주장 2를 "persistence 등 표준 배치 기준선 대비"로 **한정 재서술**하고,
  B.2 탐색의 목표에 "인과 GP 초과"를 추가한다. 인과 GP가 persistence를 이기는지 자체도 보고
  (배치 기준선 사다리의 갱신).

## 6. B.2–B.5 규율

- **B.2 (탐색적 — 사전 판정 규칙 없음).** attention pooling 계열 변형 우선. held-free·분할
  고정·페어링 통제 유지, val 전용. 유망 후보가 나오면 **그 시점에** 판정 규칙을 고정하고 4 seed
  확증 실험으로 승격 — 그 규칙은 이 문서의 개정 커밋으로 기록한다.
- **B.3 (최소 해석가능 모델).** 파일 분할은 W = 2 계열 manifest 상속. latent 4–8차원. 사전등록
  측정: ① latent 차원별 물리량 linear probe R²(T_e 평균·국소 활동·관측 간격·직전 관측값),
  ② 항별 분해 함수, ③ `V_rot` 경로 차단의 구조 검증(빠른 채널 섭동 시 bit-identical). 판정 초안:
  anchor 대비 paired 4/4 유의 우세 & 제안 모델 대비 손실 CI-허용치 이내 & probe R² 보고.
- **B.4 (스케일링 상한).** 통제 변수는 폭/깊이 하나. 평평한 곡선은 실패가 아니라 "이 입력
  집합의 성능 상한"이라는 결론이다.
- **B.5 (전면 재채점).** 헤드라인·MNAR 재가중·시간 분할·conformal·해석가능 사다리를 전부 W = 2
  수치로 교체. 각 결과에 사용 W 명기. W = 2의 coverage 축소(Δt > 15 ms 채점 표본 456행,
  MNAR in-domain 비율 추가 하락)와 PR2 폴백률을 결과 보고에 명시.

## 7. B.6 — kHz Mirnov 특징 (도착 시, 비동기)

Notion 부록 B.6의 규칙을 그대로 상속한다: 특징 명세(윈도우 RMS · 대역 파워 · 모드수 +
**모드 회전 주파수 필수**), 무작위(층화) 추첨 규칙 사전 고정·"흥미로운 방전" 선별 금지,
요청 전 검정력 역산, paired 설계 + 부분표본 시간 분할 확인 후에만 일반화 서술, 단계적
판정(파일럿 → 사전 기준 통과 시 확대 → 그때만 `T_i` 경로 개방), `V_rot` 표준 기준 /
`T_i` 보수 기준의 비대칭 판정 — 두 기준 모두 특징 도착 후 실행 전에 이 문서의 개정으로 고정한다.
기본 라우팅은 `V_rot` 경로 투입, 현행 데시메이트 MC 2채널은 제거 절제 1건 병행.

## 8. 운영 체크리스트 (각 배치 실행 전 확인)

- `RESEARCH_CONTEXT.md` §5.8의 C1–C8 전부.
- **`train.py`는 `CES_TEST_FRACTION=0`(기본)일 때 `split_manifest.json`의 `test_files`를
  파괴한다** — 분할 디렉터리는 항상 사본으로(`prepare_split_copy`).
- CUDA float32 forward는 세션 간 bit-재현 불가 — 모집단 키 bit-identical + `se_model`
  bounded-drift로 검사.
- 장시간 배치는 MKL 콘솔 핸들러 대응(`FOR_DISABLE_CONSOLE_CTRL_HANDLER=1`,
  `KMP_HANDLE_SIGNALS=0`, detached 실행).
- 체크포인트는 자기 기록 지표 재현을 확인한 뒤에만 신뢰(`T_i`만 재현되고 `V_rot`가 안 되면
  체크포인트 드리프트 의심).
