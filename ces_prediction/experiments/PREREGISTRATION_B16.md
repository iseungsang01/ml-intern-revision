# B.16 — 물리 구조 나우캐스터: Kalman 앵커 위의 사건 게이트 잔차 (사전등록 v1, 2026-10-13)

**지위.** `PREREGISTRATION_W2.md` §1(공통 고정)·§2(채점·유의성)·§3(TEST 동결)을 그대로 상속하고,
B.9의 `PRACTICAL_EPS = 0.02` 동률 규칙, B.13의 강건 co-metric(M1–M5)과 B.14의 "목적함수와 선택 지표는
한 쌍" 규칙을 상속한다. **이 문서는 어떤 수치도 보기 전에 커밋한다.** 변경은 커밋으로만 하며, val 수치를
본 뒤 §4의 TEST 규칙을 바꿀 수 없고 TEST 수치를 본 뒤의 변경은 전면 금지된다.

**어디서 나온 질문인가.** §8ba·§8bb(열 개의 증명)가 모델에 대해 지목한 두 자리다.
1. **본류.** MSE 백본은 조용한 행에서 잡음 앵커를 그대로 옮긴다(중앙값 1.03×persistence, §8ax). 잡음 OU
   모형의 최적 인과 필터 하한은 **0.875×**(foundations §7.4·§8), Huber 팔은 0.94×까지 회수했다(§8ay).
   남은 여지는 "앵커의 탈잡음"이며, 그것은 손실이 아니라 **구조**로 주는 것이 자연스럽다: 출력을 Kalman
   필터 앵커 위의 잔차로 둔다.
2. **천이.** 이득은 빠른 채널에 사건이 동시에 비치는 행에만 산다(P01: 천이 항 = 헤드라인의 90–114 %;
   P08: 조용 방전에서 −c_b = −0.072로 진다). 잔차를 **사건 게이트**로 열고 닫으면 조용한 행의 분산 비용
   c_b가 0으로 가고 천이 행의 이득은 남는다는 것이 (M6)의 예측이다.

## 1. 팔과 통제 변수

**통제 변수는 출력의 구조 하나**다. 데이터·분할·손실(MSE)·최적화·라우팅·학습 규약은 백본과 동일하다.

| 팔 | 출력 구조 | 비고 |
|---|---|---|
| 대조군 `v2` | $\hat y = \mathrm{head}(h)$ | 얼린 B.1(컷) / B.5(포함) 백본 run, 재학습 없음 |
| `v4kng` | $\hat y = a_t + r_t$ | **Kalman 앵커 + 게이트 없는 잔차**. $a_t$ = 학습 가능한 스칼라 OU–Kalman 셀의 한 걸음 예측 |
| `v4k` | $\hat y = a_t + g_t\,r_t$ | `v4kng` + **사건 게이트** $g_t=\sigma(\cdot)$. $T_i$ 게이트는 빠른 채널 증분 에너지와 LSTM 상태를, $V_\varphi$ 게이트는 느린 상태만 본다 |

**Kalman 셀**(`model_seq_v4k.py::KalmanAnchor`, 타깃별 독립, 정규화 단위). 상태 $(x,P,m)$:
$$
\text{갱신(직전 행이 관측되었을 때만)}:\ K=\frac{P}{P+\sigma_n^2},\ x\leftarrow x+K(\tilde y_{t-1}-x),\ P\leftarrow(1-K)P,\ m\leftarrow m+\alpha(\tilde y_{t-1}-m)
$$
$$
\text{전파}:\ x\leftarrow m+\rho\,(x-m),\ P\leftarrow\rho^2P+\sigma_s^2(1-\rho^2);\qquad a_t=x,\ s_t=\sqrt P
$$
관측 $\tilde y_{t-1}$은 데이터층의 carried 특징(직전 관측값, 엄격 인과)에서, 관측 여부는 loss 마스크의 한 칸
지연에서 읽는다. $(\rho,\sigma_s^2,\sigma_n^2,\alpha)$는 **학습 가능**하며 §8의 OU 적합값으로 초기화한다.
$m$은 느린 shot 수준(§8au의 shot 간 분산)을 따라가는 평균이다. $a_t$와 $s_t$는 LSTM 입력에도 붙는다.

**초기화 규약.** 잔차 head의 마지막 층은 0, 게이트 bias는 −2 → 학습은 **정확히 Kalman 필터에서 시작**한다
(B.3의 persistence 시작과 같은 원리, 한 단계 위).

**라우팅 불변.** $V_\varphi$ 가지(LSTM·앵커·게이트·head)는 빠른 15채널을 보지 않는다. 단위 테스트가 빠른 채널
교란에 대한 $V_\varphi$ 출력의 비트 동일성을 검사한다(`tests/test_seq_v4k.py`).

## 2. 설계

- split {42, 1, 7, 123} × init = split seed, **두 모집단**(컷 / 포함). 팔당 8 run, 두 팔 16 run.
- env: B.1 stage B(컷) / B.5 포함(`CES_TI_SPIKE_CUT_EV=0`) 그대로. `CES_SEQ_MODEL ∈ {v4k, v4kng}`,
  `CES_SEQ_LOSS=mse`, `CES_SEQ_SELECT=mse`(백본과 같은 선택 규칙), per-shot ON, held-free, patience 6,
  **epoch 상한 60**(백본 30; 상한에 걸리면 표에 적는다). 러너가 전 변수를 명시 고정한다(비네고시어블 1).
- TEST는 `eval_seq.py` 1회, 대조군과 `paired_model_compare.py` 행 페어링(MSE skill), `bootstrap_compare.py`
  PR4 사다리, `rescore_b13.py --extra`로 M1–M5, 러너의 `shot_winrate()`로 방전별 승률(산포 삼분위, 인과 GP 대비).
- 학습된 물리 모수 $(\tau=-\Delta/\ln\rho,\ \sigma_n,\ \sigma_s,\ \alpha)$를 물리 단위로 `metrics.json` 옆에 기록한다.
- 산출 dir: `data/.b16_{arm}_{pop}_s{seed}`, 요약 `data/.b16_summary.json`.

## 4. 가설과 판정 (수치를 보기 전에 고정)

판정은 컷 모집단이 1차, 포함 모집단이 공동 1차(§1.1). 모든 유의성은 PR4(shot 군집 paired bootstrap, CI 0 배제).

- **H16-a (본류, 1차 readout).** `v4k`의 $T_i$ M1(중앙값 AE skill) vs 백본 ≥ +0.05이고 CI > 0인 split ≥ 3/4.
- **H16-b (조용 방전).** `v4k`의 조용 삼분위(방전별 $T_i$ 산포 하위 1/3) 승률 vs 인과 GP가 백본의 값보다 ≥ +0.05 높다(4분할 풀링).
- **H16-c (집계 guard).** `v4k`·`v4kng` 각각 $T_i$ MSE paired vs 백본의 유의 열세 ≤ 1/4이고 풀링 평균 ≥ −0.02.
- **H16-d ($V_\varphi$).** `v4k`의 $V_\varphi$ M1 vs 백본 ≥ +0.05(3/4)이고 MSE 유의 열세 0/4.
- **H16-e (게이트의 몫).** `v4k` − `v4kng` paired M1 ≥ +0.02 또는 조용 승률 차 ≥ +0.05 → 게이트가 값을 한다.
- **H16-f (해석).** 학습된 $\tau$가 20–300 ms, $\sigma_n/\sigma_s$가 OU 적합의 0.3–3배 안 → 셀이 물리 모수로 남았다(보고용, 판정 아님).

**판정 규칙.**
1. **물리 rung 채택**(보고되는 팔): H16-a ∧ H16-c (컷). 포함 모집단에서도 성립하면 무조건부, 아니면 컷 조건부.
2. **백본 교체**: 위에 더해 두 모집단 모두에서 $T_i$ MSE paired 부호 4/4 양수 ∧ H16-d. 미충족이면 백본은 seq_v2로 남고 `v4k`는 rung.
3. H16-e 미충족이면 `v4kng`를 rung으로 보고하고 게이트는 음성 기록.
4. 어느 팔이든 H16-c 위반(유의 열세 ≥ 2/4)이면 그 팔은 기각, 원인(epoch 궤적·학습 모수) 기록.

## 5. 하지 않는 것

- 손실은 MSE로 둔다(B.14와의 교란 방지). Huber와의 결합은 이 배치가 끝난 뒤의 별도 통제 변수다.
- 게이트 입력에 빠른 채널의 **값**이 아니라 **증분 에너지**만 쓴다($V_\varphi$는 그마저도 쓰지 않는다).
- 데이터 처리·분할·모집단·채점 코드는 손대지 않는다.
