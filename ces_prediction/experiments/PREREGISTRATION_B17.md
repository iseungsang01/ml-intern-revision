# B.17 — 예측 분포 head: 나우캐스터는 자기 오차의 크기와 모양을 아는가 (사전등록 v1, 2026-10-27)

**지위.** `PREREGISTRATION_W2.md` §1(공통 고정)·§2(채점·유의성)·§3(TEST 동결)을 그대로 상속하고, B.9의
`PRACTICAL_EPS = 0.02` 동률 규칙, B.14의 "목적함수와 선택 지표는 한 쌍" 규칙, B.16의 집계 guard 형식을
상속한다. **이 문서는 어떤 수치도 보기 전에 커밋한다.** 변경은 커밋으로만 하며, val 수치를 본 뒤 §4의 TEST
규칙을 바꿀 수 없고 TEST 수치를 본 뒤의 변경은 전면 금지된다.

**어디서 나온 질문인가(승상님 2026-10-27: "분포 head 해보자").** 지금까지의 모든 팔은 점 예측 ŷ를 내고
MSE로 채점됐다. §8bb는 그 점 예측의 오차가 행마다 다른 물리를 갖는다고 증명했다: 조용한 행의 오차는
잡음 OU 앵커의 σ_n(≈110 eV)이고, 페데스탈 사건 행의 오차는 "붕괴가 일어나는가"라는 **두 값 중 하나**다
(P01·P08). MSE 최적 점 예측은 두 값의 평균을 찍으므로, 사건 행에서는 어느 쪽도 맞추지 못하는 것이
구조적으로 정해져 있다. 이 배치는 출력을 점이 아니라 **조건부 분포 p(y_t | h_t)** 로 바꾸고, 두 가지를
묻는다.

1. **크기.** 모델은 자기 오차의 척도를 행마다 아는가 — 예측 표준편차 σ_t가 사건 에너지(빠른 채널 증분,
   §8bb의 p_obs 대리)를 따라가고, V_rot에서는 사건이 아니라 **관측 경과 시간**(OU 분산 성장)만 따라가는가.
2. **모양.** 사건 행의 조건부 분포는 실제로 두 봉우리인가 — 2성분 혼합이 가우시안보다 CRPS에서 이기고,
   그 이득이 사건 행에 몰려 있는가.

이것은 앞선 배치와 다른 종류의 주장이다: "더 잘 맞춘다"가 아니라 **"언제 못 맞추는지 안다"** 이며, 실시간
운전에서 신뢰 구간을 함께 내는 나우캐스터의 근거가 된다. 점 예측은 guard로만 본다.

## 1. 팔과 통제 변수

**통제 변수는 출력의 표현(점 → 분포)과 그 손실(NLL) 한 쌍**이다. 인코더(두 개의 인과 LSTM, V_rot 가지는
빠른 15채널을 보지 않음)·폭·데이터·분할·최적화·학습 규약은 백본 `v2`와 동일하다.

| 팔 | head 출력(타깃별) | 학습 손실 | 비고 |
|---|---|---|---|
| 대조군 `v2` | ŷ | MSE | 얼린 B.1(컷) / B.5(포함) 백본 run, 재학습 없음 |
| `v2g` | (μ, σ) | 가우시안 NLL | 이분산 가우시안. "크기"를 묻는다 |
| `v2m2` | (π, μ₁, μ₂, σ₁, σ₂) | 2성분 혼합 NLL | "모양"을 묻는다. `v2m2 − v2g`가 두 봉우리의 몫 |

- 구현 `experiments/seq/model_seq_v2d.py`(레지스트리 `v2g`/`v2m2`). head의 마지막 선형층만 P-way로
  바뀌고 나머지는 `v2` 그대로. `forward(x)`는 **사후 평균**을 돌려주므로 `eval_seq.py`·paired 비교·
  bootstrap 사다리·`rescore_b13.py`가 수정 없이 점 예측을 채점한다. 분포 모수는
  `forward(x, return_dist=True)`로만 나온다.
- σ = softplus(·) + 10⁻³, 초기 bias로 **σ₀ = 1(정규화 단위, 타깃 train std)** — 가장 무정보한 상태에서
  시작해 우도가 보상하는 곳에서만 좁아진다. 혼합은 π₀ = ½.
- 손실은 `CES_SEQ_LOSS=nll`, 선택 지표는 `CES_SEQ_SELECT=loss`(val NLL)로 핀. 분포 head 없이 nll, nll 없이
  분포 head는 코드가 거부한다. `T_i` 음수 소프트 페널티 `0.1·relu(zero_ti − μ)`는 평균에 그대로 둔다.
- **알려진 위험(수치 보기 전에 적는다).** 이분산 NLL은 분산이 큰 행의 가중치를 1/σ²로 낮춘다. 그 행이
  바로 P01의 사건 행이므로 **사후 평균의 MSE가 백본보다 나빠질 수 있다.** 이 위험은 H17-e guard로 측정하고,
  위반 시 원인(사건 층의 paired MSE)을 기록한다. 가중치를 되돌리는 β-NLL류 변형은 두 번째 변수이므로
  이 배치에서는 쓰지 않는다.
- 단위 테스트 `tests/test_seq_v2d.py`(6개): 평균 경로 = 분포 평균, NLL = 닫힌 꼴, V_rot 분포의 빠른 채널
  교란 비트 동일성, 인과성, 초기 σ = 1, CRPS 닫힌 꼴 = 몬테카를로.

## 2. 설계

- split {42, 1, 7, 123} × init = split seed, 두 모집단(컷 / 포함). 팔당 8 run, 두 팔 16 run.
- env: B.1 stage B(컷) / B.5 포함 그대로. `CES_SEQ_MODEL ∈ {v2g, v2m2}`, `CES_SEQ_LOSS=nll`,
  `CES_SEQ_SELECT=loss`, per-shot ON, held-free, patience 6, epoch 상한 60. 러너
  `experiments/b17_dist/run_b17.py`가 전 변수를 명시 고정한다.
- 점 채점: `eval_seq.py` 1회 → 사후 평균의 `comparison_errors_test.npz`, `paired_model_compare.py`(vs 백본),
  `bootstrap_compare.py` 사다리.
- 분포 채점: `eval_dist_b17.py`가 **같은 TEST 행**에 분포 모수(물리 단위)·백본 점 예측·사건 에너지
  `log1p(mean Δz²)`·경과 시간을 `dist_test.npz`로 쓴다. 두 pairing guard(팔 평균과 백본 점 예측이 각자의
  npz `se_model`을 재현)가 어긋나면 중단.
- 분포 기준(학습 없음, `score_b17.py`):
  - **R0** = N(백본 점 예측, σ₀), σ₀ = 백본의 TEST RMSE(타깃별, **oracle 척도** — 기준에 유리, 우리에게 보수적).
  - **R1** = N(팔의 평균, σ₁), σ₁ = 팔의 TEST RMSE. R0와의 차이 중 평균 이동의 몫을 떼어내고 **이분산의
    몫만** 남긴다.
  - CRPS(가우시안 혼합 닫힌 꼴, Grimit 2006)·NLL, skill = 1 − ΣCRPS_팔/ΣCRPS_기준, shot 군집 paired
    bootstrap B = 10⁴ seed 12345(`bootstrap_compare._bootstrap`).
  - 보정: PIT로 중앙 50 %·90 % 구간 포함률.
  - 물리 readout: Spearman(σ_t, 사건 에너지), Spearman(σ_t, 경과 시간), σ의 사건행/비사건행 비.
  - `v2m2`: 두 봉우리 행 = min π ≥ 0.1 ∧ |μ₁ − μ₂| ≥ 2·max σ; 그 비율과 사건 행 농축비;
    `v2m2 − v2g` paired CRPS(전체·두 봉우리 행).
- 산출 dir `data/.b17_{arm}_{pop}_s{seed}`, 러너 요약 `.b17_runner_summary.json`, 판정 `.b17_summary.json`.

## 3. 유도가 내놓는 예측 (수치를 보기 전에 적는다)

| 양 | 예측 | 근거 |
|---|---|---|
| 컷 `T_i` `v2g` CRPS skill vs R0 | **+0.05 … +0.15** | §8aq: 상위 1 % 행이 제곱 질량의 47 % — 오차 척도가 행 사이에서 ≥ 3× 변하므로 이분산 가우시안의 CRPS 이득은 1 − E[σ]/√E[σ²] 수준 |
| 같은 양 vs R1 | **+0.03 … +0.10** | 평균 이동을 뺀 이분산의 몫 |
| 90 % 구간 포함률 | 0.85–0.93 | NLL 학습 가우시안은 약간 과신하는 경향 |
| Spearman(σ_Ti, 사건 에너지) | **+0.2 … +0.4**, σ 사건행/비사건행 ≥ 1.5 | §8bb P08: p_obs 대리 농축 1.27–1.34× |
| `V_rot`: Spearman(σ, 경과 시간) | **+0.3 … +0.6**; 사건 에너지와는 ≈ 0 | P02: V_rot 가지는 사건을 못 보고, OU 분산은 경과 시간에 단조 증가 |
| `v2m2 − v2g` CRPS | +0.00 … +0.03, 두 봉우리 행 1–5 %, 사건 행 농축 3–10× | 사건 행의 조건부 분포는 두 값 |
| 사후 평균 paired MSE vs 백본 | −0.03 … +0.01(`v2g`) | 이분산 NLL의 사건 행 가중치 감소 |

## 4. 가설과 판정 (수치를 보기 전에 고정)

판정은 컷 모집단이 1차, 포함 모집단이 공동 1차(§1.1). 유의성은 shot 군집 paired bootstrap CI 0 배제.

- **H17-a (불확실성은 정보다, 1차 readout).** `v2g`의 `T_i` CRPS skill vs R0 > 0(CI 0 배제)인 split ≥ 3/4,
  풀링 CI > 0, **그리고** vs R1 풀링 CI > 0(이분산 자체의 몫이 양수).
- **H17-b (σ의 물리).** `T_i`: Spearman(σ, 사건 에너지) ≥ +0.2 4/4 ∧ σ 사건행/비사건행 ≥ 1.3 4/4.
  `V_rot`: Spearman(σ, 경과 시간) ≥ +0.2 4/4 ∧ |Spearman(σ, 사건 에너지)| < |Spearman(σ, 경과 시간)| 4/4.
  보고용 readout — 판정 규칙 3에서 서술을 정한다.
- **H17-c (보정).** `v2g` `T_i`의 90 % 포함률 ∈ [0.85, 0.95] ∧ 50 % 포함률 ∈ [0.45, 0.55]인 split ≥ 3/4.
- **H17-d (두 봉우리가 값을 한다).** `v2m2 − v2g` `T_i` paired CRPS 풀링 CI > 0 ∧ 두 봉우리 행의 사건 행
  농축비 ≥ 2인 split ≥ 3/4.
- **H17-e (MSE guard, B.16 H16-c 형식).** 각 팔·각 타깃의 사후 평균 paired MSE vs 백본: 유의 열세 ≤ 1/4
  ∧ 4분할 평균 ≥ −0.02.

**판정 규칙.**
1. **"보정된 나우캐스터" 주장 채택**: H17-a ∧ H17-c ∧ H17-e(`v2g`, `T_i`) (컷). 포함 모집단에서도 성립하면
   무조건부, 아니면 컷 조건부. 미충족이면 분포 head는 "점 예측과 동률, 불확실성 미보정"으로 기록.
2. **보고 팔**: H17-d 성립이면 `v2m2`, 아니면 `v2g`("가우시안으로 충분" 기록).
3. **σ의 서술**: H17-b `T_i` 성립이면 "σ는 사건 물리다"(§8bb P08의 분포판). 미성립이면 "σ는 정체 불명의
   이분산"으로만 적고 사건 에너지 대신 무엇을 따라가는지(경과 시간·shot 수준)를 측정해 기록.
4. H17-e 위반(유의 열세 ≥ 2/4)인 팔은 기각하되, 사건 층(peak)과 비사건 층의 paired MSE를 따로 적어
   "NLL의 사건 행 가중치 감소"가 원인인지 기록한다. 그 경우 다음 등록은 평균을 MSE로 고정하고 분산 head만
   학습하는 2단계 설계다(이 배치에서는 하지 않는다).

## 5. 하지 않는 것

- diffusion·정규화 흐름·표본 기반 head는 쓰지 않는다. 가우시안 잡음 + OU 사전분포에서는 Tweedie의
  최적 탈잡음기가 선형(= Kalman)이고, 두 봉우리 검정은 2성분 혼합이 같은 질문을 1/100 비용으로 묻는다.
- 분산 가중치를 되돌리는 손실 변형(β-NLL), 손실 혼합(MSE + NLL)은 두 번째 변수 — 별도 등록.
- 데이터 처리·분할·모집단·점 채점 코드는 손대지 않는다.
