## 1. 내일 첫 명령 (OpenAlex 예산 리셋 = 매일 09:00 KST / 00:00 UTC)

```bash
py ces_prediction/experiments/hires_shots/literature_crosscheck.py \
      --fulltext-index --batched --priority --pace 1.0
```

`--priority`가 핵심이다. 남은 253개 중 **유효 V_rot ≥ 200인 55개**만이 단일 집합 여부를
바꿀 수 있으므로, V_rot이 많은 순으로 물어서 예산이 또 끊겨도 결정적인 답부터 남게 한다.
끊기면 같은 명령을 다시 실행하면 된다(shot 단위 재개).

**양성 대조는 이미 통과했다** — 다시 돌릴 필요 없다(2 요청 낭비). 기록:
양성 배치(기지 shot 4개 + 미끼 28개) → 논문 6편 정확히 반환, 음성 배치(미끼 32개) → 0편.
따라서 **배치가 비어 있으면 "문헌에 없음"으로 읽어도 된다.** 쿼리 문법을 건드렸다면
그때는 `--control`을 다시 돌릴 것.

### 예산에 대해 알아야 할 것

- 하루 약 100요청. 오늘은 대조 2 + 그룹 9 + 이분탐색으로 다 썼고 388/641에서 멈췄다.
- 429가 뜨면 `retry-after`를 본다. 15분 넘으면 일일 쿼터이고 `DailyBudgetExhausted`로
  **즉시** 중단된다(재시도도 과금이라 기다리는 게 손해다). 이건 이미 코드에 들어가 있다.
- 이분탐색이 부모 배치가 이미 산 답을 다시 사지 않는다(첫 절반이 설명 못 하는 논문이
  있으면 둘째 절반은 양성이 확정). 요청 25–36% 절감.

## 3. 재선정 기준 (B.9에서 유도 — 예전 기준 쓰지 말 것)

`select_hires_shots.py --rescore`가 이미 구현하고 있다(`score_v2`). 지표 정의는
`scan_file` 것을 그대로 재사용하므로 **다시 쓰지 말 것.**

1. **`t_span` 제외.** 문맥 70 ms면 충분하다(§8af). 긴 shot이 그 자체로 유리하지 않다.
2. **유효 `V_rot` 행 수가 1순위** (`label_value_v2` = 0.60·V_rot + 0.40·`T_i`).
   인과 GP 대비 어느 팔도 3/4에 못 미친 유일한 타깃이라서다.
3. **천이 구간 가점** (`transient_value`, 가중치 0.15). §5.2의 이득이 거기서 난다.
4. **인과 GP를 피하지 않는다.** GP가 강한 구간에서 이겨야 주장이 선다 — 감점 없음.
5. **세션당 하나.** `session_similarity.py` 스크린을 걸 것(인접 번호 = 같은 세션).

`mc_value` / `diag_value`는 그대로 뒀다. "원신호가 μs 취득 값어치가 있나"라는 다른 질문이고
B.9는 그에 대해 아무 말도 하지 않는다.

> ⚠ 함정 하나 (이미 고침): `vt_transient`는 유효 V_rot이 적은 249개 shot에서 정의되지
> 않는다. 백분위 랭크가 NaN을 전파해 **641개 중 263개가 랭킹에서 사라졌었다.** 측정 불가는
> 0점이지 shot 삭제가 아니다.

## 4. 재선정에서 반드시 고쳐야 할 것

**현 test 3중항은 `CES_VT`에 대해 실효 k=2다.** #31921(296) · #31114(311) · **#31873(1행,
`vt_held_frac = 1.00`)**. #31873의 회전 채널은 희소한 게 아니라 고착이고, μs 재취득으로도
복구되지 않는다 — 재취득 대상은 BES/ECEI/MC이지 CES 타깃이 아니기 때문이다.

`power_analysis.json`이 그 구간의 대가를 이미 측정해 두었다: `CES_VT | seqv2_vs_w2control`
통과율이 **k=3에서 0.665, k=2에서 0.770.** 증거가 얇아지는데 통과율이 올라간다 — 그 차이가
위양성이다. `folds.py`가 test를 3 밑으로 내리지 않는 이유로 적어 둔 바로 그 인공물인데,
타깃별로 점검된 적이 없었다.

→ **새 test 3개는 전부 유효 `V_rot`을 가져야 한다.**

## 5. 남은 작업 순서

1. 스캔 완주 (253개, `--priority`).
2. `py ces_prediction/experiments/hires_shots/select_hires_shots.py --rescore`
   → `shot_scored_v2.csv`.
3. `session_similarity.py` 스크린으로 세션 중복 제거.
4. 10 + α 확정 → `SELECTION.md`에 새 절, `FINAL_*.csv` 갱신.
5. `folds.py` 역할 재배정 (test 3 전원 `V_rot` 보유 조건).
6. `power_analysis.py` 재실행 (test 구성이 바뀌므로 필수).
7. `THESIS_RESULTS.md`에 절 추가.
