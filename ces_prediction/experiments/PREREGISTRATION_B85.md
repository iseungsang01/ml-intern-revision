# B.85 — one recurrent estimator across CES availability conditions

Exploratory on used D1 data; no claim of fresh confirmation. The author's pedestal-top nowcasting framing remains unchanged. New code only in b85_unified; no existing training module is edited. No post-fit correction stage.

## Question, data and model

Can one direct estimator preserve fresh-history accuracy and handle older/missing CES without per-scenario refitting? Use existing real D1 B.73 grid and row caches; mandatory, missing files abort. Context includes unlabelled grid rows. Supervision is only B.73 row targets F and L5 (L5: median of next five nominal 10 ms frames, at least three available, same segment; future labels never enter inputs). This is reported CES and its subsequent level, not independent physical temperature truth.

Use the Ti branch of seq/model_seq_v2.py: two-layer 160-unit causal LSTM, LayerNorm, Linear(160,64), GELU, and two scalar output heads F/L5. Both heads read the same Ti state. No rotation output or auxiliary GP prediction, no residual fit. Keep 22 input slots: BES9/ECEI4, two zeroed Mirnov slots, log1p(previous dt seconds), normalized last-visible Ti, log1p(age seconds), has-visible-Ti flag, three zeroed rotation-history slots. Full model X and identical-parameter history-only twin H (all first 15 fast slots zero); paired initialization and augmentation seeds. No scenario-ID input. Train-file-only mean/std for raw fast channels and finite Ti; same Ti scale for both heads. No per-shot or future normalization. Missing history value and age are zero with has flag zero. Reset state at original grid segment boundaries (gap >=0.5 s); whole segments, no self-prediction feedback. Within a segment one rule applies, so availability limits never go backwards and recurrent memory cannot retain newly hidden observations.

## Availability and training

Training rules sampled uniformly per segment per epoch: D10,D50,D100,D300,D650,D1000,S, exactly B.75 limits and 3 ms tolerance but always index strictly before current row. S only sees values at/before the last row preceding an already observed 15–45 ms grid gap in the same segment; before such a gap has flag zero. K10 is held out of training and validation: B.78 frame index rule, measured values at frame multiples of ten and strictly before t. At evaluation each full segment has one fixed rule, state reset, weights unchanged; report all eight rules. Sampling deterministic by unit/init/epoch/segment and identical between X/H. Validation includes all seven training rules with fixed equal rule weights. Test never selects epoch, rules, features or settings.

Initial execution units: V1_r2_k0..4, V2_s1_k0..4, V3_q1..4, V4a (15 units), three initializations 1701,1702,1703, X/H = 90 runs. Four validation designs all reported, none primary. V2 is added to the handover's initial plan to retain all designs. Other repetitions/assignments and V4b require a subsequent registration, not selected after scores. Each unit uses original B.73 fit/test file lists. Reserve ceil(15% of fit files), minimum one, for early stopping: V1/V2 seeded shuffle with seed [20261185, crc32(unit)]; V3/V4 latest shot numbers. Remaining fit files train normalization/weights. Save exact manifests. Trees used all original fit files; disclose the network's smaller training set. No test file in training or validation.

Optimization: AdamW lr 0.001, weight decay 0.0001, batch16 segments, gradient norm clip1, dropout0.1, cap80 epochs, ReduceLROnPlateau factor0.5 patience2; early stop after six epochs without improvement, select best validation mean MSE across heads and rules. Training loss averages each head's masked normalized MSE, plus 0.1 times mean normalized negative-temperature ReLU penalty on supervised values, following the inherited regime. No hyperparameter search or score-driven model changes. A one-epoch small real-data CUDA smoke (up to 12 train and 3 validation files, batch2) tests plumbing only; smoke weights/results are separate and never reported as batch results. Pin all CES data/normalization/model/optimization options in run env. GPU mandatory for training; never fall back to CPU. CPU allowed for input audits and inference checks. Never stop another GPU process; if free VRAM <2500 MiB, runner waits and records why. Runs sequential, resume only complete artifacts with matching metadata. Single-run and batch locks prevent duplicate writers.

## Mandatory checks before test errors

Directly compare grid-derived visible anchors, ages and flags against B.75/B.78 cached anchors on their scored rows for every rule. Mutate all Ti values not yet visible at sampled target times by removal and by +1000 eV: entire input prefix through that time must be unchanged, with frozen fit stats. Check current target never enters own history; future-fast mutation leaves prefix unchanged; no cross-segment carry; deterministic mixture; K10 excluded from sampling/validation; normalization uses training files only; manifests disjoint; labels equal B.73; finite CUDA forward/backward/gradients on real inputs; test predictions unaffected by target-label mutation. Smoke is plumbing, not scientific evidence. Write checks and machine-readable readiness manifest. Failed checks abort; implementation fixes disclosed before readout, registration never edited.

## Readout and comparisons

Save predictions indexed to B.73 rows per unit/init/model/rule/head. Comparisons use exact intersections with B.75 common_F/common_L5 (D rules), S_F/S_L5 (S), B.78 common_F/common_L5 (K10). D10/F also report B.73's full F rows vs stored TX[F] with counts/fallbacks explicit. Reuse per-rule T0/TX, TXall from B.84 where available (V2 absent -> explicitly unavailable), and B.73 fresh TX[F]. Never invent absent baselines or impute missing predictions. Include count of excluded rows. Baseline filenames and identities are recorded before scoring. No silent row changes.

For every design/rule/head: RMSE, MAE, median absolute error, share within 10% (F>100 eV or L5>100 eV, denominator stated), prediction range and share outside 0–3000 eV; MSE skills vs X/H twins, per-rule T0/TX, and TXall where available. Report each initialization and their mean, no post-hoc ensembling. 95% percentile intervals, 20000 draws, seed [20261185,crc32(cell)]: initialization sampled first (paired X/H), then shot clusters; discharge resampling beside it. V1/V2 one registered partition each, V3 pools its scored fifths, V4a its test block. No refitting inside bootstrap; conditional intervals, no multiplicity correction; report small cluster counts. Expose age-binned RMSE and cold-start rows separately as descriptive checks. Measure single-step recurrent CPU latency from completed model using real input traces, state carried, preprocessing separately; median/p99 and shared-machine conditions.

Statements separately per design: U1 D10/F vs B.73 TX[F], lower skill bound >-0.05; U2 D650/L5 vs per-rule TX, lower bound >-0.05; U3 S/L5 same; U4 unseen K10/L5 vs per-rule T0, lower bound >0; U5 D650/L5 X over H, lower bound >0. Expect U1–U3 uncertain, U4 uncertain, U5 holds. No substitution of non-significance for equivalence. Propose model replacement only if U1–U4 hold in every design and U5 holds under V3/V4a; otherwise retain current paper estimator and state the exact failures. Do not claim every scenario works from these eight alone. If U4 fails, the overturning measurement is an untouched campaign with specified availability and an increment over its condition-specific baseline; any revised training mix is a new registered experiment.
