# B.7 프로토콜 감사 — 과거 근거로 정당화된 제약의 전수 검토 (2026-08-14)

**목적.** 2026-08-12 방향 재정립(`THESIS_RESULTS.md` §8v)이 명령한 게이트: 사후 수정 회피·
사전등록 시점의 편의·구버전 데이터 수치를 근거로 도입된 제약 가운데 물리적으로 잘못되었거나
재검증이 필요한 것을 W = 2 전면 재실험 **시작 전에** 전수 검토한다. 지금이 이런 제약을 비용
없이(사후 수정이 아닌 사전등록으로) 교정할 수 있는 유일한 시점이다.

**분류.** (A) 물리·통계적 근거 있음 → 유지 + 근거 명기 / (B) 절차적 근거뿐 → 지금 사전등록으로
교정 / (C) 구버전 데이터 수치 근거 → 현행(또는 새) 데이터셋에서 재검증.

**게이트 선언.** 이 문서와 `PREREGISTRATION_W2.md`(교정 반영본)가 커밋된 뒤에만 B.1 이하를
시작한다.
