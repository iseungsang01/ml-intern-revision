# B.21 — 잔차의 결합 규칙: 가산 → 분산 가중 이득 (사전등록 v1, 2026-10-31)

**지위.** `PREREGISTRATION_W2.md` §1–§3, `PREREGISTRATION_B16.md` §1–§2, `PREREGISTRATION_B19.md` §1–§2를 상속한다.
`PRACTICAL_EPS = 0.02`, B.13 co-metric(M1–M5), B.16 규칙 1 막대와 MSE guard를 상속한다.
**이 문서와 코드·판정 스크립트는 B.21의 어떤 수치도, 그리고 B.20의 어떤 수치도 보기 전에 커밋한다.** B.20(선택 규칙)과
B.21(결합 규칙)은 둘 다 얼린 B.19 `v4kjt`를 대조군으로 하는 서로 독립인 한 변수 행이다. B.20의 결과로 이 등록을 바꾸지 않는다.

**어디서 나온 질문인가 (§8bm).** 순수 t 앵커는 두 표적 모두 persistence 아래인데(`T_i` 0.916× / 0.911×,
`V_rot` 0.975× / 0.976×), 가산 잔차 `y = a + r`을 얹으면 조용한 행의 중앙값이 되돌아간다(`V_rot` 1.08–1.12×,
포함 `T_i` 1.06×). 앵커는 사건 행에서 늦고(집계 MSE −0.37 … −0.42 vs 백본), 잔차는 그 행을 사면서 조용한 행을 움직인다.
B.16의 학습 게이트는 열린 채로 남아 아무것도 운반하지 않았다(§8bg, §8bi) — 게이트를 데이터에 맡기면 MSE가 연다.

**물리적 결합.** 앵커는 예측 분산 s²(t) = P + h·σ_J²을 가진 사전 추정이다(P: 갱신 후 분산, h: 마지막 관측 이후 점프
위험). 잔차를 오차 분산 σ_r²의 또 다른 측정으로 보면 베이즈 결합의 이득은 k = s² / (s² + σ_r²)다. 조용한 갓 관측된 행은
s²가 작아(≈ P + d + λσ_J² ≈ 0.05) k가 작고(컷 ≈ 0.16, 포함 ≈ 0.08), 공백이 길거나 큰 혁신 직후에는 s²가 커서 k → 1에
가깝다. 게이트에 새 신경망은 없다 — 앵커 자신의 불확실도가 라우팅이다.

## 1. 팔과 통제 변수

**통제 변수는 결합 규칙 하나**: `y = a + r` → `y = a + k(s)·r`, k = s²/(s² + σ_r²). σ_r²는 표적별 학습 스칼라 하나,
초기값은 얼린 백본의 VAL 최적 masked MSE의 네 split 중앙값(컷 `.b1_seqv2`: 0.228 0.253 0.284 0.925 → **0.27**;
포함 `.b5i_seqv2`: 0.421 0.525 0.551 1.201 → **0.54**; 정규화 단위, VAL만 사용). 셀(`jump_t`, ν₀ = 3, 본류 척도), 잔차 LSTM,
손실(MSE), 선택(val MSE), epoch 상한 60, 데이터, 분할은 B.19와 동일하다.

| 팔 | 출력 | 비고 |
|---|---|---|
| 대조군 `v2` | head(h) | 얼린 백본 |
| 대조군 `v4kjt` | a + r | 얼린 B.19(`.b16_v4kjt_*`) |
| 대조군 순수 t 앵커 | a | 얼린 B.19 readout(`.b19_anchor_*`) |
| **`v4kjtf`** | **a + k(s)·r** | `SeqCESV4K(gated=False, anchor="jump_t", fusion=True)` |

**알려진 한계(수치 전에 적는다).** 잔차 LSTM은 s를 입력으로 보므로, MSE가 원하면 조용한 행에서 r을 1/k배로 키워 이득을
상쇄할 수 있다. 상쇄되면 결과는 `v4kjt`와 같아지고(H21-b 실패), 그것이 "가산 출력에서의 맞교환은 구조가 아니라 목적함수의
것"이라는 측정이 된다.

## 2. 설계

- split {42, 1, 7, 123} × init = split seed × 두 모집단 = **8 run**.
  `run_b16.py --arms v4kjtf --summary-name .b21_summary.json` → `data/.b16_v4kjtf_{pop}_s{seed}`.
- 순수 앵커 readout 없음(같은 셀, 모수는 학습으로 안 움직임 — §8bm 5 % 이내).

  `experiments/b16_physics/verdict_b21.py` → `data/.b21_verdict.json`. 팔끼리는 `v4kjtf` vs `v4kjt`.

## 4. 가설과 판정 (수치를 보기 전에 고정)

판정은 컷 1차, 포함 공동 1차. 유의성은 shot 군집 paired bootstrap CI 0 배제.

- **H21-a (중앙값 보존).** `v4kjtf` `T_i` 중앙값/persistence ≤ 0.95 ∧ `V_rot` ≤ 1.00 (모집단별).
- **H21-b (결합의 이득).** `v4kjtf − v4kjt` 풀링 M1 `T_i` ≥ +0.02 ∧ CI > 0.
- **H21-c (B.16 규칙 1).** M1 vs 백본 `T_i` ≥ +0.05 ∧ CI > 0 (≥ 3/4) ∧ MSE guard.
- **H21-d (`V_rot` 전체, H19-d 막대).** M1 vs 백본 `V_rot` ≥ +0.05 ∧ CI > 0 (≥ 3/4) ∧ MSE 유의 열세 0/4.
- **H21-e (해석).** 학습 후 σ_r / 초기값, 앵커 모수 / 초기값.

**판정 규칙.**
1. **결합 규칙 교체**: H21-b ∧ guard. 두 모집단이면 무조건부, 한쪽이면 조건부.
2. **B.16 규칙 1**: H21-c. 두 모집단 모두면 물리 rung 무조건부.
3. **맞교환이 목적함수의 것**: H21-b 실패(잔차가 이득을 상쇄). 이때 다음 측정은 이중 판독(중앙값 = 순수 앵커, 평균 =
   `v4kjt`)을 같은 TEST 행에서 보고하는 학습 없는 행이다 — 두 목적을 한 출력에 담지 않는다.
4. **맞교환이 구조적**: H21-a 성립 ∧ guard 실패. 다음 측정은 같은 이중 판독 행이다.

## 5. 하지 않는 것

- 셀·손실·선택 규칙·잔차 입력 변경 없음(잔차가 s를 보는 것도 그대로 — §1 한계 참조).
- B.20 결과에 따른 이 등록의 변경 금지. B.20과 B.21의 결합 행은 둘 다 수치가 나온 뒤 별도 등록한다.
