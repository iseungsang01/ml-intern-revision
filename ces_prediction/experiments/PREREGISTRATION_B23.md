# B.23 — `V_rot` 점프 과정의 TRAIN 우도 적합 (사전등록 v1, 2026-11-01)

**지위.** `PREREGISTRATION_W2.md` §1–§3, `PREREGISTRATION_B19.md`, `PREREGISTRATION_B22.md`를 상속한다.
`PRACTICAL_EPS = 0.02`, B.13 co-metric(M1–M5), B.16 규칙 1 막대(+0.05)를 상속한다.
**학습 없음.** 이 문서, 적합·판독·판정 코드는 적합 결과와 어떤 B.23 수치도 보기 전에 커밋한다.

**어디서 나온 질문인가 (§8bp).** 순수 t 앵커는 `V_rot` 중앙값에서 백본을 4/4 × 2로 이기지만 persistence와는 동률이다
(유의 1/4, split별 0.94–1.00×). B.22 규칙 3이 지목한 레버: 점프율 λ를 사전등록 값(0.05/걸음 ≈ 5 Hz, σ_J = 1.0
표적 sd)이 아니라 TRAIN에서 맞춘 값으로. 학습은 앵커 모수를 움직이지 않으므로(§8bm, 7 % 이내) 지금의 λ는 등록값 그대로다.

## 1. 통제 변수

`V_rot` 셀의 점프 과정 **(λ, σ_J) 하나**: 등록값 → split별 TRAIN 최대우도. 나머지는 B.19 셀 그대로 —
`V_rot` σ_n·ν·σ_d는 체크포인트 값(초기값 5 % 이내), `T_i` 셀은 전혀 건드리지 않는다(아래 대조).

## 2. 적합 (TRAIN만)

`b16_physics/fit_vrot_jump_b23.py` → `data/.b23_vrot_jump_fit.json`.
- 목적함수: 필터 자신의 한 걸음 예측 로그우도. 매 관측에서 새 값의 예측밀도 = (1 − h)·t_ν(e; P + r) + h·t_ν(e; P + σ_J² + r)
  (h = 마지막 갱신 이후 점프 위험). 재귀는 `model_seq_v4k._jump_scan`의 float64 사본(단위 테스트로 일치 확인).
- 고정: σ_n = 0.060 표적 sd(BULK_SIGMA_N), ν = 3, σ_d = 0.05, p0 = 1. 블록의 첫 관측은 채점하지 않는다(확산 사전).
- 격자: λ ∈ {0.002, 0.005, 0.01, 0.02, 0.03, 0.05, 0.08, 0.12, 0.2, 0.3}/걸음 × σ_J ∈ {0.25, 0.35, 0.5, 0.7, 1.0, 1.4, 2.0}.
  등록값(0.05, 1.0)은 격자 위에 있다. 최댓값이 격자 가장자리면 그대로 쓰고 그 사실을 기록한다(격자 확장 금지).
- split·모집단별(각자의 TRAIN 목록). 데이터 처리: held-free, 스파이크 컷은 `T_i`에만 작용하므로 `V_rot`에 무관.

## 3. 판독과 채점

- `anchor_readout_b16.py --arm v4kjt --vt-jump data/.b23_vrot_jump_fit.json` → `.b23_anchor_{pop}_s{seed}`:
  B.19 `.b16_v4kjt_*` 체크포인트에서 `kalman_vt.lam_logit`, `kalman_vt.j_raw`만 바꾸고 순수 앵커를 TEST에 판독(GPU 추론, 학습 없음).
- `rescore_b13.py --extra anchorf=.b23_anchor_{pop}_s{s} --out data/.b23_rescore.json`.
- `verdict_b23.py` → `data/.b23_verdict.json`. 적합 대 등록: `.b23_anchor` vs `.b19_anchor`(B = 10⁴ shot 군집).
- **대조:** `T_i` TEST 오차가 B.19 readout과 비트 단위로 같아야 한다. 다르면 판정 스크립트가 FATAL로 멈춘다.

## 4. 가설과 판정 (수치 전에 고정)

판정은 컷 1차, 포함 공동 1차.

- **H23-a (persistence 동률을 뒤집는다).** 적합 앵커 `V_rot` M1 vs persistence > 0 ∧ CI > 0, ≥ 3/4 split.
- **H23-b (적합이 등록을 이긴다).** 적합 − 등록 풀링 M1 `V_rot` ≥ +0.02 ∧ CI > 0.
- **H23-c (백본 우위 유지).** 적합 앵커 `V_rot` M1 vs 백본 ≥ +0.05 ∧ CI > 0, ≥ 3/4 split.
- **H23-d (해석).** 적합 λ(Hz), σ_J(km/s), 등록값 대비 로그우도 이득, 격자 가장자리 여부.

**판정 규칙.**
1. H23-a ∧ H23-c (두 모집단) → **`V_rot` 물리 중앙값 추정량 무조건부**; §8bp 이중 판독 표와 논문 `sec:physfilter`의 `V_rot`
   문장을 갱신한다. 한 모집단이면 조건부 표기.
2. H23-b만 성립 → "적합은 등록보다 낫지만 persistence 동률은 남는다".
3. H23-a, H23-b 모두 실패 → **λ는 레버가 아니다.** 다음 측정: 같은 우도로 σ_n과 ν를 함께 TRAIN 적합(측정 모형 쪽).
   그마저 동률이면 §8bl의 "10 ms `V_rot` 본류에서 persistence가 중앙값 최적"이 적응형 필터에도 성립한다고 기록한다.

## 5. 예측 (수치 전에)

| 양 | 예측 |
|---|---|
| 적합 λ | 0.01–0.03/걸음 (1–3 Hz) — 등록 5 Hz보다 드문 점프 |
| 적합 σ_J | 0.5–1.0 표적 sd |
| `V_rot` 중앙값/persistence | 0.94–0.98 (등록 0.975) |
| H23-a | 2–4/4 |
| H23-b | +0.00 … +0.04 (통과 불확실) |
| H23-c | 4/4 |

## 6. 하지 않는 것

- `T_i` 셀, σ_n, ν, σ_d, 잔차, 백본 변경 없음. 격자 확장·재적합 금지. VAL·TEST로 적합하지 않는다.
