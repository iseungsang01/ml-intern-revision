## 1. 실행 관문 — 이 배치는 아래가 전부 닫히기 전에 시작하지 않는다

### 1.1 shot 목록 동결

이 사전등록은 **특정 shot 집합이 아니라 역할 구조에 결속**된다: test k개(동결·비학습) +
pool 7−(k−3)개(leave-one-out 회전) + companion 2개(비학습·비게이트, `folds.py`가 assert).
문헌 스캔 641개 완주 → 문헌 1순위 재선정 → `FINAL_*.csv`·`folds.py` 갱신 커밋이 목록 동결이며,
그 커밋 해시를 아래 슬롯에 기입한다. 목록 동결은 **원시 데이터 요청 전**이어야 한다.

- 동결 커밋(2026-08-21 기입): **`93e01bb`** / test = **31921 · 31873 · 31114 · 31902** /
  pool = **31097 · 31359 · 31747 · 32027 · 32092 · 32097** (companion 31923 · 31357).
  test 4 확장과 #32092 포함은 2026-08-21 승상님 결정(THESIS_RESULTS.md §8ao).

### 1.2 `V_rot` 확증 자격 관문 (test 3 vs 4 미결정의 인코딩)

`V_rot` 확증 판정(§4.2)은 **유효 독립 `V_rot` ≥ 60행인 test 방전이 3개 이상**일 때만 성립한다.
현행 3중항(#31921·#31873·#31114)은 #31873이 `vt_held_frac = 1.00`이라 실효 군집 2개이고,
군집 2개의 shot-clustered bootstrap은 통과율이 **올라가는** 위양성 구간임이 측정되어 있다
(`power_analysis.json`: k=3 0.665 → k=2 0.770). 동결된 test가 이 관문을 통과하지 못하면
**`V_rot` 팔은 자동으로 탐색(exploratory)으로 강등**되며, 사후에 되돌릴 수 없다.
test 4개 확장(측정된 개선: `CES_VT` 0.665 → 0.750, `CES_TI` 0.287 → 0.368)은 승상님 결정
사항이고, 어느 쪽이든 이 관문 자체는 불변이다.

> **판정 기록 (2026-08-21): 관문 통과.** 승상님이 test = 4를 결정했고, 동결된 test 중
> 유효 독립 `V_rot` ≥ 60행 방전이 3개다(31921 = 296 · 31114 = 311 · 31902 = 412).
> `V_rot` 확증 자격이 성립한다. `folds.py`가 이 조건을 assert로 고정한다.

### 1.3 검정력 전제 (이미 측정됨 — 재유도 금지)

`hires_shots/power_analysis.py`(실측 96-shot 게이트 재생): `CES_VT` paired-arm 검정은 k=10
pool+test 규모에서 shot-cluster 66–91%, **효과가 방전 간 일관적일 때만**이며 효과 크기 축소는
검정력을 거의 바꾸지 않는다(비율 지표 — 일관성이 전부). `CES_TI`는 k=12에서도 29–41%로

### 1.4 원시 데이터 품질 관문 (양성 대조 — 이것이 실패하면 실험이 아니라 취득 문제)

1. #31923: 3–6 s 창의 `BES_0206`에서 ~50 kHz 약결맞음 모드(WCM) 피크 (Nucl. Fusion adacfc fig.2).
2. #32027: L/H 천이 부근 100–300 kHz 교차 파워 구조 (PanoMHD fig.7).

4. 전 채널: 명시된 샘플링 주기·안티앨리어싱 필터 유무 메타데이터 확인. 100 Hz 산출물과의

## 2. 사전 가설

| | 가설 | 반증 조건 |
|---|---|---|
| **H1** (확증, `V_rot`) | 앨리어싱이 파괴한 Mirnov 정보를 **원시 스트림에서 복원한 특징**이 `V_rot` 예측을 개선한다 (kHz 모드 활동 → NTV 토크 → 회전) | §4.2 판정 실패. 그 경우 100 Hz 파생 특징의 기존 무효(4-seed paired)와 합쳐 "Mirnov 경로로는 개선 불가"가 되고, 남는 지렛대는 NBI 토크 채널 취득뿐임을 §8에 명기 |
| **H1-m** (기전, H1의 하위) | H1의 개선은 **`V_rot`이 실제로 움직이는 행 층**에서 먼저 나타난다 (§8an: 승패의 유일 예측 변수 = 타깃 변동) | 개선이 층과 무관하거나 조용한 층에 집중 → H1이 통과해도 기전 서술을 철회하고 "특징이 돕지만 모드-토크 경로가 아님"으로 기록, latent probe를 다음 측정으로 지목 |
| **H2** (방향 예측, 탐색) | 진짜 다중 레이트/비균일 입력에서는 **어텐션 계열의 상대 성적이 개선**된다 — 균일 격자의 §8ak differs(−0.023, 3/4)가 완화 또는 역전 | 비균일 입력에서도 어텐션이 같은 폭 이상으로 뒤짐 → "비균일성 가설" 기각, 어텐션 불채택이 격자 특성이 아니라 문제 특성임을 기록 |
| **H3** (측정, 검정 아님) | 세션 누출은 companion 쌍으로 **직접 측정 가능**하다 | 해당 없음 — 어떤 크기든 측정값 자체가 산출물 |
| **H4** (질적, 검정 아님) | 모델 예측은 발표된 천이(FIRE·ELM 억제·ERMP·L/H)를 추적한다 | 그림으로만 보고, 통계 주장 금지 |

`T_i` 관련 가설은 **등록하지 않는다** — §5 참조. H1이 유일한 확증 가설이므로 다중성 보정은
불필요하며, H1 내부의 결합 기준(§4.2)이 위양성을 통제한다.

## 3. 특징 명세

### 3.1 MC (Mirnov) — H1의 특징, `V_rot` 가지 투입

두 코일 MC1T03/MC1T16(전 shot 공통 쌍)에서, **각 10 ms 그리드 행에 인과적으로**(행 시각에서
끝나는 직전 10 ms 창) 계산:

1. **윈도우 RMS 엔벨로프** (코일별 2ch)
2. **대역 파워** log1p, 대역 경계 사전 고정: 0.1–3 / 3–10 / 10–30 / 30–70 / 70–300 kHz
   (WCM 30–70, PanoMHD 100–300 문헌 근거; 코일별 5ch × 2)
3. **모드 회전 주파수** (필수 계약): 두 코일 교차 파워의 지배 피크 주파수 + 교차 위상 부호,
   결맞음(coherence) 문턱 0.5 미만이면 결측 플래그 (3ch: 주파수·부호·유효 플래그)
4. 전 특징 per-shot z-score (`CES_PER_SHOT_NORM=1`과 일관)

- ⟦도착 시 확정⟧ 실제 샘플링 주기: `________` / 반영 후 최고 대역 상한: `________`
  (Nyquist 미달 대역은 제거만 허용, 경계 이동·추가 금지)

### 3.2 BES/ECEI 고대역 — §5의 탐색 전용 특징 (`T_i` 경로)

행당 인과 10 ms 창의 대역 파워(3–10 / 10–30 / 30–70 / 70–300 kHz), 채널 평균 + `BES_0206`
단독(문헌 채널). **확증 팔에는 들어가지 않는다.**

### 3.3 비균일 표현 — H2 전용

⟦도착 시 확정⟧ 납품 포맷 확인 후 기입. 고정되는 제약: 같은 특징·같은 채점 행에서 **연산자
계열만 변수**(순환 vs 인과 어텐션, B.9 코드 재사용), 그 외 전부 동일. 판정 언어는 §3.2(B.9)의
동률/차이 규칙과 `PRACTICAL_EPS = 0.02`.

## 4. H1 확증 설계 (`V_rot` 표준 기준)

### 4.1 팔

| 팔 | 내용 |
|---|---|
| **A0** (control) | `seq_v2`, pool shot만으로 학습, 현행 100 Hz 입력 그대로 |
| **A1** (primary) | A0 + §3.1 특징 전체를 **`V_rot` 가지에** 투입 (한 팔 — 특징 부분집합 탐색은 val 전용·보고만) |
| A2 (절제, 의무 1건) | A1에서 현행 데시메이트 MC 2채널 제거 (W2 §7 계약) |
| R (참조, 판정 아님) | 얼린 B.1 백본(641-shot 학습)을 같은 test 행에 채점 — 문맥 제공용. **A1 대 R 비교를 특징 가치의 증거로 쓰는 것 금지**(학습 데이터가 다르다) |
| L1 (H3, 격리) | §6 — 확증 팔과 산출물 디렉터리·실행 시점 분리 |

**변수는 하나**: A0 vs A1은 입력 특징만 다르다. env = `GATE_ENV` 상속(`W=2`·held-free·
컷 3 keV·`CES_PER_SHOT_NORM=1`), `V_rot` 라우팅(빠른 진단 차단)은 **전 팔 불변** — §3.1
특징은 빠른 진단이 아니라 파생 저대역 요약이므로 차단 대상이 아니며, 이 투입 자체가 실험이다.

### 4.2 학습·선택·판정 (실행 전 고정)

**학습 구조** (`folds.py` 동결 구조): 각 (팔 × 모집단)에 대해 init seed 42로 pool
leave-one-out 폴드 전부를 돌려 **중앙값 종료 epoch**를 얻고, 그 epoch로 pool 전체 재적합을
init seed {42, 1, 7, 123} 4개로 수행한다. TEST 채점은 재적합 4 run × 팔당 1회.
`best_epoch == epochs_run`(상한 구속) 검사 의무.

**모집단**: 두 모집단(컷/포함) 공동 1차 — W2 §1.1. 무조건부 서술은 양쪽 모두 성립 시에만.

**판정 — H1 PASS는 아래 (a)–(d) 전부 충족** (`V_rot`, A1 − A0 paired, 동일 행 검증 후):

- (a) **풀링**: 4 init seed의 행별 paired 차이를 합쳐 shot-clustered bootstrap
  (B=10⁴, seed 12345) 95% CI가 개선 방향으로 0 배제, **두 모집단 모두**;
- (b) **seed 일관성**: seed별 CI 0 배제가 같은 방향 **≥ 3/4**;
- (c) **일반성 가드** (§8al·§8am 교훈 — 풀링 CI 단독 판정 금지): test 방전의 **과반**에서
  paired 개선 양수 **그리고** 최상 기여 방전 1개 제거(−top1) 후에도 풀링 부호 유지;
- (d) **2차 bootstrap**: shot × 500 ms 블록 클러스터가 유의하게 **반대 부호가 아님**
  (반대 부호 유의 시 전체 판정 = 미정).

(a)–(d) 중 일부만 충족 = **미정**, 전부 미충족·역방향 = **기각**. 미정은 미정으로 보고하고
유리한 쪽으로 반올림하지 않는다. §1.2 관문 미통과 시 이 절 전체가 탐색으로 강등된다.

**H1-m 기전 층화** (판정 아님, PASS 문장의 기전 서술을 결정): 행별 국소 `V_rot` 활동 =
목표 행을 제외한 ±250 ms 내 genuine `V_rot` 관측의 표준편차(§8r 교훈 — held 계단으로
활동을 정의하지 않는다). shot 내 3분위로 층화, 상위층 paired 개선 > 하위층이면 기전 유지.

**의무 병기**: `V_rot`은 비절단(승상님 2026-08-16) — persistence-anchored 비교에는
스파이크-anchor 행의 SSE 비중을 병기한다. PR2 폴백률(`V_rot` 40–44%)과 test 행 수도 표로.

### 4.3 탐색 규율

특징 부분집합·대역 조정·하이퍼파라미터는 **pool 폴드 val에서만** 본다. TEST는 A0·A1·A2
각 1회. TEST를 본 뒤의 재튜닝·재채점은 금지(B.9 §3.3과 동일).

### 4.4 비용 추정 (참고)

폴드 7 + 재적합 4 = 11 학습 × 3팔 × 2모집단 ≈ 66 run. 7-shot 학습은 641-shot(1.2–1.4분)보다
훨씬 짧다 — 1 GPU/CPU 반나절 규모. 지연 벤치는 하지 않는다(§8aj 규칙 — 특징 조립 비용만
연산자 수로 보고).

### 4.5 일반화 서술 한계 (상속 계약)

test 방전 수가 3–4인 한, PASS여도 서술은 "이 test 집합에서"를 명시하고 **캠페인 일반화
주장은 하지 않는다**. 부분표본 시간 분할 확인(pool 내 시간순 재분할 1회, 보고만)을 병행한다.

## 5. `T_i` 경로 — 탐색 전용 (보수 기준의 극한값)

§1.3의 검정력(29–41%)에서 **`T_i` 확증 판정 규칙은 이 shot 수에서 존재할 수 없다**. 따라서:

- §3.2 특징의 `T_i` 효과는 **효과 크기 + CI의 서술 보고만** 한다. "유의/PASS" 언어 금지.

  test 집합(차기 캠페인 취득)을 가진 새 사전등록**이며, 그것이 §8j가 요구하는 "지목된 다음
  측정"이다.
