# B.22 — 이중 판독: 중앙값은 순수 t 앵커, 평균은 학습 모델 (사전등록 v1, 2026-11-01)

**지위.** `PREREGISTRATION_W2.md` §1–§3, `PREREGISTRATION_B16.md` §1–§2, `PREREGISTRATION_B19.md`를 상속한다.
`PRACTICAL_EPS = 0.02`, B.13 co-metric(M1–M5), B.16 규칙 1 막대(+0.05)와 MSE guard를 상속한다.
**학습 없음, 새 채점 없음.** 입력은 얼린 `data/.b19_rescore.json`(B.19 채점, 2026-10-31) 하나다.
**이 문서와 판정 스크립트는 split별 순수 앵커 수치를 읽기 전에 커밋한다.** 이미 본 수치는 §8bm의 풀링 값뿐이다
(순수 t 앵커 M1 vs 백본 `T_i` +0.106 / +0.318, `V_rot` +0.165 / +0.181; 중앙값/persistence `T_i` 0.916 / 0.911,
`V_rot` 0.975 / 0.976; MSE vs 백본 −0.37 … −0.42). 예측은 이 풀링 값을 알고 적은 것임을 밝힌다.

**어디서 나온 질문인가 (§8bm, §8bn, §8bo).** 잔차에 가한 세 변경(가산 MSE 잔차, val 중앙값 선택, 분산 가중 결합)이
모두 순수 앵커의 `V_rot` 중앙값 0.975×를 잃었다(1.08–1.12×, 1.07×, 1.15–1.21×). MSE도 이겨야 하는 출력은 조용한 행을
움직인다. B.21 등록 규칙 3에 따라 다음 행은 두 목적을 한 출력에 담지 않는 이중 판독이다.

## 1. 판독

| 역할 | 추정량 | 근거 |
|---|---|---|
| **중앙값 추정량** | 순수 t 앵커 `a` (`.b19_anchor_*`, rescore 키 `anchort_*`) | 물리 필터: 유지-또는-점프 사전 + Student-t 측정(ν ≈ 3, 본류 척도) |
| **평균 추정량** | `v4kjt` (`a + r`), 단 MSE guard가 깨진 모집단에서는 백본 `v2` | 평균(MSE)용 학습 출력. 이 대체 규칙은 수치 전에 고정한다 |

평균 쪽은 이미 측정되었다(§8bm: `v4kjt` guard 컷 성립, 포함 0.0014 미달 → 포함 평균 추정량 = `v2`). 새 가설이 아니라
재기술이다. B.22의 새 측정은 중앙값 추정량의 split별 검정이다.

## 2. 가설 (수치 전에 고정)

판정은 컷 1차, 포함 공동 1차. split {42, 1, 7, 123}. 유의성은 shot 군집 paired bootstrap(B = 10⁴, B.19 채점 그대로) CI 0 배제.

- **H22-a (중앙값: 백본 대비).** 표적별, 순수 앵커 M1 vs 백본 ≥ +0.05 ∧ CI > 0, ≥ 3/4 split.
- **H22-b (중앙값: persistence 대비).** 표적별, 순수 앵커 M1 vs persistence > 0 ∧ CI > 0, ≥ 3/4 split.
- **H22-c (해석, 판정 아님).** 순수 앵커 MSE vs 백본·PCHIP, split별 — 평균 추정량으로 쓰지 않는 이유의 기록.

**판정 규칙.**
1. 두 표적 × 두 모집단 모두 H22-a ∧ H22-b → **"물리 중앙값 추정량" 무조건부**. 논문 결과 II는 이중 판독으로 쓴다
   (중앙값 = 순수 앵커, 평균 = 학습 모델).
2. 한 표적 또는 한 모집단만 → 그 범위로 조건부 표기.
3. `V_rot`에서 H22-a는 성립하나 H22-b 실패 → "`V_rot` 중앙값은 백본보다 낫지만 persistence와 동률"로 기록.
   그것을 뒤집을 측정을 지목한다: split별 fresh/stale 층화(§8bm 3항)에서 stale 행의 점프 위험을 낮추는 λ 초기값(TRAIN 적합).

## 5. 하지 않는 것
