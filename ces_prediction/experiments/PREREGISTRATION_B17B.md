# B.17b — Student-t head: 두꺼운 꼬리 가설을 모수 형태로 직접 묻는다 (사전등록 v1, 2026-10-29)

**지위.** `PREREGISTRATION_B17.md`의 설계·기준·채점(R0/R1, CRPS 닫힌 꼴, PIT 포함률, σ 물리 readout, MSE guard)을
그대로 상속한다. **이 문서는 B.17b의 어떤 수치도 보기 전에 커밋한다.** B.17(§8bf)의 수치는 봤고, 그 결과가 이
등록의 동기다. 변경은 커밋으로만 하며 TEST 수치를 본 뒤의 변경은 전면 금지된다.

**어디서 나온 질문인가(§8bf).** B.17은 "사건 행의 조건부 분포는 두 값"이라는 가설로 2성분 혼합 head를 등록했고,
데이터는 다른 답을 했다: 두 봉우리 행은 0이고, 혼합의 두 번째 성분은 가중치 7–10 %의 넓은 성분이었다. 즉 오차는
**한 봉우리의 두꺼운 꼬리**이고, 그 형태를 모수로 직접 말하는 분포는 Student-t다. B.17의 등록은 주장을 가우시안
팔에, 기전 검정을 두 봉우리에 묶어 두어 실제로 통과한 팔(`v2m2`)을 이름 짓지 못했다. B.17b는 그 두 결함을
고친다: (1) 가설이 heavy tail이고, (2) 주장은 "guard를 통과한 팔"에 묶는다. 또 B.17에서 16 run 중 7개(혼합 8 중 6)가
epoch 상한 60에 걸렸으므로 상한을 100으로 올리고 대조 팔도 같은 상한으로 다시 돌린다.

## 1. 팔과 통제 변수

**통제 변수는 우도의 모수족 하나**(혼합 → t). 인코더·데이터·분할·최적화·선택 규칙(val NLL)·epoch 상한(100)은
두 팔에서 동일하다.

| 팔 | head 출력(타깃별) | 손실 | 비고 |
|---|---|---|---|
| `v2m2` (대조, 재학습) | (π, μ₁, μ₂, σ₁, σ₂) | 2성분 혼합 NLL | B.17과 같은 모델, 상한 100으로 다시 학습(`.b17b_v2m2_*`) |
| `v2t` | (μ, σ, ν) | Student-t NLL | ν = 2.05 + softplus(·), 초기 ν = 5; σ 초기 1(정규화 단위) |

- 구현 `model_seq_v2d.py` `dist="t"`(레지스트리 `v2t`), 평균 경로는 μ. `forward()`가 평균을 돌려주므로 점 채점은
  무수정. 분포 덤프는 `eval_dist_b17.py`가 ν를 함께 쓴다(`{t}_nu`). 채점 `score_b17b.py`(t의 CRPS 닫힌 꼴은
  Jordan–Krüger–Lerch 2019; 단위 테스트가 몬테카를로와 대조).
- 러너 `run_b17.py --arms v2t v2m2 --prefix .b17b --cap 100`, 산출 `.b17b_{arm}_{pop}_s{seed}`,
  러너 요약 `.b17b_runner_summary.json`, 판정 `.b17b_summary.json`. 16 run.

## 2. 기준과 채점 (B.17 §2 상속)

R0 = N(백본 점 예측, 백본 TEST RMSE), R1 = N(팔 평균, 팔 TEST RMSE). CRPS skill, PIT 50/90 % 포함률, σ 관계,
사후 평균 paired MSE vs 백본(guard). 추가로 두 쌍: `v2t − v2m2` paired CRPS(같은 TEST 행), 그리고
`v2m2`(상한 100) − `v2m2`(상한 60, B.17) paired CRPS = 상한의 효과.

## 3. 예측 (수치를 보기 전에 적는다)

| 양 | 예측 | 근거 |
|---|---|---|
| `v2t` CRPS vs R0, `T_i` 컷 / 포함 | **+0.18 … +0.25 / +0.40 … +0.47** (혼합과 ±0.03 안) | heavy tail은 두 모수족이 같은 형태를 표현 |
| `v2t` 50 % / 90 % 포함률 | 0.47–0.56 / 0.88–0.93 | §8bf 혼합의 0.51–0.56 / 0.89–0.92 |
| 학습된 ν (중앙값, `T_i`) | **2.5 … 6** | B.14의 ν = 3, §8aq 꼬리 몫; 혼합의 두 번째 성분 가중치 7–10 % |
| `v2t − v2m2` CRPS | **동률**(|차| < 0.02) | 같은 가설의 두 모수화 |
| `v2m2` 상한 100 vs 60 | +0.00 … +0.03 | 7/16이 상한에 걸렸던 것의 회수 |
| 사후 평균 paired MSE vs 백본, `T_i` 컷 | +0.01 … +0.05 (`v2t`), `V_rot` 동률 | §8bf 혼합 +0.015…+0.051 |

## 4. 가설과 판정 (수치를 보기 전에 고정)

판정은 컷 1차, 포함 공동 1차. 유의성은 shot 군집 paired bootstrap CI 0 배제. **"guard"는 팔마다 같은 네 조건**이다:
(i) `T_i` CRPS vs R0 > 0인 split ≥ 3/4 ∧ 풀링 CI > 0, (ii) 풀링 vs R1 CI > 0, (iii) `T_i` 90 % 포함률 ∈ [0.85, 0.95]
∧ 50 % ∈ [0.45, 0.55]인 split ≥ 3/4, (iv) MSE guard(두 타깃 모두: 유의 열세 ≤ 1/4 ∧ 평균 ≥ −0.02).

- **Hb-guards(팔별).** `v2t`, `v2m2` 각각 네 guard 통과 여부.
- **Hb-1 (t vs 혼합).** `v2t − v2m2` 풀링 CRPS: |차| < 0.02 또는 CI가 0 포함 → 동률; ≥ +0.02 유의 → t 우세; ≤ −0.02
  유의 → 혼합 우세.
- **Hb-2 (ν의 해석).** `v2t`의 `T_i` ν 중앙값이 2–8 안이면 "꼬리는 유한 분산의 heavy tail"로 보고(판정 아님).
- **Hb-3 (상한).** `v2m2`(100) − `v2m2`(60) 풀링 CRPS ≥ +0.02 유의 → B.17의 혼합 수치는 하한이었다고 §8bf에 각주.

**판정 규칙.**
1. **"보정된 나우캐스터" 주장**: guard를 통과한 팔이 하나라도 있으면 지지. 둘 다 통과 → Hb-1이 우세를 가리면 그
   팔, 동률이면 **모수가 적은 `v2t`**가 보고 팔. 컷에서 지지되고 포함에서도 지지되면 무조건부, 컷만이면 컷
   조건부, 포함만이면 포함 조건부. 어느 모집단에서도 통과 팔이 없으면 "미지지" — 그 경우 §8bf의 탐색 결과도
   확정으로 승격하지 않는다.
2. Hb-1이 t 우세 또는 동률이면 "오차는 heavy tail 한 봉우리"가 §8bf의 서술에서 측정으로 승격; 혼합 우세면
   "두 번째 척도의 자유도가 값을 한다"로 적고 그 이유(어느 층에서)를 기록.
3. guard (iv) 위반 팔은 기각, 원인 층(peak/nonpeak) 기록(B.17 규칙 4 상속).

## 5. 하지 않는 것

- 가우시안 head(`v2g`)는 다시 돌리지 않는다(§8bf에서 기각). 혼합 성분 수 K ≥ 3, 비대칭 분포(skew-t)는 별도 등록.
- 상한 외의 학습 규약 변경 없음. 점 채점 코드·데이터·분할 불변.

## 6. 비용

16 run × 약 10–15분(상한 100이라 B.17보다 길 수 있음) ≈ 3–4시간 GPU + 채점 10분. 단독 실행.
