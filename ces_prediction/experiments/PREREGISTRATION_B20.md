# B.20 — t 앵커 위 잔차의 체크포인트 선택: val MSE → val 중앙값 AE (사전등록 v1, 2026-10-31)

**지위.** `PREREGISTRATION_W2.md` §1–§3, `PREREGISTRATION_B16.md` §1–§2, `PREREGISTRATION_B19.md` §1–§2(셀·env·채점)를
그대로 상속한다. `PRACTICAL_EPS = 0.02`, B.13 co-metric(M1–M5), B.16 규칙 1 막대(M1 vs 백본 ≥ +0.05, CI > 0, ≥ 3/4)와
MSE guard(`T_i` paired MSE vs 백본 유의 열세 ≤ 1/4 ∧ 평균 ≥ −0.02)를 상속한다.
**이 문서와 코드·판정 스크립트는 B.20의 어떤 수치도 보기 전에 커밋한다.** §8bm의 수치는 봤고, 그것이 이 등록의 동기다.

**어디서 나온 질문인가 (§8bm).**
1. 순수 t 앵커는 두 표적 모두 persistence 아래다(`T_i` 0.916× / 0.911×, `V_rot` 0.975× / 0.976×).
2. MSE로 학습·선택한 잔차를 얹으면 중앙값이 되돌아간다: `V_rot` 1.083× / 1.116×, 포함 `T_i` 1.064×.
   앵커만으로는 집계 MSE가 백본보다 −0.37 … −0.42 나쁘고(사건 행이 늦다), 잔차가 그 행을 사면서 중앙값 행을 판다.
3. §8bh: 자기 목적함수로 선택하면 강건 팔의 중앙값 이득이 두 배가 되었다. 선택 규칙은 학습 손실과 별개의 변수다.

## 1. 팔과 통제 변수

**통제 변수는 체크포인트 선택 규칙 하나**: val MSE → val 중앙값 AE. 조기 종료(patience 6)·체크포인트·LR plateau가 모두
같은 키를 쓴다(§8bh와 같은 묶음). 키 = 두 표적의 관측 val 행 |예측 − 참값|(정규화 단위) 중앙값의 평균
(`train_seq.py::median_ae_key`, `CES_SEQ_SELECT=medae`). 학습 손실(MSE + `T_i` 0 아래 벌점)·셀(`v4kjt`, ν₀ = 3, 본류 척도)·
epoch 상한 60·데이터·분할은 B.19와 동일하다.

| 팔 | 출력 | 비고 |
|---|---|---|
| 대조군 `v2` | head(h) | 얼린 백본 |
| 대조군 `v4kjt` | t 앵커 + 잔차, val MSE 선택 | 얼린 B.19 run(`.b16_v4kjt_*`) |
| **`v4kjt`, medae 선택** | 같은 셀, val 중앙값 AE 선택 | `run_b16.py --arms v4kjt --select medae` → `.b20_v4kjt_*` |

## 4. 가설과 판정 (수치를 보기 전에 고정)

판정은 컷 1차, 포함 공동 1차. 유의성은 shot 군집 paired bootstrap CI 0 배제.

- **H20-a (중앙값 회복).** `v4kjt`(medae) `T_i` 중앙값/persistence ≤ 0.95 ∧ `V_rot` ≤ 1.00 (모집단별).
- **H20-b (선택의 이득).** medae − MSE 선택 풀링 M1 `T_i` ≥ +0.02 ∧ CI > 0.
- **H20-c (B.16 규칙 1).** M1 vs 백본 `T_i` ≥ +0.05 ∧ CI > 0 (≥ 3/4) ∧ MSE guard.
- **H20-d (`V_rot` 전체, H19-d와 같은 막대).** M1 vs 백본 `V_rot` ≥ +0.05 ∧ CI > 0 (≥ 3/4) ∧ MSE 유의 열세 0/4.
- **H20-e (해석).** best epoch, epochs run, 앵커 모수의 초기값 대비 비.

**판정 규칙.**
1. **포함 규칙 1 충족**: 포함 H20-c. 그러면 물리 rung이 무조건부(컷은 §8bm, 포함은 여기)가 된다 — 단 컷 H20-c도
   유지되어야 하며, 컷에서 깨지면 "모집단별 선택 규칙"으로 기록하고 무조건부라고 쓰지 않는다.
2. **선택이 원인이었다**: H20-a ∧ H20-b ∧ guard(해당 모집단).
3. **맞교환이 구조적이다**: H20-a 또는 H20-b는 성립하나 guard 실패(유의 열세 ≥ 2/4 또는 평균 < −0.02). 이때 다음 측정은
   **잔차 라우팅**(잔차가 앵커의 점프 사후확률이 높은 행에서만 작동, 선택 규칙은 MSE로 되돌림)으로 지목한다.
4. 중앙값이 돌아오지 않음(H20-a ∧ H20-b 모두 불성립): 선택 규칙은 원인이 아니다. 다음 측정은 같은 라우팅 행이다.

## 5. 하지 않는 것

- 학습 손실·셀·앵커 초기값·잔차 구조 변경 없음.
- 모집단별로 다른 선택 규칙을 골라 합치는 것 금지(판정 규칙 1의 단서).
- 데이터·분할·모집단·채점 코드 불변.
